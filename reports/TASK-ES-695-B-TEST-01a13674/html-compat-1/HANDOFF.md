# --html 선택 경계 교정 인계

작성과 L1 측정은 끝났고 정상 hook/source 및 closure를 진행한다. 실제 CI·Court·사용·효과는 미확인이다.

원 raw HTML의 ensureUserRow/loadProfile header 중 하나라도 있으면 기존 names6/extract 첫선언 선택을 사용한다. 둘 다 없는 default만 기존 actual4IIFE+나머지4extract를 그대로 쓴다. --html parse·원 extractor·ROOT inline-bundle/iso/Ledger는 불변이며 AST/임의 정규화는 추가하지 않았다. 하나만 있는 혼합의 기존 lexical 한계도 새로 보충하지 않는다.

SOURCE-PROOF.json: 기본 guardfalse, actualIIFE 블록 indent 제외 동일, 원 extractor 동일, 원22단언·6case·suffix SHA 동일, 원제품/helper/전체기존보고 23개 pin byte동일. 새 L1은 실제 makeBrowser 함수에서 두 함수 모두/ensure만/load만 세 조건을 한 번 측정해 원 여섯 함수의 첫선언 선택을 모두 확인했다. 이 때 actual 함수 몸체는 호출하지 않았고 IIFE provider read0·실 API/DB/브라우저0이다. 메모리 합성 HTML은 선택 계약의 부품이고 전체 함수 실행·E2E·양성 UI가 아니다.

첫9e49/6of6 raw 및 원CI 실패·CLI-SOURCE-SCOPE 제한 문서는 모두 그대로 보존했다. 원6을 다시 실행하지 않았고 기대값/단언/fixture/원helper/제품/Court/claims/중앙metadata/원격0변경이다. L1 PID 16244 잔류0, actual gpt-6.1-sol/high는 MODEL-PROCESS.json의 자기 turn_context에 결박했다.

root가 최종 제품+시험 exact source 통합과 ops 별도 검토를 담당한다. 기존 --html이 다른 의존성을 ROOT에서 읽는 계약은 유지하므로 과거 HTML 전체의 독립 실행 가능성은 미확인이다. leaf는 TICKET-13의 자기 기록이며 중앙 등록완료 주장이 아니다.
