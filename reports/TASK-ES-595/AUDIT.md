## 2. #859 `openModal` 손 수정의 동치 재증명

- 원본(0ff85932 의 index.html 3805~3856줄)은 세 번째 인자를 `arguments[2]` 로 읽었다.
- 생성기가 최상위 `arguments` 를 막으므로(CELL_SPLIT ⑤), 이름 붙은 매개변수 `thirdArg` 로 **손으로 바꾼 뒤** 옮겼다(`js/core/modal-open.js`).
- 「생성기 외 손 수정 0」 규칙을 어긴 것이다.

**재증명 (이 PR)**
- `tests/fixtures/open-modal-before-es591.js` 에 원본 함수를 글자 그대로 고정했다. 제품 코드가 아니다.
- `scripts/smoke-test.js` 에 동치 대조 검사 1개를 **추가**했다. 원본과 지금 세포에 같은 입력 10가지를 넣는다:
  - 문자열 하나 / 문자열+onMount / 제목+본문 / 제목+본문+세 번째 함수 / 세 번째가 함수 아님 / onMount+세 번째 함수 / 객체 onOpen / 객체+두 번째 onMount / mount 예외 / 빈 값
  - 각 입력 뒤에 한 번 더 연다(history 플래그 재사용 확인).
- 비교 항목: 시트 HTML, 마운트 호출·클래스 추가·history 기록 순서, history 플래그, 바깥 눌러 닫기 처리기.
- 결과: 작업자 PC 에서 439개 통과·0개 실패. 법정 판정은 GitHub 에서 따로 난다.
- **변이 시험**: 세포의 `thirdArg` 처리 줄을 지우면 이 검사가 「제목+본문+세 번째 함수」에서 실패한다(438 통과·1 실패). 원복 확인함.
- 추가로 정적 확인했다:
  - 앱 전체에서 `openModal` 호출 135곳 중 인자 3개 이상인 곳은 0곳이다(`@babel/parser` 로 js/** 와 index.html 인라인을 셈).

  - 함수 길이 속성(`openModal.length`)은 2 → 3 으로 바뀌었지만, 이것을 읽는 코드는 없다.

**남은 것**
