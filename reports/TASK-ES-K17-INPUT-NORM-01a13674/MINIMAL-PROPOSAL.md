# 개요

[결심 필요] 승인선⑤: 이미 승인된 홈 추천 칩·컨디션·커닝페이퍼 정리와 현재 강제 문구를 맞추는 **법령 전문 제2조 제9항 3·4호 한정 개정**을 권장한다. 이 파일은 검토용 초안이다. K17의 새 헌법 개정 승인·발효·병합은 확인되지 않았다. 원격 main의 커널은 `v2026.10.14-DIR006-SAVE`이고 전문 판도 `2026.10.14-DIR006-SAVE`다.

삭제 원승인을 다시 요청하는 안이 아니다. 정확 삭제 원문과 후속 이해 확인을 인수했고, 문서의 규범 강제만 별도 승인선으로 올린다. 근거는 커널 5.1·14.2·14.3·14.5와 전문 제14조 제8항이다. 전문 상세를 커널에 해당 문장이 없다는 이유로 무효 취급하지 않는다.

권장안은 표현 먼저·분류 나중, 서로 다른 차원의 자료 분리와 기존 값 보존을 유지하면서 추천 칩/컨디션 입력의 구체 형태 강제를 제거한다. 승인되면 총괄이 정확 본문·전문 판·대장 기록의 초안 PR를 법정에 청구하고 승인 범위와 판정을 대조하여 병합한다. 그 다음 단독 제품 담당이 사용처 조사 결과를 근거로 기존 삭제 승인 범위를 구현·검증한다. 운영 SQL·새 글·서버 수집 확대는 열리지 않는다.

- 권장: 전문의 두 강제 문장과 필수 판·대장만 정합. 장점은 기존 결정과 규범의 모순 해소, 단점은 별도 규범 PR가 필요하다는 것, 예상 결과는 K17 후속 구현의 정확한 기준 확보다.
- 현행 유지: 규범 문서를 보존하지만 추천 칩·컨디션 삭제의 제품 반영은 충돌이 남는다. 독립적인 사용처 조사·시안 대조·문구 대비 준비는 계속 가능하다.

# 핵심 변경사항

`MINIMAL-STATUTE.diff`는 검토용 텍스트이며 대상 법령 파일에는 적용하지 않았다. 전문 제2조9항3호의 첫 문장과 무예단/차원 분리 목적은 유지한다. 커널 조문·버전·포인터는 이번 전문 한정안에서 변경할 이유가 없다(14.5). 새 전문 판 제안은 `2026.10.14-K17-INPUT`이며 현재 효력은 없다.

필수 기록은 전문 머리의 「법령 전문 판」만 새 판으로 올리고 현행 커널 버전 `v2026.10.14-DIR006-SAVE`를 유지하며, 버전 대장에 **전문만의 개정 기록**을 추가하는 것이다. 실제 PR 번호·승인근거·병합커밋/시각이 없으면 null 또는 대기로 적는다. 새 마지막 행에 다른 커널 버전을 꾸며 넣지 않는다. 법정 `appendix.js`의 마지막 대장 행 커널 버전 검사와 전문판 기록의 양립은 정확한 PR 작성 단계에서 별도 대조할 사항이며, 도구 변경으로 풀지 않는다.

관련 정본 정합은 별도 경계다. `MASTER_PLAN_OURGOAL.md` L387(추천 칩), L390(두 줄 슬라이더)은 같은 두 강제를 반복하고 L284는 커닝페이퍼 힌트 기획이다. 전문에 의해 기획정본 준수도 강제되므로 전문 두 문장만 바꾼 상태를 전체 규범 정합 완료로 부르지 않는다. 후속 원승인된 기획 내용 정합은 기존 tri-sync 전용 경로·단독 담당을 통해야 하며, 이 문서는 그 원격 변경을 승인하거나 실행하지 않는다. ACTIVE DIR005의 보존 문구는 해당 디자인 PR의 동작보존 범위에 남긴다. 지시함 자체 변경이 필요하면 대표 병합 전용 절차를 따른다.

반론①: 삭제를 승인했으니 규범 파일 변경도 자동 허용된다. 원결심 기록은 삭제 결심으로 명시했고, 06의 맞음 확인은 그 이해 범위를 확정한다. 전문본문은 별도14.5/승인선⑤이므로 확대하지 않는다.

반론②: 규범의 상세가 커널에 없으니 무시해도 된다. 부재는 모순이 아니며 14.5가 전문을 해설·상세·부록으로 인정한다. 정확 두 강제를 개정 대상으로 준비하는 것이 지속적인 정합이다. PR978 승인은 DIR006 순서 한정이고 이 안의 근거가 아니다.
