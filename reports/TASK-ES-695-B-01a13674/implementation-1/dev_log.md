# DIR006 B 작업 기록

기준/모델/선정 이유는 source-intake.json, 실제 바뀐 범위와 원/후속 증거 SHA는 source-packet.json이다. root는 제품 6파일 단독 writer를 지정했고 pending 읽기능력과 신고서 hand 추가만 범위를 확정했다. 다른 세션 파일/원raw/지시함·헌법·Court/기준선/원시험/실제 운영은 수정하지 않았다.

기본값: 원 A key와 schema를 손실 없이 확장하고 기존 DTO·P0 함수·무인자 await를 유지했다. 오래된 queue와 0행은 새변경/부재로 추정하지 않고 보관한다. 실제 guest 입구는 visible CDP 조작이고 실제 auth/E2E는 null이다. 실제 DB·사진/AI/일정/settings 서버 확대·새 AI 요청·원 시험예산 재사용은 0이다.

원칙 ①~⑧은 REQ와 PLAN에 별도로 기록했다. source 작성·로컬 측정·Court 정본·운영 사용·효과를 구분한다. 원 실패를 보존하며 다음 검토는 exact sealed source에서 root가 배정한다.
