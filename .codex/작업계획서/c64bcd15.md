# 작업계획서 — #TASK-ES-175 크롬 PWA 아워골 앱 다운로드/설치 카드뉴스 설명서

## 1. 목표 (본질)
- 구글 플레이 2주 비공개 테스트 전 지인들에게 아워골 웹 주소를 전달할 때, 크롬 브라우저를 통해 스마트폰 및 PC 바탕화면에 정식 앱(PWA) 형태로 손쉽게 설치하는 전 과정을 실제 아워골 화면과 크롬 UI 예시 이미지를 반영한 5단계 카드뉴스 형태로 제작하여 완벽한 온보딩 경험을 제공한다.

## 3. 막힐 지점 예상 (문제해결 8원칙 ⑧)
- 막힐 지점 1: 기기/브라우저별 메뉴 명칭 차이 (안드로이드 크롬의 '홈 화면에 추가' vs '앱 설치').
  - 해결 방안: 카드뉴스 3번에 두 가지 케이스를 모두 시각적으로 강조하여 어떤 버전의 크롬을 쓰더라도 헷갈리지 않게 처리.
- 막힐 지점 2: 카카오톡 인앱 브라우저로 링크를 열었을 때 바로 '홈 화면에 추가' 메뉴가 뜨지 않는 문제.
  - 해결 방안: 카드뉴스 상단에 [카톡에서 열렸나요? 우측 상단 ⋮ -> 다른 브라우저로 열기(Chrome)를 눌러주세요] 안내 뱃지를 눈에 띄게 배치.
- 막힐 지점 3: 이미지 로딩 지연 시 모바일 카드뉴스가 비어 보일 가능성.
  - 해결 방안: 이미지 외에 CSS 기반의 직관적인 단계별 텍스트 카드와 아이콘을 듀얼 레이어로 배치하여 네트워크 상황과 무관하게 완벽한 시각 정보 전달.
