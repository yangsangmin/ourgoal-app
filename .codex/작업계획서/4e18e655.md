# #TASK-ES-033 기존 카카오 로그인 사용자의 구글 로그인 시도 시 세션 파괴 및 로그인 불능 먹통 버그 근본 해결

## 목표
카카오 로그인으로 사용하던 기존 사용자가 구글 로그인을 시도했을 때 세션이 파괴되거나 계정 충돌로 인해 구글·카카오 모두 로그인이 불가능해지는 치명적 결함을 원천 해결하고, 기존 계정 보호 및 안전한 로그인 복구 파이프라인을 구축한다.

## 막힐 지점 예상 (8원칙 ⑧)
1. **Supabase 콘솔 설정 제약**: Supabase Auth의 Google Provider가 현재 콘솔에서 비활성화되어 있는 상태임.
   - **대응책 및 해결 완료**:
     (1) 비활성화된 구글 Provider 환경에서 기존 카카오 계정을 오염시키던 `signUp({ email, password })` 가짜 비밀번호 시도를 차단하고, 동일 이메일 충돌 시 "이 계정은 카카오로 시작하신 계정입니다" 모달을 띄워 카카오로 즉시 인계하도록 배선 완료.
     (2) 로그인 상태에서 구글 캘린더/토큰 연동 시 기존 카카오 세션을 100% 보존.
     (3) 카카오 OAuth 리다이렉트 시 타이밍 이슈를 `onAuthStateChange` 및 대기 루프로 완전 방어.
     (4) 클라이언트 세션 꼬임 자가 치유(Self-healing) 버튼을 랜딩 및 로그인 화면에 제공.
