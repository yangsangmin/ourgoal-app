# 작업계획서: 아워골 로그인 체계 카카오 단일화 및 구글 캘린더 연동 분리

## 목표
카카오와 구글 로그인 공존으로 인한 계정 분리 및 데이터 증발 착시 문제를 근본 해결하기 위해, 메인 로그인 진입로를 **[카카오로 3초 만에 시작하기]** 하나로 일원화하고, 구글 인증은 로그인 창에서 제거하여 앱 내부 **[설정 > Google 캘린더 연동]** 전용 기능으로 분리 재배치한다. 또한 카카오 가입 전 실명 노출에 대한 거부감을 없애기 위해 로그인/회원가입 화면 전면에 **[🔒 카톡 실명 걱정 No! 닉네임과 개인정보는 100% 익명으로 언제든 변경 가능해요]** 안심 뱃지를 탑재한다.

## 막힐 지점 예상 및 해결 내역 (문제해결 8원칙 ⑧)
- **막힐 지점 1**: 구글 로그인 버튼을 없애면 기존에 구글로만 들어왔던 사용자가 계정을 잃어버렸다고 느낄 수 있음.
  - **해결책**: 로그인 화면 하단의 `[로그인이 잘 안되시나요? (세션 초기화·복구)]` 링크 및 최근 로그인 뱃지를 통해 언제든 이전 이메일/닉네임으로 데이터를 복구해 카카오 계정으로 이어갈 수 있도록 안전망을 상시 유지함.
- **막힐 지점 2**: 카카오 로그인 일원화 시 사용자가 '내 카톡 실명이 앱 전체에 공개되는 것 아닌가' 하는 심리적 불안감으로 가입을 포기할 수 있음.
  - **해결책**: 로그인/회원가입 창 카카오 버튼 직하단에 자물쇠 아이콘과 함께 `[🔒 카톡 실명 걱정 No! 닉네임과 개인정보는 100% 익명으로 언제든 변경 가능해요]` 안심 뱃지를 전면 배치하여 사용자 진입 장벽과 마찰을 완전히 해소함.
- **막힐 지점 3**: `scripts/smoke-test.js`에 기존 `authGoogleBtn` 또는 `landGoogleBtn` 검증이 남아있을 경우 테스트 실패 위험.
  - **해결책**: 스모크 테스트의 검증 조건을 '카카오 단일 로그인 표준화, 구글 캘린더 전용 분리 배선 및 익명 보장 안심 뱃지'로 동기화 갱신함.
