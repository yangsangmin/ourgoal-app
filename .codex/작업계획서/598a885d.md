**목표**: 아워골 앱 내 잔존하는 모든 Claude(Anthropic) API 호출, 구버전 Gemini 모델(404 유발), 하드코딩 라벨("Claude 판단") 및 외부 프롬프트를 Google Gemini API(Gemini 3.1 Flash Lite 1순위)로 100% 전면 전환 및 단일화, 오프라인 및 서버 지연 시 로컬 폴백 안내 문구 장착

## 1. 문제해결 8원칙 기반 분석
1. **문제 파악**: 기록 피드백 화면에 "Claude 판단"이 표시되고, 서버리스 엔드포인트 7종에 Anthropic Claude 호출 코드가 잔존하여 GEMINI_API_KEY 미설정 또는 오류 시 실제 Claude API가 호출되거나 라벨이 하드코딩되어 표시됨. 또한 vision-table 및 index.html 일부에 404를 유발하는 구버전 모델(gemini-2.5-flash 등)이 기본값으로 남아 있음.
2. **본질·원인**:
   - `api/feedback.js`를 포함한 서버리스 함수 7종에 Claude 캐스케이드가 남아있음.
   - `index.html`에서 서버 응답 수신 시 무조건 `parsed.source = 'ai'`로 설정하고 이를 "Claude 판단"으로 출력함.
   - `index.html` 설정 기본값이 `aiProvider: 'claude'`, `geminiModel: 'gemini-2.5-flash'`로 설정되어 있음.
3. **해결 방식**:
   - 모든 서버리스 API(`api/*.js` 8종)에서 Anthropic Claude 의존을 완전 삭제하고, Google Gemini API 정본 모델(`gemini-3.1-flash-lite` 1순위, `gemini-3.6-flash`, `gemini-3.5-flash`, `gemini-flash-latest`) 캐스케이드로 통일.
   - `index.html` 내 AI 프로바이더 기본값, 모델 기본값, 출처 라벨링("Gemini 판단"), 설정 탭 UI, 데이터 내보내기 프롬프트 문구를 모두 Gemini API로 전면 전환.
   - 마일스톤 축하 모달 및 피드백 슬롯에 상민님 확정 안내 문구(`⚡ 오프라인 상태 또는 아워골 서버 문제로 기본 안내가 생성되었습니다`, 12px) 장착.
4. **재검토**: 기존 기능(목표 생성, 체크인 피드백, 다음 행동 제안, 오늘의 미션, 비전 표 인식, 페르소나 생성 등)의 정상 동작을 보장하며, 키 미입력 시에도 로컬 스마트 폴백이 안정적으로 동작하도록 무중단 아키텍처 유지.
