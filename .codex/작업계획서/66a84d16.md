## 2. 막히는 지점 예상 (문제해결 8원칙 ⑧)
- **입력 도중 완료 클릭 시 blur 이벤트 지연**: 사용자가 input에 타이핑하고 엔터나 blur 없이 곧바로 하단 완료 버튼을 누를 경우, input change 핸들러가 미처 실행되기 전에 모델 저장이 일어날 수 있음.
  -> **대책**: 완료 버튼 클릭 핸들러 내부에서 `document.activeElement.blur()`를 즉각 실행함과 동시에, 현재 DOM 상의 `#goalTitleInput`, `data-msinput`, `data-taskinput`의 값을 직접 순회 추출하여 `goal` 모델에 강제 커밋한 후 `saveProfile()`을 호출함.
- **모바일 하단 내비게이션 바와 플로팅 완료 바 겹침**: 모바일 화면에서 하단 바(nav)가 플로팅 완료 바를 가릴 위험.
  -> **대책**: `bottom: 76px;` 및 `z-index: 900;`을 부여하여 하단 탭바 위에 안정적으로 플로팅되도록 설계.
