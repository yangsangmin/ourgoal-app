# 작업계획서 (561f5242)

## 작업 목표
- 상민님 직접 지시: "아니 나는 테마 구분 없이 진짜 다양한 데이터를 넣어도 ai 기반으로 적합하게 시각화까지 됐으면 좋겠어. 이해했어?"
- 사전 하드코딩된 도메인(운동/러닝 등)의 한계를 완전히 철폐하고, 세상의 그 어떤 임의의 기록 데이터(체중, 독서, 수면, 칼로리, 저축, 코딩, 혈압, 타수, 악기, 커피 등)가 유입되더라도 Google Gemini 3.1 Flash Lite 기반 AI가 데이터의 지표명, 단위, 최적 집계 방식(합계/평균/최대/최신), 최적 차트 타입(스플라인 면적/라인/바), 맞춤형 인사이트를 자율 추론하고, 성취 통계 뷰에서 100% 동적 다차원 시각화로 완결하는 시스템 구축.

## 세부 실행 계획
1. **AI 자율 메트릭 추론 & 스키마리스 인제스천 엔진 (`js/universal-stats.js` 고도화)**:
   - `aiDiscoverRecordMetrics(recs, geminiKey)`: 기록들의 비정형 줄글 및 표에서 임의의 메트릭(지표명, 이모지, 수치, 단위, 집계특성 `sum`|`avg`|`max`|`latest`, 차트형태 `area`|`line`|`bar`)을 Gemini 3.1 Flash Lite API 및 로컬 스마트 휴리스틱으로 자율 감지.
   - 메트릭 레지스트리를 유저 DB에 동적 저장/캐싱하여 반복 연산 방지.
   - 3대 운동, 러닝 외에도 독서(쪽), 체중(kg), 수면(시간), 저축(만원), 칼로리(kcal), 커피(잔) 등 100% 무제한 지표 자율 수용.

2. **서버리스 API 엔드포인트 통합 (`api/goaltemplate.js` & `vercel.json`)**:
   - Vercel Hobby 12개 함수 한도를 100% 준수하기 위해 `api/goaltemplate.js`에 `action: 'ai_stats_agent'` 추가.
   - `vercel.json`에 `/api/statsagent` -> `/api/goaltemplate` 리라이트 추가.
   - 사용자의 임의 기록 샘플을 받아 최적의 메트릭 분류, 차트 타입, 시계열 통찰 리포트를 JSON으로 반환.
   - 오프라인/지연 시 즉시 작동하는 무중단 로컬 스마트 추론기 내장.

3. **성취 통계 뷰 동적 제로-스키마 시각화 대시보드 개편 (`index.html` & `js/universal-stats.js`)**:
   - `recUniversalStatsContainer`의 상단 칩바를 AI가 발견한 모든 동적 지표(`[⚖️ 체중]`, `[📖 독서량]`, `[💤 수면]`, `[🏋️ 3대]`, `[🏃 러닝]` 등)로 실시간 생성.
   - 각 지표별 최적 차트(라인, 막대, 스플라인 영역) 자동 전환 렌더링.
   - 지표 성격에 맞춘 4대 KPI 카드(최신값/누적/평균/PR, 전월 대비 성장률) 자동 계산.
   - Gemini 3.1 Flash Lite의 지능형 데이터 인사이트 코멘터리 카드 동적 표시.

4. **1-클릭 샘플 로드 & 자유 텍스트 AI 인제스터 확장**:
   - 샘플 로더에 러닝, 3대 운동 외에 체중 1년치(78kg->68kg), 독서 1년치(주 100쪽), 수면 1년치(6.2h->7.8h) 등 다채로운 도메인 샘플 탑재.
   - 텍스트 입력창에 "오늘 체중 71.2kg, 책 45쪽 읽고 커피 2잔 마심"과 같이 여러 지표가 섞여 있어도 AI가 즉시 분리하여 각각의 독립 지표로 흡수.

5. **검증 및 3자 상호 동기화**:
   - `scripts/smoke-test.js`에 임의 도메인(체중, 독서, 수면 등) AI 메트릭 자율 추출, 다형성 차트 렌더링, `/api/statsagent` 배선 테스트 추가.
   - `npm test` 229개 전수 100% PASS 확인.
   - `index.html` 300줄 순증가 한도 엄수.
   - dev_log.md 4블록 정본, TICKETS.md 갱신, Git 커밋, Tri-Sync 확인.
