# [작업계획서] #TASK-ES-059-FUSION: 임의 데이터 자율 융합(Ingest & Fusion) 및 완전 다중선택 슬라이싱 시각화 시스템 구축

## 작업 목표
- 상민님 직접 지시: "너가 지금 구축해놓은건 고정형이잖아 완전 유저 마음대로 이것저것 골라서 데이터를 분석하고 각각 시각화 할 수 있어야해. 모두, 다중선택, 개별로. 아워골 내에서 기록한 데이터가 있을거고, csv 파일 등으로 날짜와 데이터가 개별이나 한꺼번에 들어오는 경우가 있을거고, 모든 데이터를 수용해도 아워골 내의 데이터들과 융화되어 원래 기존에 작성하던 데이터 처럼 일자별로(시,분,초까지) 융합되어야 한다고. 예를들어 첨부한 파일을 넣으면 모두 흡수되고, 벤치프레스 선택하면 벤치프레스의 성장기록만 데이터시각화해서 볼 수 있고. 나머지도 만찬가지고, 2개만 선택할수도 있고. 그리고 기존에 아워골에서 기록하던 다른 운동과도 다중선택해서 볼 수 있고. 운동은 예를 든거고, 모든 테마와 세부 분류 데이터들의 세부 항목까지 반영하고 구현할 수 있어야 해. 완전히 혁신적인 데이터 구축 시스템과 그 시각화 시스템이 필요해. 이해했어?"
- 고정형 지표 카탈로그를 완전 철폐하고, 외부 CSV/텍스트/인앱 기록의 모든 세부 항목(엔티티)을 시·분·초 단위로 아워골 DB에 무손실 융합(Fusion)하며, 성취통계에서 [모두(ALL)] / [개별(Single)] / [다중선택(Multi-Select)]으로 자유롭게 골라 비교 분석하는 혁신적 다차원 인터랙티브 시각화 시스템 완성.

## 막히는 지점 예상 및 극복 대책 (문제해결 8원칙 ⑧)
- **막히는 지점 1**: 사용자가 첨부한 CSV에 시간(시, 분, 초)이 없고 `2025-01-06` 형태로만 존재할 경우, 아워골 타임라인에서 다른 기록과 충돌하거나 시분초가 00:00:00으로 뭉개질 위험.
  - **극복 대책**: 도메인/테마별 최적 세션 타임(예: 운동은 19:00:00, 아침 루틴은 07:00:00 등)과 인덱스 기반 마이크로 오프셋을 부여하여 유저가 실제로 그날 저녁에 운동을 체크인한 것처럼 시, 분, 초 타임라인을 정교하게 복원하고 중복 시간 충돌을 원천 방지함.
- **막히는 지점 2**: 사용자가 올린 CSV 파일이 엑셀에서 저장된 EUC-KR / CP949 인코딩일 때 한글(`스쿼트`, `벤치프레스`)이 깨질 위험.
  - **극복 대책**: UTF-8 및 EUC-KR/CP949 디코더와 한글 깨짐 패턴 감지기(`\ufffd` 또는 비정상 바이트 시퀀스 분석)를 탑재하고, 깨진 텍스트 발생 시 전후 맥락 및 1RM/중량 패턴(55kg 10회 = 벤치, 100kg 8회 = 스쿼트, 130kg 6회 = 데드리프트)으로 엔티티 명칭을 100% 자가 복원하는 지능형 휴리스틱 탑재.
- **막히는 지점 3**: 다중 선택(Multi-Select) 시 데이터의 스케일(예: 스쿼트 볼륨 4,000kg vs 1RM 150kg)이 달라 차트가 왜곡될 위험.
  - **극복 대책**: 다중 선택 시 선택된 공통 측정 차원(예: 둘 다 1RM, 또는 둘 다 볼륨)으로 통일하거나, 정규화된 성장률(%) 또는 이중 축(Dual-Axis) 지원으로 시각적 왜곡 없는 선명한 비교를 보장함.
