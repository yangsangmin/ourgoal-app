## 막힐 지점 예상 (문제해결 8원칙 ⑧)
- **팀 목표 복사 시 마일스톤 및 태스크 ID 중복**: 단순 복사 시 기존 ID를 그대로 유지하면 개인 목표와 팀 목표 간 데이터 충돌이 생길 수 있음 -> 신규 고유 ID(`g-tl-ms-...`, `g-tl-tk-...`)를 동적으로 생성하여 완전 독립화.
- **참가 팀원 달성도 실시간 연동**: 연계 개인목표에서 할일 체크나 마일스톤 완료 시 팀 목표 화면의 달성률과 즉시 동기화되지 않을 우려 -> 할일/마일스톤 변경 시 `groupState(groupId).teamGoalParticipants` 내 진행률(%)을 즉시 재계산하여 보존.
