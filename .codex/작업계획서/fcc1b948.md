# [작업계획서] #TASK-ES-051: Gemini 비전 요청 inlineData 카멜케이스 규격 준수, API 키 공백 트림 및 사진 512px JPEG 리사이징 전송

## 1. 배경 및 목적
- **상민님 직접 지시**: "지금 다시 아바타 제작 해보니까. 실패 문구 안내되는데, api 왜 안되는지 다시 확인해"
- **요구사항 분석 및 근본 원인 해결**:
  1. Vercel Secret 등록 시 포함되었던 공백/CRLF 제거 및 `api/promptgen.js` 내 `.trim()` 안전망 구축으로 401 인증 실패 원천 차단.
  2. 구글 REST API v1beta 비전 규격 `{ inlineData: { mimeType, data } }` 및 `responseMimeType: 'application/json'` 준수로 400 Bad Request 원천 차단.
  3. 클라이언트 모바일 고해상도 사진을 512x512 캔버스를 거쳐 50~80KB의 표준 JPEG Base64로 압축 전송하여 Vercel 4.5MB 한도 초과 및 디코딩 지연 완벽 방지.

## 2. 작업 범위
- `api/promptgen.js`: API 키 공백 트림, inlineData 카멜케이스 규격 준수, 최신 모델 체인 정비 및 에러 로깅.
- `js/avatar-system.js`: 사진 업로드 시 512x512 캔버스 리사이징 및 JPEG(0.85) 정규화 압축.
- `scripts/smoke-test.js`: #TASK-ES-051 검증 항목 추가 (221개 전수 통과).
- `docs/rules/TICKETS.md`: #TASK-ES-051 등록 및 완료.
