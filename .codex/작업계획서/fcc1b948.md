# [작업계획서] #TASK-ES-052: Gemini 3.1 Flash-Lite Image 멀티모달 이미지 생성 모델 도입 및 AI 맞춤형 웹툰 아바타 직접 생성

## 1. 배경 및 목적
- **상민님 직접 지시**: "해결책은?", "진행해"
- **근본 원인 분석**:
  - 기존 방식은 구글 API를 텍스트 비전 모델(`gemini-3.1-flash-lite`)로만 호출하여 JSON 속성을 추출한 뒤, 브라우저가 하드코딩된 동그라미/점 2개로 2D 캔버스 스티커를 그리고 있었기 때문에 사용자 사진에 관계없이 항상 동일한 스티커 이미지가 렌더링되었음.
- **해결 방안 (Solution 1 반영)**:
  1. 구글 AI 스튜디오 최신 멀티모달 이미지 생성 모델(`gemini-3.1-flash-lite-image`, `gemini-3.1-flash-image`, `nano-banana-pro-preview`)을 엔드포인트에 1순위로 직접 연동.
  2. 사용자의 원본 사진과 선택한 77종 바디 테마(`theme.name`, `theme.cat`, `theme.gear`)를 결합하여 세상에 단 하나뿐인 3등신 한국 웹툰풍 맞춤형 캐릭터 일러스트(JPEG Base64)를 AI가 직접 생성하여 `avatarUrl`로 반환.
  3. 클라이언트(`js/avatar-system.js`)는 생성된 고품질 아바타 이미지를 256x256 캔버스로 리사이징하여 약 35KB로 경량화한 후 아바타 프리뷰 박스에 즉시 렌더링하고 `profile.settings.customAvatarUrl`에 영구 저장.
  4. 네트워크 장애나 구글 정책 차단 시 안전하게 기존 비전 분석 + 캔버스 렌더러로 원활히 폴백(2순위) 처리.

## 2. 작업 범위
- `api/promptgen.js`: 멀티모달 이미지 생성 모델 호출 (`gemini-3.1-flash-lite-image`) 및 `avatarUrl` 반환.
- `js/avatar-system.js`: AI 생성 `avatarUrl` 수신 시 256x256 캔버스 압축 최적화, 프리뷰 즉시 렌더링 및 프로필 영구 저장.
- `index.html`: `avatar-system.js?v=20260913-es052` 캐시 버스팅 적용 (순증가 0줄 엄수).
- `scripts/smoke-test.js`: #TASK-ES-052 멀티모달 아바타 생성 및 클라이언트 바인딩 검증 테스트 추가.
- `docs/rules/TICKETS.md`, `dev_log.md`: 정식 완료 기록.
