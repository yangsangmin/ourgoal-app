# [작업계획서] #TASK-ES-050: 아바타 생성 API 실패 시 서버문제 정중 안내 멘트 노출 및 횟수 보존 처리

## 1. 배경 및 목적
- **상민님 직접 지시**: "api가 제대로 작동 안하면 '죄송합니다. 현재 아워골 서버문제로 아바타 생성이 지원되지 못하고 있습니다.' 안내멘트 뜨게 해."
- **요구사항 분석**:
  1. API 호출 실패(네트워크 오류, HTTP 4xx/5xx, 또는 `resData.ok === false` / `resData.fallback === true` 등 실제 AI 생성 실패 시) 발생 시, 임의로 기본 아바타를 생성하지 않고 정확한 안내 문구(**"죄송합니다. 현재 아워골 서버문제로 아바타 생성이 지원되지 못하고 있습니다."**)를 사용자에게 즉시 표시.
  2. 실패 시 차감되었던 아바타 제작 가능 횟수(N/3회)를 **원복(복원)**하여 사용자의 소중한 기회를 억울하게 소진시키지 않음.
  3. 로딩 애니메이션(나무망치)을 즉시 닫고, 사용자가 다시 시도하거나 사진을 재선택할 수 있도록 UI 상태를 정상 복원.

## 2. 작업 범위
- `js/avatar-system.js`: `fetch('/api/avatar-face')` 결과 판정 로직 보강, 실패 시 문구 노출 및 횟수 롤백, UI 리셋.
- `scripts/smoke-test.js`: #TASK-ES-050 검증 항목 추가.
