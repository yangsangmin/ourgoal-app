# [작업계획서] 아워골 직관적 온보딩 및 기존 앱 320종 아바타·계정 체계 융합

## 1. 배경 및 목적
- **상민님 직접 지시**: "융합해" (온보딩 프로토타입의 직관적 장점과 기존 아워골 앱의 320종 아바타·계정 인프라 장점을 실서비스 코드베이스로 융합)
- **상민님 핵심 UX 원칙 반영**:
  1. *"30초 초저문턱 이런 표현은 어울리지 않음"*
  2. *"'성향에 맞는 기질을 탭하면 4마리씩 직관적으로 비교할 수 있습니다'를 'MBTI(본인성향)에 맞는 동물을 선택하세요! 추후 언제든지 변경할 수 있습니다'로 변경"*
  3. *"(자율 스킵 가능) 문구 불필요"*
  4. *"성소, 콕핏 표현 영구 삭제. 각 탭을 설명할 때 뒤에 각 탭의 화면들을 볼 수 있어야 이해하기 쉬움. 블러로 가리지 말 것"*
- **융합 설계**:
  - 기존 앱(`index.html` 6524~6736 라인)의 무거운 4단계 폼(`1/4 ~ 4/4`)을 프로토타입의 직관적 [4대 기질 16종 동물 비교 ➔ 닉네임 입력 ➔ 첫 시작 완성] 인터페이스로 교체.
  - 백엔드/로직은 기존 `avatar-system.js` 320종 동물 생성기 및 `auth-safety.js` 게스트 무손실 세션 파이프라인 100% 직결.
  - 온보딩 직후 가이드는 `tab-guides.js`의 무블러(Zero Blur) 4대 탭 투명 라이브 프리뷰로 융합.

  - MBTI 4대 기질(분석형, 외교형, 관리형, 탐험형) 16종 대표 동물 4분할 비교 UI 탑재.
  - 동물 선택 시 해당 아바타 실시간 프리뷰 렌더링.
