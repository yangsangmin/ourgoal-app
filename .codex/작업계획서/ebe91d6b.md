# 아워골 기록탭 '데이터 가져오기 & 1초 샘플' 전면 진단 및 무결성 개편

목표: 상민님 지시에 따라 '데이터 가져오기 & 1초 샘플' 모달의 5대 핵심 결함(샘플 카드 클릭 시 하단 버튼 스크롤 가림 및 무반응 체감, 원클릭 1초 즉시 로드 부재, CSV/텍스트 파서의 실시간 테이블 미리보기 부재, 샘플 데이터 일괄 되돌리기/정화 안전망 부재, 52주 날짜 현재 시점 연동)을 완전히 진단·개편하여 완벽한 사용자 경험과 무결성을 달성.

## 마일스톤 및 안전 분할 계획
- **Phase 1 [1단계: 기획·설계 상태]**: REQ-IMPORT-AND-SAMPLES.md 및 PLAN-IMPORT-AND-SAMPLES.md 수립, .Codex 작업계획서 및 컨트롤타워 연계.
- **Phase 2 [2단계: 내부 시뮬레이션 상태]**:
  - `openUniversalImportModal` UI 개편:
    1. 각 샘플 카드 내에 `[⚡ 1초 만에 담기]` 원클릭 다이렉트 버튼 탑재 (2중 스크롤 마찰 해소).
    2. 카드 선택 시 고시인성 하이라이트(브랜드 컬러 테두리 + 체크 배지).
    3. CSV 및 텍스트 탭에 실시간 상위 5행 데이터 테이블 미리보기(Table Preview) 탑재.
    4. 샘플 데이터 메타데이터(`isSample: true`, `sampleCategory`) 태깅 및 '샘플 데이터만 초기화(되돌리기)' 원클릭 안전망 탑재.
    5. 52주 파워리프팅 및 추천 샘플 날짜를 오늘 기준으로 자동 리베이스(현재 1년 필터에서 바로 보이도록 보정).
  - 단위 및 라이프사이클 테스트 작성 및 `npm test` 통과.
- **Phase 3 [3단계: 로컬 수동 확인 상태]**: `localhost:8000`에서 샘플 1초 로드, CSV 파일 드롭, 텍스트 파싱, 통계 뷰 즉시 표출, 샘플 되돌리기 실동작 확인.
- **Phase 4 [4단계: 로컬 메인 병합 상태]**: 피처 브랜치 main 병합 및 충돌 마커 0건 검증.
- **Phase 5~6 [5~6단계: 배포 및 실운영 최종 확인]**: 상민님 승인 후 프로덕션 배포.

## 막히는 지점 예상 (문제해결 8원칙 ⑧)
- **막힐 지점 1 (샘플 데이터와 실제 유저 데이터 혼동)**: 샘플을 넣었다가 지우고 싶을 때 개별 삭제하기 어렵고 유저의 실제 기록이 섞여 손실될 위험 -> `isSample: true`, `sampleType` 메타데이터를 필수 주입하고, 기록탭 상단 또는 통계 콕핏에 `[🧹 샘플 데이터만 정리하기]` 원클릭 안전망을 제공하여 실제 유저 데이터는 1바이트도 건드리지 않고 샘플만 깔끔하게 청소.
- **막힐 지점 2 (날짜가 2025년 초라 콕핏에서 안 보임)**: 고정된 과거 날짜로 샘플이 들어가면 기본 1M/3M/1Y 슬라이서에서 필터링되어 차트가 빈 화면으로 뜸 -> 오늘(now)을 종점으로 52주 전부터 오늘까지 매주 점진적으로 상승하도록 동적 날짜 계산식 일원화.
- **막힐 지점 3 (모달 내 하단 버튼 스크롤 숨김)**: 모바일 뷰포트에서 내용이 길어질 때 하단 액션 바가 아래로 밀려 안 보임 -> 플로팅 고정 하단 바(Sticky Footer) 및 각 카드 우측에 `[⚡ 1초 로드]` 즉시 실행 버튼을 배치하여 스크롤할 필요 없이 1터치로 완결.
