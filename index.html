📅 구글 캘린더 연동

Google Cloud Console에서 발급한 내 OAuth 클라이언트 ID를 붙여넣으세요. 이 값은 이 기기에만 저장돼요. ① console.cloud.google.com에서 프로젝트 생성 ② "Google Calendar API" 사용 설정 ③ OAuth 동의 화면 구성 ④ 사용자 인증 정보에서 "OAuth 클라이언트 ID"(웹 애플리케이션) 생성, 승인된 자바스크립트 원본에 이 사이트 주소 추가 ⑤ 발급된 클라이언트 ID를 여기에 붙여넣기.
