외부 연동

Notion 자동 동기화
맞춤 템플릿 저장 시 노션 DB로 자동 전송

API Key와 Database ID를 등록하면 전문 템플릿 표 기록이 노션 데이터베이스의 실제 표 페이지로 자동 전송됩니다.

💡노션 4단계 초간편 연동 가이드
  1. 노션 내 통합(Integrations) ↗에서 [새 통합 만들기] 클릭
  2. 발급된 내부 통합 시크릿(secret_...)을 위 API Key에 붙여넣기
  3. 연동할 노션 DB 페이지 우측 상단 ··· ➔ [연결(Connections)]에서 방금 만든 통합 추가
  4. 노션 DB 페이지의 웹 주소(전체 URL)를 복사해 위 Database ID에 붙여넣기 (자동 정규화)
Notion 바로 열기 ↗ Notion API/웹훅 연동 관리 ↗
