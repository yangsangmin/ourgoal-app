# 본질 게이트 (안티그래비티 워크스페이스 규칙)
규칙 원본은 저장소 루트 `AGENTS.md`다. 이 파일은 그 요약이며, 충돌 시 AGENTS.md가 우선한다.
- 착수 전: 티켓(본질 축 E1/E2/E3/INFRA/FIX · 체감 가설 · 근거) 확인. 없으면 구현하지 말고 제안만 적재.
- 브랜치에서 작업, PR로 올린다. main 직접 커밋 금지.
- 커밋: `[태그] #티켓 설명`. 절대 금지 9대 행위(헌법 제4조)·승인선 8대 통제(필수 5 + 추가 3, 헌법 제5조) 준수. 화면 문구에 '노션 DB' 같은 도구 언어 금지. 실데이터 없는 순위·인원·포인트 표시 금지.
- 무개입 세션: 통과 티켓만, 커밋 8건 이내, 새 아이디어는 제안만. 줄 수의 인위적 한도는 없다(헌법 제5조 제3항).
- 나는 주장만 쓴다. 합격·완료는 GitHub 에서 도는 법정(court) 한 곳만 말한다. 내 세션에서 돌린 법정 출력은 예비 점검이며 "막힌 것"만 옮겨 적을 수 있다.
- 못 잰 것은 확인 못 함이라고 쓴다(위반 아님). 수치·로그를 지어내거나 예시 문구를 붙이면 위반이다. PC 화면에서 눌러 보면 되는 종류를 재지 않고 확인 못 함으로 내면 돌려보내진다.
- 보고의 첫 블록은 `node court/chat.js <PR>` 출력 그대로. 그 위에 아무것도 쓰지 않는다. 심사를 청구했으면 court 검사가 끝날 때까지 기다린다.
- 돌려보내지면 멈추지 말고 고쳐서 재심한다. 한 PR 에서 돌려보냄이 3회 누적되거나 승인선에 걸릴 때만 [결심 필요]. 새 PR 로 다시 낼 때에는 PR 본문 블록 1에 앞선 PR 번호를 적는다. 한 변경에 주장 파일은 하나다.
