## 1. [원칙 ①] 문제 정확히 파악 (Problem Identification)
- **상민님 지시 원문**:
  > "추천샘플에 테마별로 모아서 볼 수 있게 해줄래? 예를들어 운동이면 하이록스, 헬스, 요가 등 사람들이 최근에 많이 하는거 테마별로 7가지씩 한눈에 너무 많이보이면 안되니까 효과적인 ui ux 기법 적용해서"
- **현재 발생하는 문제 및 한계**:
  1. 현재 데이터 가져오기 모달 내 추천 샘플 목록이 세로 나열형(영업, 개발, 공부, 재테크, 파워리프팅, 1924 올림픽, 러닝, 독서 등 8개)으로 단순 나열되어 있어, 사용자가 원하는 테마(예: 최근 대세인 하이록스, 요가/필라테스, 크로스핏 등)를 집중해서 탐색하기 어렵다.
  2. 한 화면에 수십 개의 샘플 카드가 한꺼번에 쏟아져 나오면 스크롤 압박과 선택 마비(Choice Overload)가 발생하여 직관성이 훼손된다.
- **사용자 상황 및 페르소나**:
  - 첫 방문자 혹은 신규 유저가 아워골의 프로페셔널 통계 콕핏을 체험하기 위해 샘플을 둘러볼 때, 자신이 실제 실천하는 최신 트렌드 운동(하이록스, 헬스, 요가 등)이나 업무/공부/재테크/웰니스 테마를 한눈에 파악하고 1초 만에 융합하고자 함.

## 2. [원칙 ②] 본질 · 원인 · 중심 · 핵심 파악 (Root Cause & Essence)
- **근본 원인**:
  - 샘플 카탈로그의 분류 체계가 플랫(Flat)하여, 카테고리별 전문성이 드러나지 않고 시각적 밀도가 비효율적으로 분산됨.
- **본질 축 (Essence Axis)**: `[E2]` 5단위 회고 및 유니버설 성취 통계 콕핏 자율 데이터 융합 UX
- **체감 가설 (User Experience Hypothesis)**:
  > *"사용자가 [데이터 가져오기 모달]에 진입했을 때, 상단의 [테마 칩(운동 7, 업무 7, 공부 7, 재테크 7, 웰니스 7 등)]을 가볍게 탭하면, 해당 분야의 최신 유행 실천 종목(하이록스, 헬스, 요가, 마라톤 등) 7가지가 정갈한 컴팩트 카드로 딱 맞게 표출되어 1초 만에 흥미를 느끼고 로드할 수 있다."*
- **기존 전체 기능 영향도 분석**:
  - 계정/로그인(세션, 게스트, 소셜): 영향 없음.
  - 기존 샘플 융합 엔진(`executeImport`, `isSample` 태깅, 정화 안전망 `uSamplePurgeRow`): 100% 호환 보존.
  - CSV 가져오기 / 텍스트 붙여넣기 탭: 100% 온전 보존.

  - **📖 공부·학습 (7종)**:
    1. 공무원/전문직 순공, 2. 토익/어학 시험, 3. 알고리즘 코딩테스트, 4. 주간 독서, 5. 기사/전문 자격증, 6. 악기/피아노 연습, 7. 대학원 학술 논문

- **FR-02 (효과적 UI/UX 기법 - 2중 탭 & 컴팩트 그리드)**:
  - 상단에 가로 스크롤 가능한 **세련된 테마 칩 바** (`🏃 운동 (7)`, `💼 업무 (7)`, `📖 공부 (7)`, `💰 재테크 (7)`, `🧘 웰니스 (7)`).
  - 테마 선택 시 스크롤 부담 없이 7개 카드가 정갈한 1~2열 반응형 컴팩트 카드로 전환.
  - 한눈에 너무 많은 정보가 쏟아져 나오지 않도록 폰트 계층과 여백을 최적화.
- **FR-03 (원터치 1초 로드 & 프리뷰 연계)**:
  - 각 카드 우측에 `[⚡ 1초 로드]` 버튼 배치 ➔ 1회 탭으로 52주 실전 데이터 즉시 융합.
  - 카드 본체 탭 시 하단에 모노스페이스 실시간 테이블 미리보기 표출 ➔ `[기록에 융합하기]` 버튼 활성화.
