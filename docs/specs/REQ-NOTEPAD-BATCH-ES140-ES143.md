## 2. [원칙 ②] 본질 · 원인 · 중심 · 핵심 파악 (Root Cause & Essence)

### 1) 기술적 근본 원인
1. **목표 탭 일정 설정 부재**:
   - `state.goalEditMode`가 켜져 있을 때만 `<input type="datetime-local">`이 노출되어 일반 사용자 모드에서 일정을 설정하거나 기간을 볼 수 없음.
2. **나만의 홈 구성 괴리**:
   - `js/customize.js` 화이트리스트에 이미 삭제된 `quickRoutineRow`가 남아 있고, 최신 UI 명칭(`오늘의 카드`, `이번 주 히트맵 요약`)과의 불일치 존재.
3. **구글 캘린더 재연동 풀림**:
   - 구글 OAuth 토큰을 `sessionStorage`에만 저장하고, 앱 로드 시 `getItem`으로 복원하는 코드가 전무하여 브라우저 재시작 시 메모리 토큰이 날아감. 토큰 부재로 매번 `prompt: 'consent'` 창이 강제 호출됨.
4. **AI 장애 및 보안 취약성**:
   - Gemini API 실패 시 일부 엔드포인트에서 에러 메시지만 노출되거나 지연 발생. 로컬 스마트 룰베이스 폴백 완비 필요.

### 2) 본질 축 (Essence Axis)
- **#TASK-ES-140**: `E1` (목표 실천 및 캘린더 일정 연계)
- **#TASK-ES-141**: `E1 / UX` (홈 화면 맞춤형 제어)
- **#TASK-ES-142**: `INFRA / FIX` (구글 캘린더 세션 영속화)
- **#TASK-ES-143**: `INFRA / SEC` (AI 안전망 및 보안 무결성)

## 3. [원칙 ③] 효과적 · 효율적 해결방식 결정 (Functional Specifications)

### 3-1. 세부 기능 요구사항 (FR)
- **FR-140-1 (3계층 일정 버튼)**:
  - 목표 헤더, 마일스톤 행, 할 일 행의 달력 아이콘 좌측에 `schedule-pill` 배치.
  - 일정 미설정 시: `[일정설정]` 텍스트 버튼.
  - 일정 설정 완료 시:
    - 하루 일정/마감일: `[D-X]` 또는 `[D-Day]`
    - 시작일~종료일 기간 일정: `YYYY.MM.DD~YYYY.MM.DD` 포맷으로 명시.
  - 클릭 시 `openScheduleSetupModal(type, targetId)` 모달이 뜨고 시작일/종료일/시간을 선택하여 저장할 수 있음.
- **FR-140-2 (캘린더 양방향 연동)**:
  - 저장된 일정은 목표/마일스톤/할일 속성에 저장됨과 동시에 `customSchedules` 및 캘린더 화면(월간/주간/일간 타임테이블)에 즉시 양방향 반영.
- **FR-141-1 (홈 구성 화이트리스트 최신화)**:
  - `js/customize.js` 내 유효하지 않은 `quickRoutineRow` 정리, `todayMissionCard` 라벨을 상민님 공식 원문인 `오늘의 카드`로 동기화.
  - 실제 홈 화면의 위젯들과 1:1 완벽 일치 보장.
- **FR-142-1 (구글 토큰 영속화 & 무음 복원)**:
  - 토큰 획득 시 `localStorage.setItem('ourgoal_gcal_token_v1', ...)`에 만료 시각(`expiresAt`)과 함께 저장.
  - 앱 초기화(`initApp`) 시 저장된 토큰이 유효하면 `state.googleToken`으로 즉시 복원.
  - 이미 연동된 유저는 재로그인/새로고침 시 동의창 없이 백그라운드 무음 갱신.
- **FR-143-1 (AI 장애 룰베이스 폴백)**:
  - API 호출 실패나 3초 이상 지연 시 즉시 로컬 룰베이스 지능 알고리즘으로 자연스러운 한국어 조언/미션을 즉시 공급하여 무한 로딩 차단.

### 3-2. 전수 인터랙션 명세표 (Zero Dead Click)
| UI 요소 | 위치 | 사용자 액션 | 기대 동작 | 예외 처리 |
|:---|:---|:---|:---|:---|
| `.schedule-pill` | 목표/마일스톤/할일 행 | 클릭 | 일정 설정 모달 팝업 | 잘못된 날짜(시작>종료) 경고 안내 |
| `#btnSaveSchedule` | 일정 설정 모달 | 클릭 | 목표/캘린더 데이터 동시 저장 및 즉시 리렌더 | 저장 후 자동 모달 닫힘 및 성공 토스트 |
| `#homeLayoutOpenBtn` | 설정 / 홈 상단 | 클릭 | 나만의 홈 구성 모달 팝업 | 토글 즉시 display 제어 반영 |
| `#gcalQuickConnectBtn` | 설정 캘린더 연동 | 클릭 | 구글 로그인 및 토큰 영속화 | 실패 시 인라인 한국어 안내 |

### 3-3. 유저 데이터 100% 무손실 보존 규격
- 기존 아바타, 목표, 마일스톤, 할일, 기록, 세팅값 100% 보존.
- 일정 데이터는 기존 `dueDate`에 더해 `startDate`, `endDate` 옵션을 호환성 있게 추가(Non-destructive).
