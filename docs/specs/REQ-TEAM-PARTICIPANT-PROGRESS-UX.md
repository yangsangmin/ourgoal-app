# 요구사항 정의서: #TASK-ES-111 참가 팀원 달성현황 UI 효율화 및 1열 가로 인라인 컴팩트 개편

## 1. 개요 및 배경
- **문제 진단**: 팀 목표 카드 내 👥 참가 팀원 달성 현황에서 사용자와 역할명, 진행상태 설명(마일스톤 2/4 완료)이 세로로 2단 줄바꿈되어 과도한 세로 공간을 낭비하고 정보 밀도가 떨어짐.
- **요청 사항**: 상민님 직접 지시(참가 팀원 달성현황 창이 너무 비효율적이고 사용자와 역할명, 진행상태설명이 세로로 나와있어 해결해).

## 2. 핵심 요구사항
1. **1열 가로 인라인 정돈**:
   - [아바타] [이름] [역할뱃지] · [마일스톤 X/Y]를 1행으로 가로 배치하여 시각적 연속성과 컴팩트함 확보.
   - 역할명 뱃지는 가볍고 산뜻한 마이크로 뱃지(.p-role-badge)로 표현.
2. **달성률 & 게이지 바 & 액션 버튼 슬림화**:
   - 우측의 달성률(xx%)과 미니 바, 액션 버튼(⚡ 찌르기, 💬 댓글, ✉️ DM 또는 내 목표)을 슬림한 수평 정렬로 배치.
   - 터치 타겟은 유지하면서도 패딩과 여백을 최적화하여 1인당 카드 높이를 48px 이하로 슬림화.
3. **참가 팀원 달성현황 섹션 아코디언화**:
   - 헤더 [👥 참가 팀원 달성 현황 (N명) ▼] 클릭 시 접기/펼치기 지원.
   - 팀원이 다수이거나 카드 시인성을 극대화하고 싶을 때 원클릭으로 접어둘 수 있도록 지원.
4. **헌법 및 테스트 호환성**:
   - 기존 smoke-test.js 및 	est-team-linked-goals.js의 참가 팀원 달성 현황, data-tgpnudge, data-tgpcmt, data-tgpdm, data-gotolinkedgoal 셀렉터 100% 보존.
   - index.html 라인 수 22,196줄 불변 엄수.
