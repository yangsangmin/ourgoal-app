## 1. [원칙 ①] 문제 정확히 파악 (Problem Identification)

- **상민님 지시 원문**:
  > *"다시 노션 db들 전체 일괄 확인해. 앱 다시 확인해보니 개선이 되기는 커녕 오히려 퇴화했는데 원인 정밀분석해"*  
  > *"정상화 및 개선작업 목록을 아워골 명령입력/메모장 db에 구축해"*  
  > *"진행"*
- **현재 발생하는 문제 및 한계 (표면적 현상)**:
  1. **소통탭 8중 장벽 적층 결함**: 상단 안내 ➔ 실시간 레이더 ➔ 통계 원카드 ➔ 섹션 헤더 ➔ 서브탭 ➔ 동반자 초대/검색바 ➔ 카테고리 필터 칩 ➔ 피드로 이어지는 8중 적층으로 인해 모바일 375px 화면에서 피드 글이 첫 화면에 전혀 보이지 않는 정보 과잉 발생.
  2. **동일 기능 버튼 중복 노출**: 소통탭 상단 카드 내 `[✍️ 새 글 나누기]`와 우측 상단 헤더 내 `[✍️ 게시하기]`가 50px 간격으로 중복 배치되어 사용자 시각 피로 유발. 목표탭 빈 상태에서도 상하 2중 `+ 새 목표 만들기` 버튼 중복 노출.
  3. **모바일 375px 실기기 텍스트 줄바꿈 및 글자 쪼개짐**: 레이더 타이틀("실시간 러닝메이 \n 트"), 캘린더 잠금화면 저장 버튼("잠금화면용 일정 카드 저 \n 장"), 기록탭 히트맵 기간 필터 우측 잘림 발생.
  4. **기계적 터치 규격 강제로 인한 조형 파괴**: 검사 통과용 `min-height: 44px !important;`와 과도한 여백 압축(margin 4px)으로 인해 서브탭 버튼들이 둔탁한 블록처럼 변질.
  5. **기록탭 정보 위계 족보 꼬임**: 6대 서브탭 ➔ 365일 히트맵 ➔ 다시 돌출되는 '기록/통계' 헤더와 통계 카드 ➔ 중복 세그먼트바로 이어지는 불일치.
  6. **게스트 토스트 화면 간섭**: 첫 진입 시 하단 바텀 네비 바로 위에 토스트가 고정되어 클릭을 방해.
- **표면 아래 기저 층위 분석**:
  - **1층 (미작동/표기 결함)**: 375px 좁은 뷰포트에서 nowrap 부재로 인한 비정상 단어 쪼개짐, 불필요한 중복 버튼 잔존.
  - **2층 (구조/프로세스 부재)**: 탭 모드별 조건부 가시성 제어 부재로 인해 상위 성소 뷰와 하위 레거시 뷰가 동시 노출되는 족보 꼬임.
  - **3층 (시스템/유저 체감 괴리)**: 검사 통과만을 위한 기계적 CSS 강제로 인해 사용자에게 부자연스러운 시각적 퇴화감을 안김.
- **사용자 상황 및 페르소나**:
  - 375px 모바일 기기로 접속하여 동류들의 생생한 실천 피드를 즉각 확인하고, 깔끔한 황금비 조형 속에서 방해 없이 체크인과 회고를 남기길 원하는 보통의 사용자.

## 2. [원칙 ②] 본질 · 원인 · 중심 · 핵심 파악 (Essence, Causes, Core & Anchor)

- **본질 축 (Essence Axis)**: E1(체크인 루프), E3(동류 소통) & FIX
- **[본질] (Essence)**:
  - 이 정상화의 본질은 **"형식적 검사 통과를 위해 왜곡된 기계적 블록과 불필요한 다중 레이어 장벽을 말끔히 걷어내고, 모바일 375px 실기기에서 동류의 실천 피드와 나만의 성장 궤적이 첫 화면에 쾌적하게 닿도록 하는 조형과 타이포그래피의 온전한 회복"**이다.
  - 3대 철학 기준:
    1. **무공해성**: 불필요한 중복 CTA와 텍스트 깨짐 없는 정갈한 화면 조형.
    2. **쾌적한 접근성**: 8중 장벽 없이 탭 전환 즉시 1초 만에 확인 가능한 직통 뷰포트.
    3. **황금비 시각 비례**: 기계적 수치가 아닌 사용자의 엄지와 시선 흐름에 맞춘 자연스러운 UI 여백.
- **[원인] (Root Causes - 기저 원인 3가지)**:
  1. **원인 1 (무조건적 요소 나열)**: 소통탭에 상단 안내, 레이더, 통계, 초대바, 서브탭을 아무런 탭 분기 없이 전부 적층.
  2. **원인 2 (반응형 유동 여백 및 nowrap 결여)**: 좁은 폭에서 요소가 줄바꿈될 때 단어 단위(word-break: keep-all, nowrap) 방어가 누락됨.
  3. **원인 3 (상하 뷰 공존 방치)**: sanctuaryRecordsView가 활성화되었음에도 하위 legacy screen-head 및 recSegmentBar를 정리하지 않아 족보 꼬임 발생.
- **[중심] (Core Bottleneck & Anchor)**:
  - 소통탭 피드 진입 시 초대바(#commTopCompanionBar)는 동반자 탭으로 격리하고, 중복 버튼 제거 및 통계 카드를 슬림화하여 피드 직통 노출 보장.
  - 375px 텍스트 쪼개짐 요소(러닝메이트, 잠금화면, 히트맵 알약) 전수 nowrap/keep-all/flex:1 수복.
  - 서브탭 min-height를 38px 황금비 터치로 정돈하고, 기록탭 족보 꼬임 헤더 정리.
- **[핵심] (Critical Safety & Termination)**:
  - 367개 이상 npm test 100% 통과 유지.
  - 38대 헌법 게이트 및 838개 Zero Dead-Click 전수 무결성 보존.
  - 10종 유저 페르소나 데이터 100% 무손실.
- **체감 가설**:
  > *"사용자가 소통탭을 누르는 순간 8중 장벽 대신 시원하게 정돈된 실시간 러닝메이트와 동류들의 따뜻한 실천 피드가 첫눈에 들어오며, 텍스트 깨짐 없는 완성도 높은 모바일 조형을 체감한다."*

## 3. [원칙 ③] 효과적 · 효율적 해결방식 결정 (Effective Solutions)

- **하지 말아야 할 것 (Avoid)**:
  - 기존 필수 기능(동반자 초대, 닉네임 검색, 피드 게시, 잠금화면 카드)을 완전히 삭제하는 행위 금지 (조건부 표시 및 위계 최적화로 해결).
  - 검사 통과만을 위해 기계적 padding이나 margin을 무리하게 강제하는 행위 금지.
- **해야 할 것 (Adopt)**:
  - 소통탭 `#commHeroCard` 내 중복 버튼 제거 및 통계 카드 콤팩트 패딩(10px 14px) 적용.
  - `#commTopCompanionBar`를 `companion` 서브탭 선택 시에만 노출되도록 조건부 배선.
  - `.s-radar-title`, `.s-segment-pills`, 캘린더 잠금화면 버튼에 nowrap/keep-all 및 flex:1 반응형 배선.
  - 목표 0건 엠프티 스테이트에서 점선 알약 버튼을 생략하고 중앙 트레일 카드의 액션 버튼으로 단일화.
  - 기록탭 성소 뷰 활성화 시 중복 `#screen-records > .screen-head` 및 `#recSegmentBar` 정리.
  - 토스트 알림 클릭 즉시 닫기 인터랙션 부여.
