# REQ-TASK-ES-320: 카카오 로그인 동명이인 가입/중복 닉네임 방지 고유 태그 부여 및 동반자 핀포인트 매칭 완결

## 1. 배경 및 목적
- **출처**: 상민님 생각 메모장 [69]번 아이디어
- **원문 지시**: *"카카오톡으로 로그인 일원화 하고 닉네임은 카카오 닉네임으로 기본설정 되고 있는 것 같은데, 동명이인 가입에 대한 대책이 아직 없는 것 같음. 해결책 찾아야함"*
- **사용자 추가 지시**: *"동반자에서 어떻게 검색하고 구분할지, 어떻게 본인이 원하는 사람과 매칭하여 동반자를 맺을지에 대한 세부적인 고려도 포함"*
- **목적**:
  1. 카카오 로그인 기반 가입 시 동명이인 중복 가입으로 인한 식별 불가 문제를 디스코드/배틀넷 스타일의 4자리 고유 식별 태그(`#\d{4}`) 자동 부여 및 충돌 방지 루프로 영구 해결.
  2. 태그 분리 렌더러(`formatDisplayNameWithTag`)를 도입하여 닉네임 본체는 깨끗하게 강조하고 고유 태그는 은은한 보조 배지로 분리 표현.
  3. 동반자 검색 창에서 고유 태그 직접 검색(`#1042` 또는 `상민#1042`) 시 1명 단일 매칭 최우선 정렬 제공.
  4. 검색 결과 카드에 4대 식별 앵커 배지(고유 태그, 아바타, 관심 카테고리 칩, 실천 스트릭/레벨 배지, 한 줄 다짐)를 완비하여 동명이인 중 원하는 상대방을 오차 없이 직관적으로 식별 및 결연.

## 2. 요구사항 명세
1. **R1**: `index.html` 내 `resolveUniqueDisplayName` 함수가 카카오 로그인 가입 시 중복 닉네임을 감지하고, 최대 5회 충돌 방지 탐색 루프를 통해 고유 태그(`#\d{4}`)를 자동 부여함을 보장한다.
2. **R2**: `index.html` 내 `formatDisplayNameWithTag` 분리 렌더러가 탑재되어 기본 닉네임(`display-name-base`)과 식별 태그(`display-name-tag`)를 시인성 높은 규격으로 분리 렌더링한다.
3. **R3**: `js/team-invite-comm.js` 내 동반자 실시간 닉네임 검색에서 고유 식별 태그(`#\d{4}`) 핀포인트 입력 시 매칭된 사용자를 최우선으로 정렬한다.
4. **R4**: `js/team-invite-comm.js` 내 동반자 검색 결과 카드에 고유 태그, 아바타, 테마 칩(`u.theme`), 실천 레벨/스트릭 배지(`🔥 Lv.N · M일 연속`), 한 줄 다짐 등 4대 앵커 배지를 제공한다.
5. **R5**: `js/components.js` 내에 직통 핸들러 `handle인증_Item69Action`이 구현되어 12ms 햅틱 반응, `og_task-69_cache` 로컬 캐시 영속화, 4대 뷰 원자적 전파를 보장한다.
6. **R6**: `tests/unique-display-name.test.js` 및 `scripts/smoke-test.js` 내에 `#TASK-ES-320` 검증 테스트가 정의되어 무결점을 전수 입증한다.
7. **R7**: `docs/rules/TICKETS.md`에 `#TASK-ES-320`이 승인 티켓으로 등록되어 있다.
