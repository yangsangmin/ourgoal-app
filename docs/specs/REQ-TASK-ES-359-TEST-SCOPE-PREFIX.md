# REQ/PLAN — TASK-ES-359 시험지가 세포 파일의 L./K. 접두를 떼고 읽는다

## REQ
- 대상 파일: `scripts/smoke-test.js`
- 대상 함수: `readAppModule(f)` (신규), 합본 `html` / `APP_SRC`
- 대상 DOM ID: 없음(시험지 변경, 제품 코드 0)

## PLAN — 문제해결 8원칙
- [x] 1. 목표 정의: 탭 코드를 세포 파일로 옮겨도(동작 그대로) 기존 단언이 같은 코드를 찾게 한다. 기대값은 바꾸지 않는다.
- [x] 2. 현상 분석: 기록 탭 이전(TASK-ES-358) 뒤 smoke-test 442/443 — `[#TASK-ES-060]` 단언 `renderUniversalStatsDashboard(uDashBox, allRecs, state` 가 옮긴 줄 `allRecs, L.state` 와 불일치.
- [x] 3. 원인 추정: 이전 생성기(`docs/design/harness/module-split/gen-*.js`)는 index.html 지역 이름을 `L.<이름>`, 같은 탭 파일 호출을 `K.<이름>` 으로 바꿔 쓴다. 글자 그대로 찾는 단언은 탭마다 같은 이유로 깨진다(구조 문제).
- [x] 4. 대안 탐색: A 단언마다 두 형태 허용(탭마다 반복, 단언 수정) / B 옮긴 코드에서 접두 제거(`window.state` 사본을 읽게 되어 동작 변경) / C 시험지 합본에서 세포 파일만 접두 제거(단언 0 변경) → C 선택.
- [x] 5. 실행 계획: `OurgoalAppScope` 를 읽는 파일만 `/(^|[^A-Za-z0-9_$.])[LK]\.(?=[A-Za-z_$])/g` 로 접두 제거 후 합본.
- [x] 6. 절차 재검증 및 반론 격파: 반론① "다른 글자를 잘못 지운다" → 앞 글자가 식별자·점이면 건드리지 않아 `URL.x`·`obj.L.y` 유지, 대상은 생성기가 만든 세포 파일로 한정. 반론② "시험을 느슨하게 한다" → 단언·기대값 변경 0, main 에서 통과 수 443 그대로, 접두 제거는 생성기가 붙인 글자를 되돌릴 뿐.
- [x] 7. 즉시 실행: `readAppModule` 추가, 합본이 이를 거치게 변경.
- [x] 8. 성과 측정: main 443/443 통과 유지, ES-358 브랜치에 적용 시 442→443.
