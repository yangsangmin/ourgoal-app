## 1. [원칙 ①] 문제를 정확히 파악한다

- finalize(X9)의 전제는 IIFE 최상위 문이 「키트 손잡이 · 구역 함수 가져오기 · 구역 함수 호출문」뿐인 것이다. 상태 이전 4차(#952)가 `var state = …` · `var _promptEncyclopediaOpen = …` 를 상태 기관 정의 줄로 바꿨지만, 그 줄 둘은 IIFE 최상위에 남아 전제를 막는다.
- `state` 정의 줄 바로 다음 문이 `bootExposeAppState();`(구역 함수 — `window.state = L.state;`)다. 정의가 그 호출보다 먼저 돌아야 한다.
- `_promptEncyclopediaOpen` 의 정의 줄이 세포로 가면 무결성 게이트는 「세포의 상태 기관 호출」 갈래로 그 이름·초기값을 본다(#947).

## 4. [원칙 ④] 재검토 (반례·부작용)

- **순서** → 구역 함수 `bootAppStateObject()` 는 정의 줄이 있던 자리에서 불리고 바로 다음 줄이 `bootExposeAppState()` 다. 시점 탐침: 작업 트리에서 `state` 정의 사건이 224번 자리, `window.state` 대입 사건이 226번 자리다(사이의 하나는 그 정의가 통로에 접근자를 다는 사건). 사건 줄 전체(기준 342 · 작업 343)는 다시 달린 getter 의 노출 사건 하나를 빼면 기준과 글자 그대로 같다.
- **알고 넘어가는 차이 ① — 인라인 줄 수가 는다(577 → 581)** → 문 하나짜리 구역은 「부르는 줄 + 가져오기 줄」이 된다. 구역 둘이 4줄(정의 2 · 주석 1 · 빈 줄 1)을 빼고 8줄(머리 주석 1 · 가져오기 2 · getter expose 문 3 · 부르는 줄 2)을 더한다. 모듈 가드의 기준선은 늘어난 값을 사유 없이 받지 않는다 — `module-guard --update --reason "…"` 으로 사유를 적어 올렸다(선례 #936). **이 PR 의 값은 줄 수가 아니라 문의 종류다**: finalize 를 막는 문이 72 → 71, 정의 줄 3 → 1(남는 하나는 결심 대기인 `sb`). 는 줄 가운데 3줄(getter)은 다음 재철거가, 나머지는 finalize 가 지운다. **이 값을 치르지 않는 쪽이 낫다고 보시면 돌려보낼 지점이다**(이 PR 을 열지 않고, finalize 가 정의 줄을 다루는 길을 따로 정한다).
- **알고 넘어가는 차이 ② — 통로 getter 하나가 다시 생겼다(`isoDate`)** → `state` 의 초깃값이 `isoDate(new Date())` 를 두 번 부르고, 구역 본문은 그것을 `L.isoDate(…)` 로 읽는다. 재철거가 index.html 의 `get isoDate` 를 지운 뒤라(등록 기관이 통로에 내준다) 생성기가 getter 를 다시 달았다(#951 의 `daysFromNow` 와 같은 일). 그 노출 사건 앞뒤로 통로의 이름 수가 같고, 통로에 새로 생긴 이름 0 · 값 지문 동일이다.
- **무결성 게이트** → `_promptEncyclopediaOpen` 의 정의 줄이 세포(`js/core/boot-app-state.js`)로 간 뒤 게이트 38/38(종료 코드 0). 처음 값 false, 읽는 그리기 함수와 쓰는 단추 처리기가 기준과 같이 돈다(상태 객체 탐침).
- **같은 객체인가** → 통로의 `state` · `window.state` · 템플릿 부품의 `getState()` 가 같은 객체이고 통째 대입 왕복이 기준과 같다. 상태 객체 탐침의 기록이 기준(2회)과 작업에서 통째로 같다(이번에는 주인 표시·기관 종류도 그대로).
- **주석의 행방** → `bootAppStateObject` 의 앞 주석(다른 작업의 자리 표지 주석 한 줄 · 빈 줄)이 생성기 규칙으로 세포에 함께 갔다. 구획 주석은 그 묶음에 다른 문이 남아 index.html 에 남는다.

- **finalize 는 주석을 어떻게 다루나**: 전제 검사는 최상위 문의 종류만 본다(주석·빈 줄은 전제가 아니다). 적용하면 `<script>` 줄부터 `</script>` 줄까지를 통째로 지우고 문만 부팅 파일로 옮긴다 — 주석·빈 줄은 구획 주석까지 전부 사라진다(생성기 `runFinalize` · 설계 5.8).
