## 2. 상세 요구사항 (요구사항 8원칙 적용)

### 2.1 #TASK-ES-146: 홈 탭 최하단 <아워골 평가해주기> 고정 배너 및 90% 팝업
- **REQ-146-1**: 홈 탭 최하단에 <아워골 평가해주기> 고정 배너 노출. `customize.js`의 `CORE_IDS`에 포함하여 나만의 홈 구성에서 숨길 수 없도록 보호.
- **REQ-146-2**: 배너 클릭 시 화면 크기의 90%를 차지하는 대형 팝업 모달 노출 (`width: 90vw`, `max-height: 90vh`).
- **REQ-146-3**: 팝업 입력 항목 5종:
  1) 종합점수평가 (100점 만점 숫자)
  2) 장점
  3) 단점
  4) 추가 및 개선요청
  5) 대표에게 하고싶은 말 (`"진짜 맘대로 써주셔도 됩니다. 신고안합니다"` 플레이스홀더)
- **REQ-146-4**: 제출 시 로컬 영속화(`state.profile.settings.appEvaluations`) 및 노션/서버리스 연동.

### 2.2 #TASK-ES-147: 목표 탭 '목표만' 버튼 이격 배치 및 확인 UI
- **REQ-147-1**: 목표 탭 상단 필터 바 [기본, 마일스톤만, 할일만]과 [목표만] 버튼 사이에 상단 상세/전체접기 간격(약 14px)만큼 이격(margin) 부여.
- **REQ-147-2**: [목표만] 선택 시 내가 설정한 모든 목표를 마일스톤처럼 하위 마일스톤/진척도와 함께 수직 카드 형태로 직관적 열람 가능.

### 2.3 #TASK-ES-148: 맞춤 템플릿 스톱워치 표 시간기입 안내문구
- **REQ-148-1**: 맞춤 템플릿 스톱워치 측정 화면에 `'넣을 칸 누르고 ‘표에시간기입’누르면 바로입력됨'` 안내 문구 추가.
- **REQ-148-2**: 빈칸 클릭 후 스톱워치 값을 표 셀에 자동 주입하는 흐름의 사용자 경험 개선.

### 2.4 #TASK-ES-149: 팀목표 200% 활용 가이드 안내문구
- **REQ-149-1**: 팀목표 탭 '팀목표 200% 활용 가이드' 타이틀 우측에 3pt 축소 폰트로 `'* 팀 목표를 생성하면 사라짐'` 안내 텍스트 표시.

### 2.5 #TASK-ES-150: 아바타 레벨업 대형 팝업 및 성향 프롬프트 설정
- **REQ-150-1**: 레벨업 시 팝업창과 함께 큰 아바타 이미지(200px 이상) 노출.
- **REQ-150-2**: [SNS 공유] 버튼으로 이미지/카드 공유, [이미지 저장] 버튼으로 팝업 화면 다운로드, [확인] 닫기 버튼 탑재.
- **REQ-150-3**: 아바타 성장 성향(더 강하게, 잘생기게, 이쁘게 등) 사용자 설정 입력 칸 제공 및 유해어 필터링.
