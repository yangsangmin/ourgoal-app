## 3. [원칙 ③] 해결 방식

- 구역 감싸기(설계 3.4): 문을 순서 그대로 세포 함수 본문으로 옮기고 원래 자리에 부르는 한 줄을 둔다. IIFE 머리에서 `var bootAppConfig = _uiKit.bootAppConfig;` · `var bootTemplatePartHandles = _uiKit.bootTemplatePartHandles;` 로 가져온다.
- 세포는 하나다(`js/core/boot-app-handles.js`). 두 곳 모두 「앱이 뜰 때 다른 부품에 건네 줄 것을 마련하는 일」이고 합쳐 7줄이다. 앞선 구역 이전(#933)의 시동 세포들(`boot-early-state` · `boot-finish` 등)과 같은 자리(`js/core/`)·같은 키트다.
- **이름과 머리 설명**: 파일 이름·구역 함수 이름·머리 설명에 돈 관련 낱말을 쓰지 않았다(「템플릿 부품」 · 「앱 손잡이」로 적었다). 구획 주석 두 줄은 생성기 규칙으로 세포 **본문**에 글자 그대로 함께 갔다.
