## 1. #TASK-ES-137: AI 엔진 공통 데이터 불변 시 API 재호출 전면 차단 & KST 자정(00:00) 자동 롤오버
1. **문제 정의**:
   - 데이터가 변하지 않았는데도 탭을 이동하거나 새로고침할 때 불필요하게 AI 조언 API가 호출될 경우 과도한 비용 및 지연이 발생함.
   - 반대로 날짜가 바뀌어 새로운 날이 되었음에도 이전 피드백이 영구 고착되면 안 됨.
2. **해결 사양**:
   - `getKSTDateKey(date)` 함수 신설 (한국 표준시 UTC+9 기준 YYYY-MM-DD 산출).
   - `goalStatusSummaries` 및 `todayMissions` 캐시에 KST `dateKey`를 기록하고, 데이터 해시 일치 및 당일 유효 시 0ms 즉시 반환.
   - 한국 시간 자정(00:00 KST) 도달 시 자동으로 캐시를 만료시켜 새 하루 피드백 갱신(롤오버).

## 2. #TASK-ES-138: 캘린더 일정(customSchedules) 일간/시간표 24시간 블록 뷰 구현 및 세부 일정 저장 무결성
1. **문제 정의**:
   - 활용법 가이드(`js/tab-guides.js`)에서 약속한 "일간 시간표 뷰로 오늘 하루의 24시간 블록을 밀도 있게 계획" 기능이 일간 뷰에서 비어 있음.
   - 일정 추가/수정 후 즉각적인 상태 반영 및 타임라인 표시가 완결되어야 함.
2. **해결 사양**:
   - `renderCalendarScreen()`의 `day` 뷰에 24시간(06:00~24:00 주요 시간대) 타임라인 블록 그리드 탑재.
   - 각 시간 슬롯 클릭 시 해당 시간이 자동 채워진 `openCalendarManualEditModal` 호출.
   - 등록된 일정(시/분 포함)이 시간표 블록에 직관적으로 배치되어 시각화됨.

## 3. #TASK-ES-139: 설정창 노션 연동 6대 UX 개선 및 가이드 툴팁·URL 정규화
1. **문제 정의**:
   - 사용자가 노션 전체 DB URL을 복사했을 때 400 에러 발생.
   - 노션 내부 통합 발급 및 DB 연결 절차에 대한 친절한 온보딩 가이드 부재.
2. **해결 사양**:
   - 노션 DB ID 입력 시 32자리 UUID 자동 추출 및 정규화.
   - 노션 바로 열기 버튼 클릭 시 입력된 DB ID 기반 실제 DB 페이지로 원클릭 다이렉트 이동.
   - 4단계 친절 가이드 툴팁(통합 생성, 시크릿 토큰 복사, DB 연결 추가, URL 입력) 탑재.
   - 토큰 미입력 시 테스트 전송 에러 토스트를 지양하고 인라인 안내 박스 제공.
