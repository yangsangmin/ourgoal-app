## 1. 개요 및 배경
- **현상 및 문제점**:
  - 기존 아바타 시스템은 유저가 AI로 아바타를 제작할 때마다 최신 1개만 `settings.customAvatarUrl`에 덮어써져, 이전에 공들여 제작했던 아바타들이 모두 영구 유실되는 구조였음.
  - 최대 10회까지 제작할 수 있으나 제작 이력을 조회하거나 이전 아바타로 복귀할 수단이 전무했음.
- **상민님 핵심 지시**:
  - *"생성한 아바타들을 누적해서 확인할 수 있고 변경하면서 사용할 수 있게 해야해."*

## 2. 기능 요구사항 (Functional Requirements)

### F-1. 아바타 누적 보관함 (`settings.savedAvatars`)
1. 유저가 AI 아바타 제작을 완료하면 자동으로 보관함 배열에 누적 추가한다.
2. 각 보관 항목 규격:
   - `id`: 고유 식별자 (`ava_` + 타임스탬프 + 랜덤 문자열)
   - `url`: 256x256 표준 정규화된 아바타 이미지 DataUrl
   - `themeId`: 선택한 바디 테마 ID (1~77)
   - `themeName`: 선택한 바디 테마명 (예: 열정 러너, 비전 CEO 등)
   - `themeIcon`: 선택한 바디 테마 아이콘
   - `createdAt`: ISO 8601 제작 일시
3. 최대 보관 개수는 계정당 제작 한도인 10개까지 모두 보존.

### F-2. 아바타 서랍 UI 및 시각화
1. 아바타 모달 상단/탭 영역에 '내 아바타 서랍' 섹션을 제공하여 누적된 아바타들을 썸네일로 가로 스크롤 카드 또는 그리드로 직관적으로 노출한다.
2. 현재 프로필에 적용되어 있는 아바타 카드에는 `[착용 중]` 녹색 뱃지와 하이라이트 테두리를 표시한다.
3. 테마 아이콘, 테마명, 생성 일시를 한눈에 볼 수 있도록 표시한다.

### F-3. 자유로운 원클릭 변경 및 착용 (0회 차감)
1. 보관함에서 원하는 아바타 카드를 클릭하면 상단 메인 미리보기가 즉각 해당 아바타로 전환된다.
2. `[이 아바타 착용하기]` 버튼을 누르면 잔여 제작 횟수 차감 없이 즉시 프로필 및 상단바/레벨뱃지에 반영된다.
3. 기존 로봇 아바타로의 복귀 옵션도 완벽하게 지원한다.

### F-4. 자가 치유 및 하위 호환성 (Zero Data Loss)
1. 기존에 이미 단일 `customAvatarUrl`만 가지고 있던 기존 사용자가 앱에 접속하면, 보관함이 비어있을 경우 기존 아바타를 1번 보관 아이템으로 자동 복원(Self-Healing Migration)한다.
2. 게스트 모드에서 아바타를 제작한 후 소셜 로그인으로 전환할 때도 `savedAvatars` 목록 전체가 새 계정으로 100% 무손실 복제 승계된다.
