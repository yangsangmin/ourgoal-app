# 요구사항 정의서 — #TASK-UIUX-PHASE1-GLOBAL-SHELL

## 1. 개요
- **티켓**: `#TASK-UIUX-PHASE1-GLOBAL-SHELL`
- **제목**: [UI/UX 틀 개편 Phase 1] 글로벌 셸 & 모바일 네비게이션 프레임워크 8대 과업

## 2. 요구사항 (Requirements)
- **R1**: 모바일 뷰포트(375~430px) 고정 및 100dvh 반응형 셸과 52px 초슬림 헤더가 구현되어 있음을 보장한다.
- **R2**: iOS/Android 노치 및 하단 홈바 Safe-Area 완전 자동 보정과 하단 블러 글래스모피즘 탭바 및 활성 탭 인디케이터가 구현되어 있음을 보장한다.
- **R3**: 탭별 독립 스크롤 위치 영속 메모리(Scroll Position Memory)와 온라인/오프라인 네트워크 상태 인디케이터가 배선되어 있음을 보장한다.
