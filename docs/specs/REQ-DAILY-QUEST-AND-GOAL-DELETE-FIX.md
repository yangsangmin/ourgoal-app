# [REQ-DAILY-QUEST-AND-GOAL-DELETE-FIX] 오늘의 3대 데일리 퀘스트 고도화 & 목표 삭제 부활 버그 근본 해결 요구사항 정의서 (#TASK-ES-099)

## 1. 문제 해결 8원칙 1회차 적용 (요구사항 단계)

### ① 문제정의
1. **홈탭 '오늘 달성 레이스'의 허구성**: 백엔드 연동이나 실제 점수 계산 없이 점수 0, 게이지 0, 토스트만 띄우는 껍데기(더미 목업)로 남아있어 화면을 낭비함.
2. **'오늘의 퀘스트'의 부실함**: '오늘 할 일'이 아니라 전체 마일스톤 누적 수치를 잘못 표기하고 있으며, 구체적 퀘스트 리스트가 없고 EXP/레벨 보상감이 결여됨.
3. **목표 삭제 후 새로고침 부활 버그 (치명적 데이터 버그)**: 목표 편집 화면에서 목표를 삭제해도 새로고침 시 `ourgoal_guest_profile` 미동기화, `ourgoal_goals_backup_` 잔류 및 자가치유(Self-Healing) 과잉 복구, `loadProfile` 서버 덮어쓰기 등으로 삭제된 목표가 도로 살아나는 치명적 현상 발생.

### ② 본질
- **목표 삭제 본질**: 유저가 삭제를 확정(`confirm`)한 데이터는 세션 메모리, 로컬 스토리지 정본, 삼중 백업, 서버 DB 모든 계층에서 즉시 **완전 소멸(Zero Phantom Data)**되어야 하며, 새로고침 시 절대 부활하지 않아야 한다.
- **데일리 퀘스트 본질**: "오늘 내가 무엇을 해야 하는지(3대 핵심 액션)"가 한눈에 보이고, 액션 완료 시 실시간으로 체크되며 레벨/경험치(+EXP)가 차오르는 **직관적 게이미피케이션 동기부여 엔진**이어야 한다.

### ③ 유저 관점
- 유저가 목표를 지우면 새로고침 후에도 깨끗이 지워져 있어야 한다.
- 유저가 홈 화면에 들어왔을 때 의미 없는 더미 레이스 대신, 오늘 달성할 수 있는 3대 퀘스트와 보상이 명확히 보이고, 퀘스트를 누르면 해당 행동(기록 쓰기, 스톱워치 켜기)으로 즉시 연결되어야 한다.

### ④ 원인분석
1. `saveProfile()` 내부에서 `ourgoal_guest_profile` 갱신이 누락되어 새로고침 시 예전 프로필로 롤백.
2. 목표가 0개가 되었을 때 `ourgoal_goals_backup_`에 빈 배열이 저장되지 않고 이전 백업이 남아있어, 부트스트랩 자가치유가 이를 유실로 오인하고 강제 복구.
3. `launch.html`이 실행될 때 기존 프로필을 무조건 기본 목표 3개로 강제 덮어쓰기.
4. `renderDailyQuestBar()`가 전체 마일스톤 누적치만 계산하여 출력.

### ⑤ 지표
- 목표 삭제 후 브라우저 새로고침(F5) 시 삭제된 목표 복원 건수: **0건 (완전 소멸)**.
- 오늘의 3대 퀘스트 인터랙션 및 완료 체크 실시간 반영률: **100%**.
- 245개 자동화 테스트 및 5대 무결성 게이트: **100% Pass**.
- `index.html` 총 줄 수: **22,196줄 불변 (순증가 0줄 엄수)**.

### ⑥ 최소스펙 (MVP)
- **FR-01**: 목표 삭제 시 `state.profile.goals`, `ourgoal_guest_profile`, `ourgoal_goals_backup_`, Supabase DB 즉각 완전 동기화 및 0개 삭제 완벽 수용.
- **FR-02**: `saveProfile()` 내에 `ourgoal_guest_profile` 실시간 동기화 배선 추가.
- **FR-03**: `launch.html`의 무조건 덮어쓰기 방지 (이미 프로필이 있으면 보존).
- **FR-04**: 홈탭 '오늘 달성 레이스' 껍데기 완전 숨김/제거.
- **FR-05**: '오늘의 퀘스트'를 진짜 3대 데일리 퀘스트(체크인 +30 XP, 마일스톤 +40 XP, 시간기록 25분 +50 XP) 카드와 실시간 게이지 바로 고도화.

### ⑦ 엣지케이스
- 모든 목표를 다 지워서 0개가 되었을 때도 자가치유가 예전 백업을 부활시키지 않고 빈 상태 유지.
- 하루가 바뀌었을 때(자정 경과) 일일 퀘스트가 새 날짜 기준으로 리셋.

### ⑧ 막히는 지점 예상
- `index.html` 22,196줄 불변 제약: 코드 추가 시 불필요한 레거시 주석이나 더미 함수 공간을 치환하여 순증가 0줄을 엄격히 지킨다.
