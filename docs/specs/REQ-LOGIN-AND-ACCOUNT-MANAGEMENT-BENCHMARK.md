## 1. 개요 및 분석 배경

### 1.1 분석 목적
본 문서는 글로벌 빅테크 및 국내 최고 수준의 웹/모바일 서비스들이 공통적으로 채택하고 있는 **로그인(Authentication) 및 로그인 후 계정 관리(Account Management & Security)** 시스템을 전수 벤치마킹하여, 현재 아워골(`ourgoal-app`)에 부재하거나 고도화가 필요한 모든 기능을 체계적으로 도출하고 아워골의 3대 본질 축에 맞춘 최적의 구현 스펙을 정의함을 목적으로 한다.

### 1.2 아워골 현행 실측 진단 요약
- **현재 구현된 것**:
  - 이메일/비밀번호 가입 및 로그인 (`sb.auth.signUp`, `sb.auth.signInWithPassword`)
  - Google OAuth 로그인 (GSI 토큰 클라이언트 기반 팝업/One-Tap 브릿지)
  - Kakao OAuth 로그인 버튼 및 폴백 모달
  - 1초 빠른 시작 및 세션 복구 모달 (`landRescueBtn`, `authRescueBtn`)
  - 비밀번호 보기/숨기기 토글 (`.pw-toggle`)
  - 설정 내 2FA 토글 스위치 (단, `settings.twoFactorAuth` 불리언 저장에 불과한 UI 더미)
  - 설정 내 기기 텍스트 노출 (`현재 기기: Windows Chrome... 모바일: Android PWA` 고정 문자열)
  - 다른 모든 기기 원격 로그아웃 (`sb.auth.signOut({ scope: 'others' })` + Realtime 브로드캐스트)
  - 회원 탈퇴 (2중 confirm 후 Supabase RLS 테이블 클라이언트 `delete()` + `/api/withdraw` 즉시 영구 파기)
  - 데이터 CSV/JSON 내보내기 및 전체 백업/복원
  - 구글 캘린더 / 노션 외부 연동 및 해제
- **치명적 결함 및 누락 상태**:
  1. **비밀번호 찾기(재설정) 기능 완전 부재**: 비밀번호를 분실하면 계정을 되찾을 방법이 없음.
  2. **설정 화면 내 비밀번호 변경 기능 부재**: 로그인된 상태에서 비밀번호를 바꿀 수 없음.
  3. **'이 기기에서 로그인 유지' 미지원**: 공용 PC에서도 무조건 로컬스토리지에 영구 보존됨.
  4. **회원 탈퇴 즉시 영구 파괴(하드 삭제)**: 실수 탈퇴 시 복구 유예기간(30일) 없음.
  5. **최근 로그인 수단 뱃지 부재**: 소셜 계정과 이메일 계정을 헷갈려 중복 계정 생성 빈발.
  6. **활성 기기 개별 로그아웃 불가**: 특정 1개 기기만 골라서 세션을 종료할 수 없음.

## 2. 아워골 미구현 기능 전수 리스트 (7대 영역 · 35개 채택 기능)

### [영역 1] 로그인 & 회원가입 진입 UX (10개)

#### 1. 이 기기에서 로그인 유지 (Keep Me Logged In / Remember Me) `[P0 채택]`
- **선도 기업 레퍼런스**: Google, Naver, Kakao, GitHub, Notion
- **현황 및 문제점**: 현재 아워골은 Supabase Client 기본 설정인 `persistSession: true`로 동작하여 무조건 `localStorage`에 영구 보관됨. 공용 PC(카페, 도서관, PC방 등)에서 체크인한 후 브라우저를 닫아도 세션이 유지되어 심각한 사생활 노출 위험.
- **반영 스펙**:
  - 로그인 폼 하단에 `[✓] 이 기기에서 로그인 유지` 체크박스 기본 제공.
  - 체크 해제 시 `sessionStorage`에 세션을 저장하거나 브라우저 닫힘 감지 시 세션을 파기.
  - 마우스 호버/터치 시 "공용 기기에서는 체크를 해제하세요" 툴팁 안내.

#### 2. 아이디(이메일) 기억하기 (Remember Email/ID) `[P1 채택]`
- **선도 기업 레퍼런스**: Naver, Coupang, Netflix, Toss, Kakao
- **반영 스펙**: `[✓] 아이디 저장` 체크박스 제공. 선택 시 `localStorage`에 마스킹된 아이디 보관 및 재방문 시 자동 완성.

#### 3. 최근 로그인 수단 안내 뱃지 ("지난번 Google로 로그인하셨어요") `[P1 채택]`
- **선도 기업 레퍼런스**: 카카오, 네이버, 배달의민족, 29CM
- **반영 스펙**: 마지막 성공한 로그인 수단 상단에 `[최근 로그인]` 하이라이트 뱃지 표시로 중복 가입 및 계정 혼선 방지.

#### 4. 비밀번호 찾기 및 이메일 재설정 링크 (Forgot Password / Password Reset) `[P0 채택]`
- **선도 기업 레퍼런스**: Google, Notion, Slack, GitHub
- **현황 및 문제점**: **현재 아워골에 비밀번호 재설정 기능 완전 부재.**
- **반영 스펙**: 로그인 버튼 밑에 `비밀번호를 잊으셨나요?` 링크 -> 모달에서 이메일 입력 -> Supabase `auth.resetPasswordForEmail()` 호출 -> 이메일 수신 링크 클릭 시 '새 비밀번호 2회 입력 모달' 진입.

#### 5. 비밀번호 없는 매직 링크 로그인 (Magic Link / Passwordless) `[P2 채택]`
- **선도 기업 레퍼런스**: Notion, Slack, Medium, Substack
- **반영 스펙**: "비밀번호 없이 이메일로 바로 로그인" 링크 제공 -> `sb.auth.signInWithOtp({ email })` 호출 -> 받은 메일의 원클릭 매직 링크로 즉시 로그인.

#### 6. Apple로 로그인 (Sign in with Apple) `[P3 채택]`
- **선도 기업 레퍼런스**: Apple, Toss, 당근, Instagram, Notion
- **반영 스펙**: iOS Safari 사용자 및 PWA/앱스토어 등록 필수 조건(가이드라인 4.8) 충족, '나의 이메일 가리기' 지원.

#### 7. 패스키(Passkey / WebAuthn) 생체 인증 (Touch ID / Face ID) `[P3 채택]`
- **선도 기업 레퍼런스**: Google, Apple, GitHub, Toss
- **반영 스펙**: FIDO2 WebAuthn 기반 패스키 등록 및 원터치 생체인증 로그인.

#### 8. 비회원 둘러보기 / 1회 체험 모드 (Guest Onboarding Tour) `[P2 채택]`
- **선도 기업 레퍼런스**: Toss, Duolingo, Nike Training Club
- **반영 스펙**: 가입 전 1회 체크인 및 AI 피드백을 체험하게 한 뒤, "소중한 기록을 안전하게 평생 보관하기" 소셜 가입 브릿지로 전환 유도.

#### 9. 로그인 실패 잠금(Brute-force Throttling) 및 간이 캡차 `[P2 채택]`
- **선도 기업 레퍼런스**: Google, Cloudflare Turnstile, GitHub
- **반영 스펙**: 연속 5회 로그인 실패 시 1분간 입력 잠금 타이머, 10회 실패 시 Cloudflare Turnstile 캡차 인증 강제.

#### 10. 간편 비밀번호(PIN 6자리) 및 앱 화면 잠금 `[P3 채택]`
- **선도 기업 레퍼런스**: Toss, 카카오뱅크, 삼성노트
- **반영 스펙**: 개인적인 목표와 회고 일기를 보호하기 위해 앱 재진입 시 6자리 PIN 또는 생체인증 요구.

### [영역 2] 계정 보안 및 2단계 인증 (5개 채택 · 1개 제외)

#### 11. 실제 동작하는 TOTP 2단계 인증 (Google Authenticator 연동) `[P1 채택]`
- **선도 기업 레퍼런스**: Google, GitHub, Notion, Discord
- **반영 스펙**: Supabase MFA (`sb.auth.mfa.enroll({ factorType: 'totp' })`) 연동, QR 코드 스캔 및 6자리 OTP 입력 검증 완성.

#### ~~12. 2단계 인증 비상 복구 코드 (Backup Recovery Codes)~~ `[상민님 지시로 제외 (DROP)]`
- **제외 사유**: 4번(이메일 비밀번호 재설정), 5번(매직링크), 27번(보조 복구 이메일), 22번(다중 소셜 연동), 세션 복구 모달이 완비되어 있으므로, 10자리 복구 코드 보관 요구는 B2C 사용자에게 불필요한 인지 피로와 이탈만 초래함.

#### 13. 설정 화면 내 비밀번호 변경 (Change Current Password) `[P0 채택]`
- **선도 기업 레퍼런스**: 모든 서비스 공통 필수 기능
- **현황 및 문제점**: **현재 아워골 설정 화면에는 비밀번호를 변경하는 메뉴나 버튼이 아예 없음.**
- **반영 스펙**: 설정 > 계정 및 보안 블록에 `비밀번호 변경` 버튼 신설. [현재 비밀번호 확인] -> [새 비밀번호] -> [새 비밀번호 재입력] 3단계 폼 제공 (`sb.auth.updateUser({ password })`).

#### 14. 비밀번호 복잡도/보안 강도 실시간 측정기 `[P2 채택]`
- **선도 기업 레퍼런스**: Google, 1Password, GitHub
- **반영 스펙**: 취약 비밀번호(`1234` 등) 가입 차단, 실시간 조합 강도 바 시각화.

#### 15. 해외 IP / 타 지역 로그인 차단 설정 `[P3 채택]`
- **선도 기업 레퍼런스**: Naver, Kakao, Toss
- **반영 스펙**: Vercel Geo 헤더(`x-vercel-ip-country`)를 확인하여 대한민국 외 IP 접속 차단 및 본인 확인 메일 발송.

#### 16. 보안 활동 타임라인 및 로그인 이력(Audit Log) 조회 `[P2 채택]`
- **선도 기업 레퍼런스**: Google (보안 활동), Naver (로그인 기록), GitHub
- **반영 스펙**: 최근 30일간의 로그인 일시, 기기/브라우저, 접속 IP(마스킹) 목록 열람.

### [영역 5] 개인정보 및 프로필 관리 (4개)
