## 1. [원칙 ①] 문제 정확히 파악 (Problem Identification)

### 1-1. 상민 대표님 지시 원문
- "아워골 최근 업데이트 하면서 일정탭을 많이 이상하게 만들어놨네? 일정탭의 모든(ui, 컴포넌트, 버튼, 상호작용, 실제 동작, 사용자경험 등) 문제점을 표형태로 보고해"
- "진행"

### 1-2. 표면 아래 기저 층위 심층 분석
1. **1층 (미작동 및 2단 중복 결함)**:
   - 상단에 성소 캘린더 카드(`#sanctuaryCalendarView`)가 나오고 바로 아래에 구형 일정 헤더, 배너, 잠금화면 버튼, 일간 상세, AI 등록 카드가 줄줄이 이어붙어 한 화면에 2개의 캘린더가 2층 탑처럼 겹쳐 노출됨.
   - `[월 | 주 | 일]` 토글 버튼을 클릭해도 `ui.css` 내 `display: none !important;`로 인해 주간/일간 뷰가 전혀 나타나지 않는 Dead UI 발생.
   - 상단 달력에서 날짜를 클릭해도 하단 일간 상세 영역은 갱신되지 않는 상태 불일치 발생.
2. **2층 (구조/프로세스 부재 — 시맨틱 미통합)**:
   - 성소 테마 적용 시 기존 검증된 마크업 슬롯과 비즈니스 로직을 계승(Skinning)하지 않고, 상단에 독립된 대체 뷰를 얹은 뒤 하단 요소 일부만 CSS로 가리는 '가짜 듀얼레이어 편의주의' 개발 방식으로 인해 발생.
3. **3층 (시스템/유저 체감 괴리)**:
   - 사용자는 일정을 보거나 추가하려고 들어왔으나 화면이 조잡하게 겹쳐 있고, 버튼을 눌러도 반응이 없으며, 날짜를 바꿨는데 아래 일정이 바뀌지 않아 "앱이 망가졌다"는 극심한 불신과 인지 부하를 겪음.

### 1-3. 대상 사용자 페르소나 및 발생 상황
- **모바일/웹 사용자 페르소나**: 일정을 월간/주간/일간으로 확인하고 실천 계획을 세우려는 일반 사용자 및 학생/직장인 러너.
- **발생 상황**: 하단 내비게이션 바에서 '일정' 탭을 탭하여 진입했을 때 발생.

## 2. [원칙 ②] 본질 · 원인 · 중심 · 핵심 파악 (Essence, Causes, Core & Anchor)

### 2-1. 5대 축 귀속
- **본질 축**: **FIX (회귀 결함 복구 및 무결성 보완)** & **E1 (체크인 및 일정 실천 루프)**

### 2-2. 본질 (Essence)
- 본 작업의 본질은 **"상단 성소 뷰와 하단 레거시 슬롯으로 기형적으로 분열된 일정 탭의 DOM과 CSS를 헌법 제3조 제5항(시맨틱 통합)에 입각하여 단일하고 완결된 고품격 캘린더 경험으로 직결 복구하는 것"**이다.

### 2-3. 원인 (Root Causes - 기저 원인 3가지)
1. **[원인 1] 가짜 듀얼레이어 및 CSS 강제 은폐 (`display: none !important;`)**: 기존 뷰를 숨기고 새 뷰를 상단에 얹으면서 하단 슬롯과의 DOM 위계가 파괴됨.
2. **[원인 2] 상태 변경 시 연계 뷰 동시 전파 누락**: `selectCalDay`와 `finishPomodoroSession` 등에서 연계 뷰(`renderCalDayDetail`, `renderHome`, `renderRecordsScreen`)를 호출하지 않아 화면 간 불일치 초래.
3. **[원인 3] 컴포넌트 및 버튼의 2~3중 중복 난립**: 동일한 기능의 버튼(`+ 일정 추가`, `🖼️ 배경사진`, `📅 허브`)이 상하 뷰에 각각 별개로 렌더링되어 IA가 왜곡됨.

### 2-4. 중심 (Core Bottleneck)
- **"상단 성소 3대 모드(월간/타임라인/뽀모도로)와 하단 핵심 기능(일간 상세, 모달, 4대 뷰 전파)의 완벽한 1:1 시맨틱 통합 배선"**:
  - 모드에 맞게 레이아웃이 깔끔하게 정돈되고, 날짜 클릭 시 상하가 실시간 연동되며, 모든 버튼이 검증된 실제 비즈니스 로직과 100% 바인딩되는 것.

### 2-5. 핵심 (Critical Anchor)
- **Zero Data Loss, Zero Dead-Click, Full State Propagation**:
  - 기존 등록된 일정, 마일스톤, 사진 배경 100% 무손실 보존.
  - 모든 버튼 클릭 시 JS 에러 0건, 100% 실제 동작.
  - 4대 뷰 동시 전파로 홈/일정/기록/통계 화면 간 완벽한 일치 보장.

### 2-6. 체감 가설 (User Experience Hypothesis)
> *"사용자가 일정 탭을 열면 최상단에 깔끔한 헤더와 모드 선택기가 위치하고, 월간 달력에서 날짜를 탭하면 상단과 하단 상세 카드가 부드럽게 동기화되며, 타임라인 모드에서는 집중된 시간표가 시원하게 펼쳐지고, 모든 버튼이 군더더기 없이 즉각 반응하는 최상의 캘린더 경험을 체감한다."*

## 3. [원칙 ③] 효과적 · 효율적 해결방식 결정 (Effective Solutions)

### 3-1. 하지 말아야 할 것과 해야 할 것
- **하지 말아야 할 것 (PROHIBITED)**:
  - 기존의 검증된 일정 데이터 구조(`customSchedules`, `calendarItemsByDate`, `toggleScheduleDone`)를 파괴하거나 변경하지 않는다.
  - 임의로 기능을 영구 삭제하지 않고 정돈 및 슬롯 이식한다.
  - 가짜 토스트나 더미 핸들러를 남기지 않는다.
- **해야 할 것 (MANDATORY)**:
  - `#screen-calendar`의 최상단에 페이지 헤더(`.screen-head`)를 올바르게 배치하고, 성소 모드 바(`[📅 월간 | ⏱️ 타임라인 | 🧘 집중 타이머]`)와 시맨틱하게 결속.
  - `ui.css` 내 파괴적 `#calGrid { display: none !important; }`를 정상화하여 주간/일간 시간표 뷰 복구.
  - 날짜 클릭(`selectCalDay`) 시 상단 성소 캘린더와 하단 일간 상세(`renderCalDayDetail`)를 동시 갱신.
  - 중복 난립하던 버튼(`+ 일정 추가`, `🖼️ 배경사진`, `📅 허브`)을 성소 카드의 컨트롤 바로 통합하고 하단 중복 버튼을 단일화.
  - 타임라인에서 일정 터치 시 체크박스는 완료 토글, 텍스트 영역은 일정 수정 모달(`openCalendarManualEditModal`)이 열리도록 4위 1체 배선.
  - 타임라인 시간 하드코딩 `10:00`을 종일/시간 분기 로직으로 정상화.
  - 모바일 375px 환경에서 날짜 셀의 글자 짤림 방지: 날짜 숫자 + 멀티 인디케이터 점(도트) 중심의 세련된 조형으로 최적화.
  - 뽀모도로 완료(`finishPomodoroSession`) 시 4대 연계 뷰 동시 전파 배선.

### 3-2. 스토리지 원장화 3대 명세 (헌법 제2조 제4항 준수)
1. **1호 (원격 DB 스키마 명세)**: Supabase `custom_schedules`, `records`, `user_profiles` 테이블 구조 유지. 신규 DDL 변경 불필요(기존 스키마 100% 호환).
2. **2호 (스마트 스토리지 분기 설계)**: 캘린더 배경사진 및 첨부자산은 기존 3계층 스마트 스토리지(localStorage 메타 + IndexedDB 원본) 유지.
3. **3호 (4대 뷰 전파 배선도)**: 일정 완료/추가/수정/삭제 및 타이머 완료 시 `renderCalendarScreen`, `renderHome`, `renderRecordsScreen`, `renderStatsScreen` 4대 뷰 동시 호출.

## 4. [원칙 ④] 1~3 재검토 및 보완 (Review & Edge Cases)

### 4-1. 비판적 자기 검토 및 약점/한계 인정
- 캘린더 화면에서 모든 모드(월간/타임라인/타이머)를 하나의 화면에 담으려다 보니 CSS 제어가 복잡해질 수 있음. 이를 해결하기 위해 `activeCalMode` 상태에 따라 CSS 클래스(`cal-mode-month`, `cal-mode-timeline`, `cal-mode-timer`)를 루트 컨테이너에 부여하여 서브 슬롯들의 노출/은폐를 명확하게 선언적(Declarative)으로 제어한다.

### 4-2. 기존 기능과의 충돌 가능성 검토
- 구글 캘린더 연동, 폰 잠금화면 라이브 연동, AI 일정 등록은 아워골의 핵심 특화 기능이므로 절대 삭제하지 않고, 시각적 IA 위계에 맞게 자연스럽게 녹여낸다.
- 4대 테마(`focus-sanctuary`, `black`, `white`, `urban-city`) 및 일반 테마 모두에서 깨짐 없이 렌더링되도록 스타일 스코프를 정밀하게 정리한다.

### 4-3. 엣지 케이스 (Edge Cases)
1. **일정이 전혀 없는 날짜 선택**: 빈 상태 안내와 함께 깔끔한 `+ 일정 추가` 유도.
2. **당일 일정이 5개 이상 많은 경우**: 날짜 셀에 텍스트를 무리하게 넣지 않고 멀티 인디케이터 점과 하단 상세 카드에서 전수 스크롤 렌더링.
3. **네트워크 오프라인 상태**: 로컬스토리지 우선 저장 및 비동기 복구.

## 5. [원칙 ⑤] 해결 절차 정리 (Implementation Procedure)
