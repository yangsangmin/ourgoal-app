# [TASK-ES-058] 아워골 AI 콘텐츠 모더레이션(금칙어 차단) 및 오탐 방지 이중 방어 시스템 요구명세서

## 1. 개요 및 배경
- **작업 코드**: `#TASK-ES-058`
- **지시자**: 상민님 직접 지시 (2026-09-14)
- **핵심 목표**: 아워골의 생성형 AI 진입점(내 목표 생성하기, 내 전용 템플릿 생성하기)에 범죄, 음란, 자해 등 사회적 규범에 반하는 키워드가 입력될 경우, 불필요한 LLM 호출 및 답변 생성을 원천 차단하고, 오탐(False Positive) 가능성을 배려한 친절하고 상세한 안내를 제공하는 이중 방어선(UI + Serverless API) 체계를 구축한다.

## 2. 상민님 직접 지시 및 설계 철학
1. **차단 안내 멘트의 표준화**:
   - 주 메시지: `'아워골 내부 차단 키워드가 식별되어 생성이 거부되었습니다'`
2. **서술어 결합(끊기/치료 등) 우회 로직 배제 (2026-09-14 상민님 긴급 지시)**:
   - "서술어 결합 부분은 다시 삭제하는게 좋을 것 같은데? 오용, 남용을 확실히 막을 수 있을지 장담할 수 없어"
   - 악의적 사용자가 금칙어 뒤에 '끊기', '치료', '재활' 등 회복형 서술어를 덧붙여 우회(Prompt Injection/Jailbreak)하는 결함을 원천 방지하기 위해, **서술어 결합 예외 로직을 전면 삭제하고 금칙어 매칭 시 엄격 차단** 원칙 확립.
3. **오탐(False Positive) 발생 시 1:1 문의 채널 연결**:
   - 시스템 예외 허용 코드로 우회 구멍을 열어두는 대신, 오인 차단된 선의의 유저에게는 상민님 지시 문구를 노출하여 소통 창구로 연결:
     `"정상적인 의도의 목표/템플릿이나 시스템 오인 차단인 경우, 아워골 앱 내 [설정] 탭의 '1:1 문의 및 오류 제보를 사용하세요'."`
4. **타깃 범위의 정밀 타격 (과잉 차단 배제)**:
   - '오늘의 미션', '다음행동 추천', '비전보드/테이블'은 이미 저장된 목표를 조회하는 파생 기능이므로 제외.
   - '아바타 제작'은 사진 업로드 기반 Gemini Vision 특징점 추출 및 77종 SVG 바디 합성 방식이므로 텍스트 필터링 불필요.
   - **원천 입구인 '내 목표 생성하기'와 '내 전용 템플릿 생성하기' 2대 핵심 입구에 집중 방어선 구축**.

## 3. 세부 아키텍처 및 구현 스펙

### 3.1. 공통 모더레이션 코어 엔진 (`js/content-moderation.js`)
- **모듈 형식**: Universal Module Definition (UMD) — 클라이언트 브라우저와 Node.js Vercel 서버리스 함수에서 동일 모듈 공유.
- **차단 카테고리**:
  1. **CRIME (범죄/위법)**:
     - 마약류: 필로폰, 메스암페타민, 대마초, 대마액상, 엑스터시, 코카인, 헤로인, 케타민, LSD, 환각물질, 프로포폴 불법, 졸피뎀 대리/불법 등
     - 사기/피싱: 보이스피싱, 스미싱, 몸캠피싱, 대포통장, 대포폰, 카드깡, 전세사기, 폰지사기, 작업대출 등
     - 불법도박: 불법도박, 사설토토, 토토사이트, 사설사다리, 사설카지노, 불법홀덤, 바카라사이트 등
     - 강력범죄: 청부살인, 살인청부, 살인교사, 살해방법, 보복살인, 장기매매, 폭탄테러, 사제폭탄 등
     - 사이버범죄: 악성코드 유포, 랜섬웨어 제작, 디도스(DDOS) 공격, 해킹툴 배포, 계정탈취 등
  2. **OBSCENE (음란/성범죄)**:
     - 성착취/성범죄: 성매매, 조건만남, 원조교제, 불법촬영, 몰카, 리벤지포르노, 성폭행, 강간, n번방, 딥페이크 음란 등
     - 노골적 음란물: 음란물, 야동 유포, 포르노 제작, 야설 연재 등
  3. **SELF_HARM (극단선택/자해)**:
     - 자살 방법, 동반자살, 자해 인증/도구 등
- **오용/남용 방지**: 서술어 결합 예외 로직 없음. 명백한 불법/위해 키워드 식별 시 100% 차단.

### 3.2. 서버리스 API 2종 차단 배선
1. **`api/goalagent.js` (대화형 목표 에이전트)**:
   - `message` 수신 즉시 `moderation.check()` 실행.
   - 차단 시 Gemini API 및 `localGoalAgentFallback` 호출 없이 즉시 HTTP 400 JSON 반환:
     ```json
     {
       "error": "CONTENT_FILTER_REJECTED",
       "message": "아워골 내부 차단 키워드가 식별되어 생성이 거부되었습니다",
       "detail": "사회적 규범(범죄, 음란 등)에 부합하지 않는 키워드가 감지되었습니다.",
       "support": "정상적인 의도의 목표/템플릿이나 시스템 오인 차단인 경우, 아워골 앱 내 [설정] 탭의 '1:1 문의 및 오류 제보를 사용하세요'.",
       "category": "crime"
     }
     ```
2. **`api/goaltemplate.js` (새 목표 및 맞춤 템플릿 생성)**:
   - `query`, `prose`, `description`, `title` 등 입력값 통합 검증.
   - 차단 시 Gemini API 및 `localCustomTemplateFallback`, `localGoalTemplateFallback` 원천 차단 후 동일한 400 Bad Request JSON 반환.

### 3.3. 클라이언트 UI 이중 방어선 (`index.html`)
- `js/content-moderation.js` 로드.
- **사전 검사 (Pre-Flight Filter)**:
  - `sendGoalAgentMessage`: 전송 전 검사하여 위반 시 API 호출 없이 즉시 상세 안내 모달 노출.
  - `showNewGoalChatStep` (템플릿 만들기 버튼): 입력값 사전 검사.
  - `openCreateCustomTemplateModal` (AI 줄글 분석 버튼): 사전 검사.
- **서버 거부 응답 대응 (Post-Flight Handler)**:
  - 서버에서 `CONTENT_FILTER_REJECTED` 수신 시 로컬 폴백을 타지 않고 동일한 상세 안내 모달 노출.
