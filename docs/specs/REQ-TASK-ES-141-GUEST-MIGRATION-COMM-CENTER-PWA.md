# [REQ] TASK-ES-141: 게스트-정회원 자산 승계 무손실 방어, 소통탭 상단 배너 가운데 정렬 강화 및 PWA 3초 온보딩

## 1. 개요
- 상민님의 "모두진행" 지시에 따라 프로덕션 실측, 게스트-정회원 전환 무손실 자산 승계 결함 수술, 소통 탭 상단 배너 1:1 대칭 가운데 정렬 강화 및 PWA 3초 온보딩 검증을 포괄 집행한다.

## 2. 요구사항 (Requirements)
- **R1 (자산 승계 무손실)**: `migrateGuestDataToUser` 호출 시 `state.profile`이 초기화되지 않은 상태에서도 널포인터 예외 없이 게스트 모드에서 작성된 목표, 기록, 아바타 서랍, 구글 캘린더 연동 정보가 정회원 계정으로 100% 안전하게 합집합 병합되어야 한다.
- **R2 (소통 배너 정렬)**: 소통 탭 상단 대표 안내 문구(`#commHeadlineSentence`) 및 무공해 응원 독(`#commFloatingReactionDock`)이 모바일 390px 뷰포트 기준 좌우 1:1 대칭 정중앙에 가운데 정렬되어야 한다.
- **R3 (PWA 3초 온보딩)**: 홈 화면 추가 3초 가이드 모달(`modalPwaInstallGuide`)이 iOS 사파리 및 안드로이드 크롬 플랫폼별로 정확하게 3단계 카드뉴스를 렌더링하고, 온보딩 완료 시 로컬 플래그가 정상 기록되어야 한다.
