## 1. [원칙 ①] 문제 정확히 파악 (Problem Identification)
- **상민님 지시 원문**:
  > "아워골 모든 탭에 활용법이 중복적으로 들어가 있는데, 해결방안 표형태로 알기쉽게 정리해서 보고해. 1단계까지 진행해"
- **현상 및 현태**:
  1. 최상단 고정 헤더(Topbar)에 `#topHomeGuideBtn`("💡 활용법")이 상시 떠 있음 (#TASK-ES-118에서 모바일 스크롤 시 접근성 확보를 위해 고정).
  2. 그와 동시에 본문 영역의 각 탭 헤더(홈, 목표, 일정, 기록, 소통, 설정)마다 `[💡 이 페이지 활용법 보기]` 버튼 6종이 중복 배치되어 있음 (#TASK-ES-102에서 배치).
  3. 결과적으로 사용자가 화면을 볼 때 최상단 탑바와 바로 아래 본문 헤더에 동일한 '활용법' 버튼이 상/하 수직으로 이중 노출되어 극심한 시각적 피로도와 공간 낭비를 초래함.
  4. 특히 기록(records) 탭에서는 탑바의 '💡 활용법' 버튼을 클릭해도 `js/tab-guides.js` 내에 `records` 정의가 결측되어 있어 아무런 반응이 없는 데드클릭(Dead Click) 결함이 존재함.

## 2. [원칙 ②] 본질 · 원인 · 중심 · 핵심 파악 (Root Cause & Essence)
- **근본 원인**:
  - 기존 #TASK-ES-102(각 탭 본문 헤더에 가이드 버튼 탑재)와 후속 #TASK-ES-118(스크롤 시 미노출 문제를 해결하기 위해 탑바에 퀵 액션 영구 고정)이 순차적으로 진행되면서, 이전 단계의 본문 버튼을 정리하지 않고 상단 탑바를 추가하여 '이중 노출' 상태가 됨.
- **본질 축 (Essence Axis)**: `UX` / `FIX` / `E1`
- **체감 가설 (User Experience Hypothesis)**:
  > *"사용자는 어느 탭에서 스크롤을 내리든 항상 최상단 고정 탑바의 `💡 활용법` 버튼 하나로 현재 탭뿐만 아니라 6대 탭 전체의 활용법을 막힘없이 열람할 수 있으며, 본문 헤더 영역은 제목과 핵심 기능만 깔끔하게 표시되어 화면 집중도가 극대화된다."*

## 6. [원칙 ⑥] 단순하고 알기 쉽게 (Simplicity)
- **유저 행동 흐름 (User Flow)**:
  1. 어떤 화면에서든 상단 고정 탑바의 `💡 활용법` 클릭.
  2. 현재 머물고 있는 탭의 가이드가 즉시 펼쳐짐.
  3. 다른 탭의 활용법이 궁금하면 모달 상단의 `[ 🏠홈 | 🎯목표 | 📅일정 | ✍️기록 | 💬소통 | ⚙️설정 ]` 세그먼트 알약을 눌러 자유롭게 전환.
  4. 본문 화면은 불필요한 중복 버튼이 사라져 타이틀이 1줄로 시원하게 정돈됨.

## 7. [원칙 ⑦] 구체적인 사실과 데이터 중심 (Fact & Data)
- 모바일 뷰포트(폭 393px, iPhone 16 Pro 기준):
  - 기존: 본문 헤더에 버튼이 포함되어 타이틀 영역 가로 점유율이 85% 이상에 달해 타이틀 줄바꿈 또는 잘림 발생.
  - 개선 후: 본문 헤더 여백이 100% 확보되어 가독성 및 UI 밸런스 대폭 향상.
- 탑바 퀵액션 접근 시간: 스크롤 위치와 무관하게 0초 (언제든 1클릭).
