## 1. 8단계 문제해결 프레임워크 (헌법 제2조 준수)

### ① 고객·상민님 관점의 진짜 문제
- **상민님 지시 원문**: "화면이 복잡해. 전문가용 데이터, 점문가용 데이터 시각화가 되어야 하는건 맞는데, 인터페이스를 보고 사용법을 모르겠으면 안돼."
- **진짜 문제**:
  1. **인지 부하(Cognitive Load) 폭발**: 한 화면에 30~40개의 버튼과 엔지니어링 전문 용어(`[ANALYTICS]`, `DATA GRID`, `Linear/Norm%`, `Cross-Ratio`, `Facet Ontology`)가 무질서하게 쏟아져 나와 유저가 들어오는 순간 "어디를 보고 어떻게 조작해야 할지" 알 수 없음.
  2. **사용법 가이드의 부재**: "종목 선택 ➔ 기간 선택 ➔ 렌즈 전환"이라는 자연스러운 사용자 멘탈 모델(Mental Model)이 UI 레이아웃에 반영되지 않아 조작 순서를 직관적으로 파악하기 어려움.
  3. **전문가용 파워와 단순함의 조화 실패**: 전문가용 데이터 분석 역량(4대 렌즈, 다차원 상관비, 동적 레이더, 주기 분석, CSV 입출력)은 100% 보존해야 하지만, 화면의 첫인상은 누구나 3초 안에 바로 이해할 수 있는 정갈함이 결여되어 있음.

### ② 도메인·데이터 층위의 기술적 본질
- **본질**: **점진적 공개(Progressive Disclosure)와 시각적 계층 구조(Visual Hierarchy)의 확립**.
  - 1계층: 핵심 분석 렌즈(추세/효율/레이더/주기)와 보고자 하는 종목(칩)을 1초 만에 선택.
  - 2계층: 직관적인 한글 라벨과 친절한 1줄 가이드로 "지금 내가 무엇을 보고 있는가"를 명시.
  - 3계층: 데이터 테이블, CSV 저장, 세부 설정 등 부가 도구는 지저분한 버튼 나열 대신 `[⚙️ 데이터 관리]` 메뉴로 세련되게 수납.

### ③ 기존 코드베이스 전수 조사 & 맹점 발굴
- `js/universal-stats.js`의 `renderUniversalStatsDashboard`:
  - 헤더에 4개 버튼(`DATA GRID`, `가져오기`, `CSV`, `📸`)이 가로로 나열되어 복잡함.
  - 렌즈 바 아래 컨트롤 영역에 `mode(ALL/single/multi)` + `taxonomy` + `period(7종)` + `scale(Linear/Norm%)`이 13개 버튼으로 빽빽하게 뭉쳐 있음.
  - 종목 칩과 차원 토글이 별도 안내 없이 노출되어 사용자가 왜 눌러야 하는지 맥락을 모름.

### ④ 5대 파괴적 혁신 가설
1. **가설 1 (직관적 3단계 퀵 가이드 탑재)**: 상단에 `💡 [1] 분석 렌즈 선택 ➔ [2] 종목 탭 ➔ [3] 성장 인사이트 확인` 1줄 퀵 가이드를 배치하면 사용자가 설명서를 읽지 않아도 3초 만에 멘탈 모델을 형성한다.
2. **가설 2 (3단 정돈 레이아웃 & 점진적 공개)**: 복잡한 버튼 13개를 상단에서 걷어내고, [렌즈 탭 4종] ➔ [분석 종목 칩] ➔ [차트 및 기간 알약] 3단으로 단순화하면 시각적 피로도가 70% 이상 감소한다.
3. **가설 3 (친숙하고 전문적인 한글 라벨 단일화)**: 개발자용 영어 약어(`Linear`, `Norm %`, `DATA GRID`, `Series`)를 `실제 수치`, `상대 비교(%)`, `전체 데이터 표` 등 품격 있는 한국어로 전면 순화하여 진입 장벽을 완전히 없앤다.
4. **가설 4 (인사이트 카드 중심의 차트 피드백)**: 복잡한 텍스트 리포트 나열 대신 차트 직하단에 4대 핵심 KPI 카드(역대 최고, 성장률, 피크 유지율, 주 활동 요일)를 정갈하게 배치하여 한눈에 결과를 읽게 한다.
5. **가설 5 (데이터 관리 도구 통합 수납)**: 데이터 그리드, 가져오기, CSV 내보내기를 헤더 우측 `[📥 데이터 관리 ▾]` 모달/팝다운 메뉴로 깔끔하게 수납하여 차트 감상에 방해되는 군더더기를 100% 제거한다.

### ⑤ 최소 3가지 파격적 대안 설계 및 비교
- **대안 A (기존 UI 유지 + 툴팁 추가)**: 기존 복잡한 버튼 그대로 두고 마우스오버 툴팁만 추가. ➔ 기각 (모바일 환경에서 툴팁 확인 불가, 근본적인 인지 부하 해소 불가).
- **대안 B (기능 축소하여 차트만 1개 남기기)**: 복잡한 렌즈와 전문가 기능을 전부 삭제. ➔ 기각 (상민님 지시: 전문가용 데이터 시각화 요구에 정면 배치).
- **대안 C [선택: 프로급 분석 파워 100% 보존 + 초직관적 3단 계층화 + 점진적 수납]**:
  - 4대 렌즈(추세·효율·레이더·주기)와 정밀 온톨로지 엔진은 100% 보존.
  - UI 레이아웃을 [퀵 가이드] ➔ [4대 렌즈 탭] ➔ [종목 칩] ➔ [차트 & 기간] ➔ [4대 KPI 카드]로 재구성.
  - 데이터 그리드, CSV, 스냅샷 등 관리 도구는 `[⚙️ 데이터 관리]`로 수납.

### ⑥ 선택한 대안의 엔지니어링 구현 명세
- `js/universal-stats.js`:
  1. `renderUniversalStatsDashboard` 템플릿 구조를 3단 시각 계층으로 전면 재설계.
  2. 직관적 상단 퀵 가이드 칩 마운트.
  3. 4대 렌즈 탭에 각 렌즈별 명확한 목적 서브카피 연동.
  4. 복잡한 모드/스케일 버튼을 직관적 드롭다운 또는 차트 우상단 미니 설정으로 수납.
  5. 관리 도구들을 원클릭 퀵 메뉴(`openDataManagementMenu`)로 통합 제공.
- `ui.css`:
  1. `.u-cockpit-quick-guide`, `.u-lens-btn`, `.u-kpi-card`, `.u-mgmt-menu` 등 모던 고밀도 스타일 완비.
- `scripts/smoke-test.js` & `scripts/test-universal-stats-ux.js`:
  1. 신규 UI/UX 구조 및 버튼 상호작용 무결성 검증 추가.

### ⑧ 막히는 지점 사전 대비 (Zero Blindspot)
- **막힐 지점 1 (렌즈 변경 시 유저가 무엇을 봐야 하는지 모름)**: 렌즈를 바꿀 때마다 차트 상단에 친절한 안내 문구를 동적으로 변경 표출.
- **막힐 지점 2 (종목이 2개 이상일 때 비교 모드 자동 진입)**: 유저가 칩을 2개 이상 선택하면 자동으로 비교 모드로 전환되고 차트 축이 맞춤 조정되도록 지능형 기본값 적용.
