- **기존 전체 기능 영향도 분석**:
  - `composite3DeformedAvatar`/`BODY_THEMES_77`(외형 합성 엔진): 변경 없음. 신규 기능은 이 위에 얹는 부가 레이어.

## 4. [원칙 ④] 1~3 재검토 및 보완
- **기존 기능과의 충돌 검토**: 사진 기반 외형 생성(`composite3DeformedAvatar`)과 기간 기반 페르소나 생성(MBTI/좌우명)은 입력 소스가 다른 별개 분석이므로 병렬 수행 후 결과만 합쳐 저장 — 기존 얼굴 특징 로직은 손대지 않는다.
- **엣지 케이스**:
  - 기간을 지정하지 않고 바로 제작 클릭: 기본값(최근 30일) 자동 적용.
  - 미래 날짜 선택: 종료일이 오늘보다 미래면 오늘로 자동 보정.
  - 목표/기록은 있으나 팀 활동이 전혀 없는 사용자(개인 목표만 운영): 팀 데이터 없이 목표·기록만으로 MBTI/좌우명 생성 진행(팀은 옵셔널 입력).
  - 게스트 계정(로그인 전): 목표/기록이 로컬에만 있어도 동일하게 분석 대상에 포함.
  - Gemini 텍스트 분석 실패(네트워크/쿼터): FR-08과 별개로 "MBTI/좌우명 생성에 실패했어요, 잠시 후 다시 시도해주세요" 안내 후 얼굴 특징 기반 캐릭터 자체는 정상 생성(부분 실패 허용, 전체 제작 실패로 만들지 않음)— 실행 단계에서 세부 확정.

## 5. [원칙 ⑤] 해결 절차 정리
- 이번 요구사항은 아바타 모달(`js/avatar-system.js`) 내부에 한정되며, 목표/기록/팀 원본 데이터는 읽기 전용으로만 참조한다 — 홈/기록/통계/캘린더 등 다른 화면에는 쓰기 영향 없음.
