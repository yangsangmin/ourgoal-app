- 회의 02 의 합의가 지시의 글을 바꾸면 → 글틀만 고치고 도구를 다시 돌린다.
- 법정이 「없던 폴더에 생긴 새 파일」을 예상 밖 파일로 볼 수 있다(결심 대기 표의 알려진 결함) → 로컬 예비 점검으로 먼저 본다.
