# #TASK-ES-133 소통 탭 3대 핵심 상호작용(피드 댓글·팀 개설·마니또) 실 서버 DB 완전 배선 요구사항 정의서 (REQ)

## 1. 개요 및 배경
- **문제 진단**: 아워골 전수 압수수색 감찰에서 적발된 P0 3대 중대 결측(피드 댓글의 로컬 격리 및 타인 공유 단절, 새 팀 개설의 메모리 고립 및 타 유저 미노출, 마니또의 100% 난수 가짜 봇 시뮬레이션)을 해결한다.
- **상민님 결심**: 선택지 "1" (P0 3대 핵심 상호작용 서버 DB 완전 배선) 직접 선택 및 집행 승인.
- **최고 규범**: 헌법 제1조(본질 루프 및 UX), 제4조(가짜 구현 원천 배제), 제13조(실 사용자 계정 상호 연동), 제14조(외부 연동 E2E 무결성).

## 2. 세부 기능 요구사항 (문제해결 8원칙)
1. **[실제 피드 댓글 서버 파이프라인]**:
   - 피드 글에 댓글 작성 시 Supabase 	eam_comments (또는 eed_posts.extra.comments 실시간 동기화)에 실제 insert.
   - 글 작성자 및 다른 모든 실사용자가 피드 글을 열람할 때 서버의 실제 댓글 목록을 조회하여 화면에 렌더링.
   - 가짜 AI 페르소나 자동 답글은 실사용자 글에서 전면 배제하고, AI 글인 경우에만 [🤖 AI 페르소나] 투명 공지 명시.
2. **[실제 팀/모임 개설 및 전역 공유 파이프라인]**:
   - + 팀 만들기 실행 시 로컬 MOCK_GROUPS 배열뿐만 아니라 서버리스/원장 파이프라인(pi/track.js 또는 	eams 원장)에 팀 데이터를 영구 등록.
   - 다른 모든 사용자가 소통 탭 [모임·팀] 서브탭에 진입했을 때 실사용자가 개설한 팀이 실제로 노출되고, 원클릭 참여 및 인원 카운트 동기화 지원.
   - 새로고침 시에도 개설된 팀이 영구 보존되는 자가 치유(Self-Healing) 파이프라인 구축.
3. **[진짜 마니또 익명 응원 및 투명성 배선]**:
   - 100% 난수 시드 가짜 봇을 근절하고, 실제 가입 유저 풀을 기반으로 관심사 매칭.
   - 마니또 응원 스탬프 및 메시지 전송 시 실제 	eam_ping_replies 익명 파이프라인으로 전송되어 상대방의 마니또 편지함(manitoInbox)에 실시간 도착.
   - 콜드스타트 가상 유저인 경우 헌법 제13조 제3항에 따라 [🤖 AI 동반자] 투명 뱃지 표기.
4. **[Vercel Hobby 12개 함수 한도 사수]**:
   - 신규 함수 파일을 추가하지 않고 기존 12개 엔드포인트(예: pi/track.js 또는 pi/push-subscribe.js) 내 서브라우팅 또는 클라이언트 Supabase 직접 연동으로 12개 한도 엄격 준수.
