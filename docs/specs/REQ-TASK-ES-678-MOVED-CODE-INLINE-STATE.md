## 3. [원칙 ③] 해결 방식

- `inlineScripts(root)`: index.html 에서 `src` 없는 `<script> … </script>` 를 모은다. HTML 주석은 같은 길이의 빈칸으로 바꾼 글자에서 찾으므로 주석 안의 스크립트는 읽지 않는다. `type` 이 자바스크립트가 아닌 스크립트(템플릿·JSON)는 실행되지 않으므로 읽지 않는다.
- `stateDefines(name, root)`: 세포 파일 목록 뒤에 인라인 스크립트를 이어 붙여 **같은 고리**를 돈다. 조건은 세포 파일과 같다 — 상태 기관 태그보다 뒤에 있고, `@babel/parser` 로 읽은 나무에서 `window·global·globalThis.OurgoalAppState.define|defineVar('이름', 초기값)` 호출을 찾는다. 찾은 자리는 `file: 'index.html(인라인)'` 로 적는다.
- 초기값 맞대기(`textOrStateDefined`)는 그대로다(공백과 이름 접두 `L.` 만 떼고 글자가 같아야 한다).
- 금고 게이트는 이미 `MOVED.textOrStateDefined(…)` 를 부른다(#947). 도우미만 고치면 게이트의 그 줄이 넓힌 판정을 쓴다.
