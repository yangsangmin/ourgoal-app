## 1. [원칙 ①] 문제 정확히 파악 (Problem Identification)
- **상민님 지시 원문**: "데이터 가져오기&1초샘플 현재 문제가많아 진단해서 고쳐보자"
- **현재 발생하는 문제 및 한계**:
  1. **스크롤 가림 및 Dead Click 체감**: 샘플 모달에 카드가 8개 이상 나열되어 있어, 모바일이나 일반 화면에서 카드를 클릭해도 하단의 미리보기 박스와 [융합하기] 버튼이 스크롤 아래로 밀려 있어 화면에 아무 변화가 없는 것처럼 느껴짐.
  2. **선택 피드백 부재**: 카드를 클릭했을 때 카드가 선택되었는지 시각적 강조(테두리, 체크 뱃지 등)가 전무함.
  3. **2중 스크롤 마찰**: '1초 샘플'이라는 명칭과 달리 카드를 탭하고 맨 아래로 스크롤하여 별도 적용 버튼을 또 눌러야 하는 불필요한 번거로움.
  4. **파서 미리보기 부재**: CSV 파일 업로드 및 텍스트 붙여넣기 시 파싱된 데이터가 어떤 컬럼/값인지 표 형태로 사전에 검토할 수 없음.
  5. **샘플 데이터 제거/되돌리기 안전망 부재**: 샘플 52~156개가 들어가면 유저의 실제 기록과 섞여버려, 샘플만 쏙 골라 삭제할 수 없고 중복 누적 시 데이터가 오염됨.
  6. **날짜 괴리**: 52주 파워리프팅 등이 고정된 2025년 과거 데이터로 생성되어 현재 시점 기준 통계 차트에서 기간 밖으로 밀려남.
- **사용자 상황 및 페르소나**:
  - 첫 방문자 혹은 데이터가 없는 유저가 아워골의 프로급 다차원 콕핏 차트를 즉시 체험하고자 할 때.
  - 본인의 엑셀/CSV 기록(영업, 커밋, 공부, 운동)을 가져와 통계로 분석하고자 할 때.

## 2. [원칙 ②] 본질 · 원인 · 중심 · 핵심 파악 (Root Cause & Essence)
- **근본 원인**:
  - 모달 레이아웃이 상하 길게 늘어지는 구조인데 액션 버튼이 맨 밑(Footer)에 위치함.
  - 각 카드 단위의 직관적인 다이렉트 실행 버튼(`[⚡ 1초 로드]`) 부재.
  - 샘플 데이터와 실제 유저 데이터를 식별하는 메타데이터(`isSample: true`)와 자가 정화(Self-Purge) 메커니즘 부재.
- **본질 축 (Essence Axis)**: `[E2] 5단위 회고 및 실시간 시간기록 / 데이터 분석 콕핏`
- **체감 가설 (User Experience Hypothesis)**:
  > *"사용자가 기록 탭에서 '데이터 가져오기 & 1초 샘플'을 열었을 때, 원하는 분야(영업, 개발, 공부, 운동 등)의 카드를 누르면 단 1초 만에 즉시 로드되어 화려한 다차원 차트가 눈앞에 펼쳐지며, 언제든 안심하고 샘플만 되돌릴 수 있어야 한다."*
- **기존 전체 기능 영향도 분석**:
  - 계정/로그인: 무영향.
  - 홈 화면 및 스트릭: 무손실 보존.
  - 기록/통계: 샘플 로드 시 통계 뷰 즉시 표출, 샘플 정리 기능 추가로 데이터 관리 편의성 극대화.

## 3. [원칙 ③] 효과적 · 효율적 해결방식 결정 (Functional Specifications)

### 3-1. 세부 기능 요구사항 (Functional Requirements)
- **FR-01 (원터치 1초 다이렉트 로드)**: 각 샘플 카드 우측에 `[⚡ 1초 로드]` 버튼을 직접 배치하여, 클릭 즉시 데이터 주입 -> 모달 닫기 -> 통계 뷰로 전환.
- **FR-02 (선택 카드 시각적 강조)**: 카드를 탭하면 활성화 테두리(Brand 컬러) 및 체크 아이콘 표시.
- **FR-03 (CSV/텍스트 실시간 표 미리보기)**: 파일 선택 또는 텍스트 입력 시 파싱된 상위 3~5행을 깔끔한 모노스페이스 데이터 테이블로 즉시 렌더링.
- **FR-04 (샘플 데이터 자가 정화/되돌리기 안전망)**: 샘플 데이터에 `isSample: true` 및 `sampleCategory` 주입. 모달 상단 및 통계 콕핏에 `[🧹 샘플 데이터만 정리하기]` 버튼을 노출하여, 유저의 실제 데이터는 보존하면서 샘플만 1초 만에 깔끔히 삭제.
- **FR-05 (동적 날짜 리베이스)**: 모든 52주 샘플을 오늘(`Date.now()`) 기준으로 자동 역산하여, 로드 즉시 1년/6개월/3개월 통계 차트에서 완벽히 시각화되도록 보장.

### 3-2. 전수 인터랙션 명세표 (Zero-Dead-Click)
| UI 요소 (ID / Selector) | 위치/화면 | 사용자 액션 | 기대 동작 | 피드백 |
| :--- | :--- | :--- | :--- | :--- |
| `[data-sample-quick]` | 샘플 카드 우측 | 클릭 | 해당 샘플 52세션 즉시 융합 및 통계 뷰 전환 | 토스트 + 콕핏 즉시 갱신 |
| `.u-sample-card` | 샘플 카드 본체 | 클릭 | 카드 선택 강조 + 하단 프리뷰 및 융합 버튼 텍스트 갱신 | 테두리 하이라이트 + 체크 표시 |
| `#uImpCsvFileInput` | CSV 탭 | 파일 선택 | CSV 파싱 후 실시간 상위 5행 데이터 테이블 표출 | "N건 파싱 완료" + 표 프리뷰 |
| `#uImpTextInput` | 텍스트 탭 | 타이핑/붙여넣기 | 한국어 날짜/구분자 자동 감지 및 실시간 표 표출 | "N건 감지됨" + 표 프리뷰 |
| `#uClearSampleDataBtn` | 모달 상단/통계 헤더 | 클릭 | `isSample: true`인 샘플 기록만 선별 삭제 | "샘플 데이터 N건이 정리되었습니다." |

### 3-3. 유저 데이터 100% 무손실 보존 규격 (Zero-Data-Loss Schema)
- 실제 유저가 작성한 기존 기록(`type !== 'sample'` 또는 `!r.isSample`)은 샘플 로드/삭제 시 1바이트도 수정되지 않음.
- 딥이퀄 검증 및 스토리지 백업 보존.

## 4. [원칙 ④] 1~3 재검토 및 보완 (Review & Edge Cases)
- **엣지 케이스 1**: 이미 샘플이 로드되어 있는데 다른 샘플을 또 로드할 경우 -> 기존 동일 카테고리 샘플을 덮어쓰거나 중복 없이 융합.
- **엣지 케이스 2**: 깨진 CSV나 날짜가 없는 텍스트 입력 -> 정중한 안내 문구와 유효 행만 선별 파싱.

## 5. [원칙 ⑤] 해결 절차 정리 (Procedure & State Propagation)
1. `js/universal-stats.js` 샘플 생성기 날짜를 `now` 기준 동적 52주로 리베이스.
2. `openUniversalImportModal` 마크업에 원클릭 `[⚡ 1초 로드]` 버튼 및 실시간 테이블 프리뷰 영역 배선.
3. `isSample` 플래그 관리 및 원클릭 `[🧹 샘플 데이터 정리]` 핸들러 탑재.
4. 단위 테스트 작성 및 `npm test` 무결성 검증.
