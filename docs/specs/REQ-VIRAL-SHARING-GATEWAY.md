## 1. 문제 정확히 파악 (8원칙 ①)
1. **피드(Feed)**: 개별 피드 카드에 외부 공유 버튼 및 글별 딥링크가 전무하여 외부 SNS로 피드를 공유할 수 없고, 비회원이 접근하면 랜딩 화면에 막혀 내용을 볼 수 없음.
2. **모임(Club/Team)**: 소그룹 모임(?invite_group=)은 게스트 온보딩이 있으나, 팀 모임장 초대 모달(?join_team=)은 index.html 수신 핸들러가 누락되어 접속 시 랜딩 화면에 멈추는 배선 결함 발생. Kakao SDK 미탑재로 클립보드 복사로 fallback.
3. **템플릿(Template)**: 60선 전문가 템플릿 및 마켓 템플릿에 외부 공유 버튼, 딥링크, 비회원 카탈로그/온보딩 파이프라인이 전무.
4. **기타 연계**: 완주 인증서에서 ?goal= 파라미터를 생성하지만 수신 측에서 무시되어 비회원에게 완주 카드가 노출되지 않음.
5. **외부 SNS 미리보기(OG)**: 카카오톡/페이스북 크롤러는 JS를 실행하지 않아 모든 공유 링크가 항상 고정된 기본 아워골 메타태그(메인 이미지)만 노출됨. 도메인(ourgoal.kr vs vercel.app) 파편화.

## 2. 본질·원인·중심·핵심 파악 (8원칙 ②)
- **본질**: 아워골의 우수한 콘텐츠(목표, 피드, 템플릿, 모임)가 앱 내부 폐쇄망에 갇혀 있어, 바이럴 유입 및 앱 미사용자 전파가 물리적으로 차단된 상태.
- **핵심**: "공유 발송 규격", "비회원 수신 라우터", "SNS 크롤러 대응(OG)" 3대 공통 백본의 부재.
- **귀속 축**: E3(동류 소통) 및 INFRA(성장 인프라).

## 3. 해결방식 결정 (8원칙 ③)
1. **공통 공유 엔진 (`shareContent`)**:
   - Web Share API (모바일 카카오톡/인스타/시스템 시트) + 클립보드 복사 자동 fallback.
   - 현재 호스트(`window.location.origin`) 기반 동적 URL 생성으로 도메인 파편화 원천 해소.
2. **클라이언트 통합 딥링크 게이트웨이 (`handleDeepLinkRouting`)**:
   - `?feed={id}`: 피드 상세 팝업 (비회원 즉시 열람 + "나도 응원하기/목표 시작" CTA)
   - `?invite_group={id}` 및 `?join_team={id}`: 모임 초대 팝업 (누락된 `join_team` 통합 연결, 제로 인스톨 게스트 온보딩)
   - `?template={id}`: 템플릿 4단계 둘러보기 팝업 (비회원 즉시 열람 + "이 템플릿으로 내 목표 시작" CTA)
   - `?goal={id}`: 완주 인증 카드 팝업 (비회원 즉시 열람 + "나도 도전하기" CTA)
3. **Vercel 서버리스 동적 OG 엔드포인트 (`api/share.js`)**:
   - SNS 크롤러 봇 접속 시: 해당 콘텐츠의 제목, 설명, 썸네일을 담은 완전한 HTML `<meta property="og:...">` 반환.
   - 실제 사용자 접속 시: 0.1초 만에 `/?feed={id}` 등 앱 메인으로 안전 리다이렉트.
4. **피드 카드 및 템플릿 모달 UI에 [공유하기] 버튼 4위 1체 배선**:
   - 마크업 + 이벤트 리스너 + `shareContent` 핸들러 + 피드백/토스트 완비.

## 4. 1~3 재검토 및 보완 (8원칙 ④)
- 비회원이 외부 링크로 유입되었을 때 기존 회원의 로컬스토리지나 계정 상태를 절대 오염시키지 않는 '게스트 소프트 뷰어' 패턴 엄수.
- 아워골 최고 헌법 제12조(실 사용자 연동 제19조): 가짜 봇이나 눈속임 없이 실제 DB 데이터와 템플릿 레지스트리 기반으로 동작.

## 5. 절차 정리 (8원칙 ⑤)
1) `api/share.js` 동적 OG 서버리스 엔드포인트 구현 (피드/모임/템플릿/완주 메타태그 생성)
2) `index.html` 내 공통 공유 엔진 `shareContent` 구현
3) `index.html` 내 클라이언트 통합 딥링크 라우터 `handleDeepLinkRouting` 구현 (피드, 모임, 템플릿, 완주)
4) 피드 카드(`feed-item`)에 공유 버튼 마크업 및 리스너 배선
5) 템플릿 모달(`openTemplatePreviewModal`, 마켓 템플릿)에 공유 버튼 마크업 및 리스너 배선
6) `team-invite-comm.js`의 `join_team` 링크 및 `shareCardExternal` 도메인 통일
7) 5대 무결성 검증 (npm test, 스모크 테스트, 전수 클릭, 페르소나 보존)
