## 2. [원칙 ②] 본질·원인·중심·핵심

- 본질: 이 단언이 지키려던 것은 글자가 아니라 「프롬프트 백과사전 아코디언이 **접힌 채**(초기값 false) 시작한다」는 사실이다.
- 원인: 그때는 초기값을 확인할 길이 index.html 의 선언 줄 글자뿐이었다. 상태 기관이 생긴 뒤로는 같은 초기값이 기관 호출의 둘째 인자로 적힌다.
- 중심: 금고의 잣대를 지우거나 약하게 하지 않고, 초기값이 적히는 두 자리를 각각 진짜로 확인하게 하는 것.
- 핵심: 이름이 다르거나 초기값이 다르거나 기관을 읽지 않으면 반드시 실패하고, 도우미를 들여오는 PR 과 병합 순서가 바뀌어도 게이트가 죽지 않는 것.

## 3. [원칙 ③] 해결 방식

- 게이트 머리에 `textOrStateDefined(source, legacyDeclText)` 를 둔다. 공용 도우미 `tests/helpers/moved-code.js` 가 **있으면** 그 판정(옛 선언 글자 **또는** 상태 기관 호출 — 같은 이름·같은 초기값·기관을 먼저 읽음·파서로 읽음)을 쓰고, **없으면** `source.includes(legacyDeclText)`(고치기 전 식)만 쓴다.
