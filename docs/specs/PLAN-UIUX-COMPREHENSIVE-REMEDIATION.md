## 2. 본질 · 원인 · 중심 · 핵심 기반의 단계별 세부 작업 계획 (원칙 ②)
- **본질 파악**: 유저가 앱을 사용할 때 겪는 불필요한 시각적 복잡성, 2중 분열된 액션 버튼으로 인한 의문, 명확한 가이드와 긍정적 피드백에 대한 유저의 욕구를 해소하는 것이 본질이다.
- **원인 규명**: 잦은 기능 고도화 과정에서 레거시 액션 버튼과 신규 바가 공존하고, 전문가용 통계 용어가 여과 없이 노출된 것이 원인이다.
- **중심 해결**: 사용자의 시선 흐름을 중심에 두고 화면별 핵심 행동을 단일화하며, 직관적인 한국어 마이크로카피로 전환한다.
- **핵심 구현**: 12대 UI/UX 개선 과제를 8단계에 걸쳐 질서정연하게 구현한다.

1. **Phase 1: PWA 캐시 네임 갱신**
   - `sw.js`: `CACHE_NAME`을 `ourgoal-shell-v20260919-uiux-comprehensive-remediation`으로 갱신
2. **Phase 2: 홈 탭 UI 개선**
   - 14일 히트맵: 요일 라벨(`월`,`화`...) 추가 및 오늘 테두리 하이라이트
   - 3초 체크인: 커닝페이퍼 칩을 깔끔한 접이식 아코디언/토글(`💡 내 목표 맞춤 커닝페이퍼 (추천 예시)`)로 감싸고 입력창 시원하게 정돈
3. **Phase 3: 목표 탭 UI 개선**
   - D-14 중복 제거: 헤더 요약 뱃지 단일화
   - 4종 보기 토글 및 버튼 정리, 마일스톤 리스트 뷰 기본화
4. **Phase 4: 기록 및 통계 탭 UI 개선**
   - 기록 탭: 중복 `+ 새 기록` 버튼 정리 및 샘플로드 카드 접이식 전환
   - 통계 서브탭: `[DIMENSION]` 영문 제거, 렌즈 설명 순화
5. **Phase 5: 캘린더 탭 UI 개선**
   - 선택 일자 2중 분열 카드를 상단 선택바로 단일화
   - 새 일정 모달 저장 버튼 배경색 긍정 에메랄드/그린 전환 및 신규 생성 시 완료 토글 숨김
6. **Phase 6: 소통 탭 UI 개선**
   - 부정적 평가 버튼(`별로에요`) 영구 삭제
   - 러닝메이트 0명 시 슬림 바로 정돈
7. **Phase 7: 설정 탭 UI 개선**
   - 4대 아코디언 타이틀 아래 핵심 서브 항목 힌트 텍스트 표기
8. **Phase 8: 테스트 및 로컬 프리뷰 구동**
   - `npm test`, `verify-integrity-gate.js`, `verify-all-clicks.js` 통과
   - 로컬 프리뷰 서버(`http://localhost:3000`) 가동
   - CDP 스크린샷 캡처 및 상민님 검증표 작성
