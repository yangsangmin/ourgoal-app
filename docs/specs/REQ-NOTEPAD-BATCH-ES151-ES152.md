## 2. 상세 요구사항 (요구사항 8원칙 적용)

### 2.1 #TASK-ES-151: 일정 체크버튼 완료/미완료 토글 및 목표 연동 UI/UX 구현
- **REQ-151-1 (체크버튼 토글)**: 캘린더 일간/시간표 블록, 일정 목록 모달, 일정 카드 좌측에 마일스톤형 원터치 체크 버튼 탑재. 클릭 시 완료(done: true, 취소선, 음영 처리), 재클릭 시 미완료(done: false)로 상호 전환.
- **REQ-151-2 (목표 양방향 동기화)**:
  - 일정 등록/수정 모달에 연계할 목표/마일스톤/할일 선택 드롭다운(셀렉터) 제공.
  - 일정 체크(완료) 시: 연동된 목표의 해당 마일스톤/할일도 자동 완료 처리되어 목표 달성률(%) 즉시 상승.
  - 반대로 목표 탭에서 할일 체크 시: 캘린더의 해당 일정도 완료 상태로 자동 반영.
  - 연계되지 않은 독립 개인 일정은 자체 완료 상태만 독립 토글.
- **REQ-151-3 (UI/UX 시각화)**: 캘린더 일정 블록 및 목록에 연계된 목표 명칭 뱃지(예: 🎯 목표명)를 표시하여 한눈에 식별 가능하도록 배치.

### 2.2 #TASK-ES-152: 백그라운드·앱종료·미확인 전역 알림(DM 포함) 전수 구현 및 세부 알림 설정창 구축
- **REQ-152-1 (3대 상황별 알림 커버리지)**:
  - 포그라운드(앱 켜놓고 다른 탭/창 볼 때): 인앱 플로팅 배너/토스트 및 헤더 레드 닷 뱃지로 즉각 인지.
  - 백그라운드(앱 최소화/타 앱 사용 중): Web Notification API로 OS 시스템 알림창 팝업.
  - 앱 종료(창 닫힘): Web Push API / 서비스워커(sw.js) Background Push 리스너 연동.
- **REQ-152-2 (미구현 알림 전수 배선)**:
  - 1:1 DM 신규 수신 실시간 알림 (대화방 외부에 있을 때 즉각 발송).
  - 마니또 익명 응원 메시지 도착 알림.
  - 팀 피드 댓글 및 실시간 응원 도착 알림.
  - 목표 마감일 / 일정 시작 리마인더 알림.
- **REQ-152-3 (설정창 세부 알림 제어 센터)**:
  - 설정창(renderSettingsScreen) 내 전용 알림 섹션 구축:
    1) 백그라운드 알림 수신 ON/OFF
    2) 앱 종료 푸시 알림 수신 ON/OFF
    3) 알림 피드백 모드: [소리(Audio)] / [진동(Vibration)] / [무음] 선택
    4) 노출 수준(프라이버시): [간략형] / [상세형: 발신자 및 본문 미리보기] 선택
    5) 카테고리별 개별 토글 (1:1 DM, 팀 활동, 일정/목표 리마인더)
  - 설정값 로컬 영속화(state.profile.settings.notifications) 및 디바이스 권한 요청 플로우 무결성 확보.
