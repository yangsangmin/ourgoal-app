## 1. [원칙 ①] 문제 파악 및 정의 (Problem Definition)
- **상민님 원문 요구사항**:
  - "앱 들어가면 내 아바타가 화면의 절반크기로 반겨줘야함."
  - ""오늘은 뭘 할거냐? 내자신" 이라고 말하면서 또는 밤에는 "오늘은 뭘 했냐? 내자신"이라고."
  - "이 멘트를 바꾸는 기준은 오전 4시. 오후 4시로 하고 사용자가 설정창에서 직접 바꿀 수 있게 해야함"
  - "팝업창은 X 버튼(누르기 쉬울 정도로 크게)으로 바로 닫을 수 있고, 앱 킨 뒤 2.5초만에 자동으로 사라지도록 설정." (노션 생각 메모장 [26]번)
- **현재 상황 및 개선 필요성**:
  - 1) 앱 진입(부트) 시 사용자를 맞아주는 감성적 인트로 시각 효과가 부재하여 첫 인터랙션 몰입감이 약함.
  - 2) 성장 중인 내 아바타가 앱의 첫 관문에서 주도적으로 말을 걸어주는 자기 대화(Self-reflection) UX 부재.
  - 3) 시간대별(오전 4시~오후 4시 주간, 오후 4시~오전 4시 야간) 맞춤 멘트 및 사용자 취향에 맞춘 시간/멘트 커스터마이징 설정 부재.
  - 4) 유저의 흐름을 방해하지 않도록 대형 X 닫기 버튼과 2.5초(2500ms) 자동 페이드아웃(Auto-Fadeout) 안전 장치 완비 필요.

## 2. [원칙 ②] [본질] · [원인] · [중심] · [핵심] 4대 요소 분석 (Root Cause & 4 Elements)
- **[본질] (Essence)**:
  - 아바타와 나 자신의 교감과 내적 동기부여(E1 본질). 아침에는 당찬 각오를, 저녁에는 치열했던 하루의 점검을 내 아바타가 거울처럼 비추어주는 정체성 일체감.
- **[원인] (Causes)**:
  - 부트 루틴이 데이터 로드와 화면 렌더링에만 집중되어 있어, 유저가 앱을 열었을 때 맞이하는 정서적 환영과 자극 장치가 없었음.
- **[중심] (Core)**:
  - 화면 절반(Viewport 45~50% 높이) 크기의 압도적인 아바타 비주얼, 시간대별 지능형 말풍선 멘트 분기, 2.5초 논블로킹 자동 소멸 및 초간편 즉시 닫기.
- **[핵심] (Anchor)**:
  - 1) **대형 아바타 인사 팝업 렌더러**: 화면 중앙에 뷰포트 높이 절반에 달하는 아바타 SVG/이미지 및 세련된 네온 글래스 말풍선 탑재.
  - 2) **지능형 시간대 분기 엔진**: 기본 기준(오전 4시 주간 시작, 오후 4시 야간 시작)에 맞춰 "오늘은 뭘 할거냐? 내자신" / "오늘은 뭘 했냐? 내자신" 동적 출력.
  - 3) **대형 X 닫기 버튼 & 2.5초 Auto-Fadeout**: 누르기 쉬운 42px 대형 원형 닫기 버튼 + 2500ms 후 부드러운 CSS 페이드아웃 소멸.
  - 4) **설정창 커스텀 센터**: 설정창(`screen-settings`) 내 활성화 토글, 주간/야간 기준 시간 셀렉트, 멘트 커스텀 입력 및 '인사 미리보기' 원터치 버튼 제공.
  - 5) **영구 영속화**: `state.profile.settings.avatarGreeting` 구조로 로컬스토리지 및 프로필 저장 완비.

## 3. [원칙 ③] 설계 및 아키텍처 방안 (Design & Architecture)
- **UI/UX 구조 (`ui.css`)**:
  - `#avatarGreetingModal`: 반투명 글래스 백드롭 모달 오버레이.
  - `.avatar-greet-box`: 화면 중앙에 위치하며 아바타가 강조되는 플렉스 레이아웃.
  - `.avatar-greet-img-half`: 높이 48vh (최대 340px) 규모의 대형 아바타 비주얼.
  - `.avatar-greet-bubble`: 아바타 상단/중앙에 배치되는 말풍선과 굵은 멘트 타이포그래피.
  - `.avatar-greet-close-big`: 42x42px 크기의 시원한 원형 X 닫기 버튼 (터치 반경 넉넉함).
  - `.avatar-greet-fadeout`: 2.5초 후 0.35초간 부드럽게 사라지는 CSS 트랜지션.
- **엔진 로직 (`index.html`)**:
  - `openAvatarGreetingPopup(profile, isPreview)`: 현재 시간과 설정값을 비교하여 주간/야간 멘트 결정 후 팝업 렌더링.
  - 2500ms 타이머 등록 및 X버튼/백드롭 클릭 시 `clearTimeout` 후 즉시 소멸.
  - `boot(profile)` 완료 시점에 자동 호출.
  - `renderSettingsScreen()` 내 아바타 인사 팝업 커스텀 설정 섹션 추가.
- **PWA 서비스워커 (`sw.js`)**:
  - `ourgoal-shell-v20260917-es165` 캐시 갱신.

## 4. [원칙 ④] 엣지 케이스 및 부작용 방지 (Edge Cases & Countermeasures)
- 1) **반복 방해 방지**: 한 번 진입한 세션 내에서 사용자가 다른 탭으로 이동했다 돌아올 때 무한히 뜨지 않도록 세션 플래그(`sessionStorage` 또는 런타임 플래그)로 첫 1회 산뜻하게 표시, 미리보기 버튼 클릭 시에는 언제든 수동 트리거 가능.
- 2) **타이머 메모리 누수 방지**: 사용자가 2.5초 전에 직접 X 버튼을 누르거나 백드롭을 터치하면 `clearTimeout`을 호출하여 고스트 타이머 방지.
- 3) **시간대 경계선(오전 4시, 오후 4시 정각)**: 정확한 시간 비교 함수(`isDaytime(hour, dayStart, nightStart)`)로 경계값 무결성 보장.
- 4) **용어 헌법 준수**: '잔디' 단어 절대 배제, '히트맵' 단일화.
