## 1. [원칙 ①] 문제 정확히 파악 (Problem Identification)
- **상민님 원문 지시사항**:
  - *"일정(월)을 폰 잠금화면에서 킬때 바로 볼 수 있게 할 수 있어? 아워골 앱 안들어와도 폰 볼때마다 확인할 수 있는거야."*
  - *"선택형으로 다 사용할 수 있게? 폰 잠금화면에서 보기 누르면 어떨게 설정하는지 알려주면서 바로 설정까지 할 수 있게?"*
- **타깃 과제 상세**:
  1. 앱에 들어가지 않고도 스마트폰 잠금화면을 켤 때마다 이번 달 일정과 오늘 할 일을 0초 만에 즉시 인지하는 선택형 3대 솔루션(월간 달력 배경화면, 캘린더 위젯 연동, 모닝 알림) 제공.
  2. 일정 탭 상단에 `[📱 폰 잠금화면에서 보기]` 버튼 마운트.
  3. 클릭 시 열리는 통합 허브 모달에서 기종별(아이폰/갤럭시) 친절한 설정 가이드와 지금 바로 설정/다운로드/복사할 수 있는 원클릭 액션을 완벽 일체화.

---

## 2. [원칙 ②] 본질 · 원인 · 중심 · 핵심 파악 (Essence, Causes, Core & Anchor)
- **본질**:
  - 앱 실행 없이 폰을 켜는 순간(0초) 일정과 목표를 인지하게 하여 루틴 실행률을 극대화하는 UX 혁신.
- **원인**:
  - 웹 앱(PWA)은 네이티브 앱 대비 OS 잠금화면 제어가 제한적이므로, 사용자가 가장 직관적으로 체감할 수 있는 3가지 대안(배경화면, 시스템 캘린더 위젯 구독, 푸시 알림)을 종합적으로 제공해야 함.
- **중심 & 핵심**:
  - 설명만 늘어놓는 것이 아니라, "화면 안에서 원클릭으로 고화질 배경화면을 즉시 생성·저장"하고 "구독 주소를 복사"하며 "알림을 켜는" 즉시 실행성을 갖출 것.

---

## 3. [원칙 ③] 효과적 · 효율적 해결방식 결정 (Effective Solutions)
1. **진입 버튼 (#calLockScreenBtn)**:
   - 위치: `#screen-calendar` 내 캘린더 네비게이션 행 바로 아래
   - 요소: `<button id="calLockScreenBtn">📱 폰 잠금화면에서 보기</button>`
2. **통합 허브 모달 (#lockScreenHubModal)**:
   - 3단 세그먼트 탭: `[🖼️ 달력 배경화면]`, `[📅 위젯 연동]`, `[🔔 모닝 알림]`
3. **탭 1 (월간 달력 배경화면 실시간 생성기)**:
   - 1080×2340 Canvas 2D 고해상도 그래픽 엔진 (`generateLockScreenCalendarImage`)
   - 상단 시계/상태바 영역(0~520px) 세이프존 확보
   - 중앙 월간 캘린더 그리드 (오늘 하이라이트 + 일정 컬러 도트)
   - 하단 오늘 일정 및 핵심 D-Day 브리핑 카드
   - 다크/라이트 테마 전환 및 `[📥 고화질 잠금화면 이미지 다운로드]` 버튼
   - 아이폰/갤럭시 기종별 3초 설정 안내
4. **탭 2 (폰 캘린더 위젯 실시간 연동)**:
   - WebCal 실시간 구독 URL 복사 (`#btnCopyLsWebCal`)
   - iCalendar (.ics) 파일 수동 다운로드 (`#btnDownloadLsICS`)
   - 아이폰/갤럭시 기종별 1분 완성 위젯 배치 안내
5. **탭 3 (아침 잠금화면 모닝 알림)**:
   - 아침 기상 시각 선택 (07:00 ~ 09:00)
   - 알림 켜기/끄기 토글 버튼 (`#btnToggleDigest`)
   - 브라우저 웹 푸시 권한 연동 및 `localStorage` 영속화

## 6. [원칙 ⑥] 절차 재검증: 5대 무결성 검증 시나리오 설계 (Re-Verification)
