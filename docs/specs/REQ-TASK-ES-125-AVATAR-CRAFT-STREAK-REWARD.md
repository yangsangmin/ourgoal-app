## 1. 배경 및 목적 (문제해결 8원칙 ①파악 ②본질)
- **비용 방어**: 초기 유저 유입 급증 시 1인당 10회(~430원)는 수익화 이전 과도한 API 지출 유발. 이를 신규 유저 기본 3회(~130원)로 조정하여 초기 비용 리스크 70% 차단.
- **습관 형성(E1) 리텐션 강화**: 아워골의 핵심 가치인 '7일 연속 체크인(스트릭)' 달성 시마다 아바타 제작권 1회를 보너스로 충전하여, 아바타를 '성실한 실천의 훈장/트로피'로 자리매김.
- **기존 유저 무손실 보호 (TECH-RULE-03)**: 기존에 10회를 부여받았던 계정은 기존 10회 한도를 100% 유지하며, 7일 체크인 리워드 역시 동일하게 누적 혜택 적용.

## 2. 기능 요구사항 (Functional Requirements)

### [FR-01] 기본 제작 한도 분기 (기존 10회 보존 & 신규 3회)
- 신규 계정의 기본 아바타 제작 한도는 3회(DEFAULT_BASE_CRAFTS = 3)로 설정한다.
- 기존 로그인 계정(avatarCraftCount 존재 또는 기존 customAvatarUrl/savedAvatars 보유)은 10회 한도를 그대로 유지한다.

### [FR-02] 7일 연속 체크인 스트릭 보너스 티켓 (+1회)
- 체크인 기록 완료 시 streakDays가 7의 배수(7, 14, 21, 28...)에 도달할 때마다 `settings.bonusCraftCredits`를 +1 자동 지급한다.
- 동일 구간 중복 지급 방지: `settings.lastStreakAwarded`를 기록하여 한 스트릭 구간당 정확히 1회만 지급.
- 지급 즉시 축하 토스트 노출: *"🎉 7일 연속 체크인 달성! 아바타 제작권 1회가 충전되었습니다! 🎨"*

### [FR-03] 총 가용 및 잔여 횟수 동적 계산
- 총 가용 횟수 = `baseCrafts + (settings.bonusCraftCredits || 0)`
- 잔여 횟수 = `Math.max(0, 총 가용 횟수 - usedCrafts)`
- UI 표시: 모달 상단 및 제작 버튼에 `(남은횟수/총가용횟수)`로 정직하게 표기 (예: `(3/3회)`, `(2/4회)`).

### [FR-04] 생성창 상시 충전 안내문구 탑재
- 잔여 횟수가 0회일 때뿐만 아니라, 아바타 생성 모달 내에 상시로 안내 배너 노출:
  *"🔥 7일 연속 체크인 시 아바타 제작권 1회 자동 충전!"*
