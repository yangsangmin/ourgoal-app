# [요구사항 명세서] #TASK-ES-306: [55] 스톱워치 구간기록별 텍스트 입력창 UI 정돈 및 시인성 개선

## 1. 개요 및 배경
- **티켓 ID**: `#TASK-ES-306`
- **본질축**: `E2/UX` (기록 회고 루프 및 실존적 데이터 자산화)
- **노션 원천**: 생각 메모장 아이디어 DB [55]번 (Page ID: `3de598db-9096-81ef-97d2-d125083e7c59`)
- **상민님 원문**:
  > "스톱워치 구간기록의 각 입력창 더 깔끔하게 가다듬어"
- **비고**:
  > 구간별 입력 폼 인풋 필드 마진/패딩/보더 스타일 정돈, 불필요한 공백 및 텍스트 겹침 정리

## 2. 핵심 요구사항 (Requirements)
- **R1 (구간기록별 텍스트 입력창 행 단위 정돈 UI)**:
  - 스톱워치에서 '랩' 버튼 클릭 시, 구간별로 번호(`sw-lap-badge`), 랩 타임(`sw-lap-time`), 활동 메모 입력 필드(`sw-lap-memo-input`), 해당 랩 즉시 표 기입 버튼(`sw-lap-inject-btn`)이 단정하게 구성된 전용 행(`.sw-lap-row`)으로 렌더링되어야 한다.
- **R2 (인풋 필드 스타일 및 텍스트 겹침 제거)**:
  - 각 입력창은 마진, 패딩, 보더(`border: 1px solid var(--rule)`, `border-radius: 8px`, `background: var(--surface-2)`)가 일관되게 정돈되어야 하며, 텍스트가 잘리거나 겹치지 않도록 적절한 플레이스홀더와 높이/너비를 갖추어야 한다.
- **R3 (실시간 데이터 바인딩 및 4대 뷰 동시 전파)**:
  - 구간 메모 입력 시 스톱워치 상태에 즉시 반영되며, 표에 시간 기입 시 해당 랩의 시간 및 메모가 연결될 수 있어야 한다.
  - 리셋 시 랩 목록이 깨끗하게 정리되어 상태 불일치를 방지한다.
- **R4 (375px 모바일 반응형 및 기존 기능 무결성)**:
  - 375px 모바일 화면에서 수평 넘침(0px overflow) 없이 깔끔하게 표시되며, 기존 423개 스모크 테스트를 100% 보존한다.
