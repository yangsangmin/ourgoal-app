## 1. 배경 및 목적

- **사용자 원문 지시**: "아워골 ai 추천 목표 템플릿 테마별 예시 60선을, 목표-나만보기 오른쪽 빈공간에 ‘템플릿백과사전’으로 바꿔. 그걸 누르면 팝업창 전체화면으로 뜨면서(닫을 수 있어야 함) ‘실사용 템플릿 사전’ / ‘아워골 ai 템플릿’으로 나눠서 볼 수 있게 해. 실사용 템플릿 사전에서는 실제 유저들이 공유한 템플릿을 복사해갈 수 있는거야. 이와 관련한 지금 구축한된 시스템과 유저들간의 상호작용 시스템까지 실제 작동되도록 누락없이 진행해."
- **문제점**: 사용자가 목표 탭에서 동기부여를 얻거나 입증된 목표 로드맵을 찾고자 할 때, 템플릿 탐색 진입점이 숨겨져 있거나 실 유저들이 검증한 고품질 템플릿을 한눈에 보고 즉시 자신의 목표함으로 복제 및 상호작용(응원, 공유)할 수 있는 통합된 전체화면 인터페이스가 부족함.
- **해결 방안**:
  1. 목표 탭 `#goalsPrivacyBadge`('나만 보기') 바로 오른쪽 빈공간에 `#btnGoalTemplateEncyclopedia`('📖 템플릿백과사전') 버튼을 눈에 띄게 상시 노출하고 클릭 시 전체화면 팝업창을 오픈함.
  2. 전체화면 팝업 모달(`#templateEncyclopediaModal`)에 닫기 버튼 및 ESC/외부 닫기 핸들러를 보장하고, 2대 핵심 서브탭('실사용 템플릿 사전' / '아워골 AI 템플릿')을 제공함.
  3. '실사용 템플릿 사전'에서 실제 유저 공유 템플릿 목록, 복제 횟수, 상세 마일스톤 및 할 일 구성 확인, '내 목표로 복사하기' 원클릭 기능, 응원(좋아요) 토글, 내 목표 공유하기 상호작용 시스템을 완전 구축함.
  4. '아워골 AI 템플릿'에서 60선 테마별(운동·건강, 학습·자격, 커리어·머니, 취미·창작, 마음·습관, 관계·생활) 카테고리 필터링 및 1초 자동 이식 기능 제공.
  5. 4위 1체 배선 (마크업 `#og-task-53-container`, `#og-task-53-action-btn`, `handle목표탭_Item53Action`, 12ms 햅틱, `og_task-53_cache` 로컬 원자적 영속화 및 Supabase 연동, 헌법 제15조 제6항 4대 뷰 동시 전파).
  6. 375px 모바일 뷰포트 반응형 최적화 (터치 타겟 44px 이상, 가로 스크롤 0px 방어).

## 3. 예외 및 안전망

- 모달 내 템플릿 복제 시 기존 사용자의 목표 데이터가 손상되거나 덮어쓰여지지 않고 unshift 방식으로 최상단에 안전 추가됨.
- 로컬스토리지 오류 시에도 기본 내장 템플릿 풀을 통해 중단 없이 렌더링됨.
- 네트워크 두절 시에도 `localStorage`를 통한 오프라인 동작 보장.
