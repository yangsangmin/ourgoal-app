## 2. 기능 요구사항 (Functional Requirements)

### [FR-01] 320개 페르소나 온톨로지 데이터셋 구축
- 16개 MBTI(INTJ, INTP, ENTJ, ENTP, INFJ, INFP, ENFJ, ENFP, ISTJ, ISFJ, ESTJ, ESFJ, ISTP, ISFP, ESTP, ESFP) 각각에 정확히 20개 페르소나 매핑 (ID 1~320 전수 정의).
- 각 페르소나 필드: `id`, `mbti`, `cat`, `name`, `kw`, `desc`, `gear`, `icon`, `color`, `subColor`.

### [FR-02] 하위 호환성 매핑 레이어 (Backward Compatibility)
- 기존 `BODY_THEMES_77`의 ID 1~77번 테마는 영구 보존하며, `getThemeById(id)` 호출 시 ID 범위에 따라 올바른 테마를 반환:
  - 1~77번 요청 시: 레거시 테마 및 320종 테마 상호 호환 매핑.
  - 1~320번 요청 시: 320종 페르소나 카탈로그에서 완벽 반환.

### [FR-03] MBTI 기반 스마트 추천 및 4대 군 탭 브라우징
- 유저 프로필에 저장된 MBTI가 있을 경우, 해당 MBTI에 해당하는 20종 페르소나를 최우선 상단 탭/목록으로 자동 큐레이션.
- 아바타 선택 드로어에서 4대 군 탭(분석형 NT, 외교형 NF, 관리자형 SJ, 탐험가형 SP) 및 검색 필터 제공.
