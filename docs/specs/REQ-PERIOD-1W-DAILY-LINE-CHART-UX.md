## 1. [원칙 ①] 문제 정확히 파악 (Problem Identification)
- **상민님 지시 원문**:
  > '기출문제 예시에서, 1w 로 설정했을때 하루단위 꺾은선 그래프가 나와야지. 나머지 기간들도 사용자경험 만족을 위해서 시인성 좋게.'
- **현재 발생하는 문제점**:
  1. 기출문제(공부) 샘플 데이터가 52주간 1주일 단위로만 생성되어 있어, 사용자가 기간 필터를 '1W'(1주일)로 설정했을 때 최근 7일 내 데이터 포인트가 단 1개뿐이어 꺾은선(Line)이 그려지지 않고 점 1개만 나오거나 빈 차트처럼 보임.
  2. 사용자가 1W를 보는 본질적인 목적은 '이번 주 월~일요일 7일간 매일매일 내가 몇 문제를 풀었는지 하루단위 꺾은선 추세'를 확인하는 것인데, 이를 충족하지 못함.
  3. 다른 기간('1M', '3M', '6M', '1Y', 'ALL')에서도 데이터 포인트 밀도가 높아질 때 원(circle)이 겹치거나 x축 눈금이 단조로워 시인성이 다소 떨어지는 아쉬움이 있음.

---

## 2. [원칙 ②] 본질 · 원인 · 중심 · 핵심 파악 (Root Cause & Essence)
- **근본 원인**:
  1. generateDomainSample('study')에서 최근 1주(w = 0)의 일일 세션이 1건뿐이었음.
  2. 차트 렌더러 renderMultiSeriesSvg가 인덱스 기반으로만 x 좌표를 계산하여, 기간 필터('1w')에 맞는 7일간의 절대 시간 축(Time Domain)을 형성하지 못했음.
- **본질 축**: [E2] 5단위 회고 및 전문 통계 콕핏 시계열 시인성 만족.
- **체감 가설**:
  > '사용자가 기출문제 샘플을 로드한 뒤 [1W] 버튼을 누르면, 최근 7일간(월, 화, 수, 목, 금, 토, 일) 하루하루 풀이한 문제 수의 상승 곡선이 시원한 꺾은선 그래프와 요일 레이블로 한눈에 펼쳐져 실천의 보람을 즉시 느낄 수 있다.'

---

## 3. [원칙 ③] 효과적 · 효율적 해결방식 결정 (Functional Specifications)
- **FR-01 (기출문제 최근 7일 하루단위 실천 세션 완비)**:
  - 기출문제 샘플에 최근 7일간(D-6 ~ D-0) 매일 일일 세션 완비 (35문제, 42문제, 48문제, 52문제, 58문제, 65문제, 72문제 등 점진적 과부하 곡선).
  - 52주 전체를 볼 때도 과거 51주 데이터와 완벽하게 연결되는 자연스러운 성장 궤적 보장.
- **FR-02 (1W 전용 하루단위 꺾은선 렌더링 & 요일 x축 시인성)**:
  - 1w 선택 시 x축이 최근 7일(7 calendar days)을 균등하게 커버하며, 각 날짜의 요일과 일자(09.15(일))를 시인성 높게 표시.
  - 7개 데이터 포인트가 매끄러운 꺾은선과 은은한 그라데이션 영역(Area)으로 연결되어 일일 실천 추세가 극명하게 드러남.
- **FR-03 (전 기간 시인성 최적화: 1M, 3M, 6M, 1Y, ALL)**:
  - 1M (30일): 5일 간격 x축 눈금 및 일일 포인트 렌더링.
  - 3M, 6M, 1Y, ALL: 데이터 포인트가 많을 때(30개 이상) 기본 서클 크기를 축소(r=1.8~2.2)하여 뭉개짐을 방지하고, 역대 최고치(PR) 뱃지만 명확히 강조.

## 4. [원칙 ④] 1~3 재검토 및 보완 (Edge Cases)
- 특정 일자에 기록이 0건인 경우: 1W 축에서 해당 일자는 건너뛰거나 정확한 시간 간격 위치에 점이 배치되어 시간 왜곡이 없음.
- 실제 유저 데이터와의 호환: 유저가 1W 동안 2~3일만 기록했더라도 해당 요일 위치에 정확히 점과 선이 연결되어 시인성을 만족함.
