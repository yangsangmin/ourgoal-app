## 1. 배경 및 문제의식 (문제해결 8원칙 ①, ②)
- **상민님 지시 원문**:
  > *"하이록스는 종목별로 다 샘플데이터 넣어줘 각 종목별로 일자별 기록, 페이스, 강도(본인이 느끼는) 등 넣어줘.*
  > *기타 다른 테마의 분류들도 그런식으로 세부적으로 다 샘플 넣어줘.*
  > *각 샘플데이터 종목별로 어떻게 반영했는지 모두 보고해."*
- **현재의 한계**:
  - 기존 하이록스 샘플은 '하이록스'라는 단일 엔티티 아래 '완주시간(88->68분)' 하나로 묶여 있어, 하이록스의 본질인 8대 개별 스테이션(스키에르그, 슬레드푸시, 슬레드풀, 버피점프, 로잉, 파머스캐리, 런지, 월볼) 및 1km 러닝 인터벌을 개별적으로 분석하거나 종목 간 밸런스를 볼 수 없음.
  - 다른 테마들도 단일 지표 중심으로 되어 있어, 실제 사용자가 기록하는 체감 강도(RPE: Rate of Perceived Exertion, 1~10 또는 60~100%), 페이스, 세부 종목 구분이 미흡함.
- **해결 본질**:
  - 하이록스를 실제 세계 규격에 맞게 8대 공식 스테이션 + 러닝 인터벌로 분할하여, 종목별 일자별 기록(초/분), 페이스(초/m), 체감 강도(RPE 6~10)를 EAV 구조로 정밀 생성.
  - 콕핏에서 [전체 모아보기] 터치 시 8개 스테이션의 추세선이 멀티 컬러로 펼쳐지고, 개별 종목 탭 시 해당 종목의 정밀 궤적 및 RPE가 분석되도록 함.
  - 파워리프팅(스쿼트/벤치/데드), 러닝(롱런/조깅/인터벌), 공부(기출문제/개념정리/모의고사), 개발(기능구현/PR머지/코드리뷰), 영업(미팅/수주/제안) 등 주요 테마에도 종목별 세부 EAV 및 RPE 메트릭을 전면 부여.

## 2. 세부 스펙 요구사항 (문제해결 8원칙 ③, ④)

### 2-1. 하이록스 8대 공식 스테이션 및 러닝 EAV 모델
1. **스테이션 1: 스키에르그 (SkiErg 1000m)**
   - 주 지표: 완주시간 (초, 260s -> 215s 점진 단축)
   - 페이스: 500m 페이스 (초, 130s -> 107s)
   - 체감 강도: RPE (7.0 -> 8.5)
2. **스테이션 2: 슬레드 푸시 (Sled Push 50m)**
   - 주 지표: 완주시간 (초, 180s -> 135s)
   - 페이스: 10m 페이스 (초, 36s -> 27s)
   - 체감 강도: RPE (8.5 -> 9.5 극강도)
3. **스테이션 3: 슬레드 풀 (Sled Pull 50m)**
   - 주 지표: 완주시간 (초, 240s -> 190s)
   - 페이스: 10m 페이스 (초, 48s -> 38s)
   - 체감 강도: RPE (8.0 -> 9.0)
4. **스테이션 4: 버피 브로드 점프 (Burpee Broad Jump 80m)**
   - 주 지표: 소요시간 (초, 320s -> 245s)
   - 페이스: 회당 거리 (m, 1.2m -> 1.6m)
   - 체감 강도: RPE (8.5 -> 9.5)
5. **스테이션 5: 로잉 (Rowing 1000m)**
   - 주 지표: 완주시간 (초, 255s -> 210s)
   - 페이스: 500m 페이스 (초, 127s -> 105s)
   - 체감 강도: RPE (7.5 -> 8.5)
6. **스테이션 6: 파머스 캐리 (Farmers Carry 200m)**
   - 주 지표: 완주시간 (초, 130s -> 95s)
   - 페이스: 50m 페이스 (초, 32s -> 24s)
   - 체감 강도: RPE (7.0 -> 8.0)
7. **스테이션 7: 샌드백 런지 (Sandbag Lunges 100m)**
   - 주 지표: 소요시간 (초, 270s -> 205s)
   - 페이스: 10m 페이스 (초, 27s -> 20s)
   - 체감 강도: RPE (8.5 -> 9.5)
8. **스테이션 8: 월볼샷 (Wall Balls 100회)**
   - 주 지표: 소요시간 (초, 360s -> 280s)
   - 페이스: 분당 샷수 (개, 17개 -> 22개)
   - 체감 강도: RPE (9.0 -> 10.0 최대심박)
9. **러닝 인터벌 (1km Running x 8)**
   - 주 지표: 1km 평균 랩타임 (초, 350s -> 270s)
   - 페이스: km 페이스 (초, 350s -> 270s)
   - 체감 강도: RPE (7.5 -> 8.5)
