## 1. 개요 및 추진 배경 (Overview & Background)

### 1.1 배경 및 문제 정의
1. **일방향 보고의 한계**:
   - 기존의 팀 목표 화면은 모임장이 일방적으로 팀원의 진척을 점검하거나 도장을 찍는 구조였습니다.
   - 팀원 스스로가 자신이 이룬 성취를 모임장에게 직접 자랑하거나, 반대로 마일스톤 달성 중 난관에 부딪혔을 때 리더에게 SOS(도움 요청)를 칠 수 있는 능동적 소통 창구가 없었습니다.
2. **리더의 즉각적 1:1 케어 부재**:
   - 팀원이 의욕을 잃거나 지쳤을 때, 모임장이 즉시 1:1 DM으로 다가가 대화하고 격려해 줄 수 있는 직접 연계 고리가 부족했습니다.
3. **본질적 해결책**:
   - 팀원이 목표, 마일스톤, 세부할일 3단계 어디서든 자신의 상태에 맞추어:
     - 완수 시: **`🎉 달성자랑 찌르기`**
     - 미완료/진행 중: **`🥺 힘들어요 찌르기`**
   - 모임장은 팀원들의 찌르기를 알림 센터에서 확인하고, 즉시 **`💬 1:1 DM`**으로 대화를 시작해 조언과 응원을 건넬 수 있는 감성적·실질적 인터랙션을 구현합니다.

### 1.2 체감 가설 (Essence Hypothesis)
> **"팀원이 목표·마일스톤·세부할일을 달성했을 때 모임장에게 '달성자랑 찌르기'로 인정을 받고, 미달성 시 '힘들어요 찌르기'로 고민을 나눠 모임장과 1:1 DM으로 소통함으로써, 팀원은 리더의 지지 속에 목표를 끝까지 완주할 수 있음을 체감한다."**

## 2. 기능 요구사항 (Functional Requirements)

### FR-01: 3단계 계층별 능동적 찌르기 (Multi-Level Ping Suite)
- **FR-01-1 [적용 대상]**:
  1. 목표(Goal) 단위 (예: "3대 500 달성하기")
  2. 마일스톤(Milestone) 단위 (예: "벤치프레스 100kg 1RM 성공")
  3. 세부 할 일(Task) 단위 (예: "오늘 85kg 5회 3세트 완수")
- **FR-01-2 [상태별 찌르기 분기]**:
  - **완료(`done`) 상태**: `🎉 달성자랑 찌르기` 버튼 노출.
    - 기본 문구 템플릿: *"모임장님! 방금 [항목명] 목표를 완벽히 달성했어요! 칭찬해주세요 🎉"*
  - **미완료(`todo` / `doing`) 상태**: `🥺 힘들어요 찌르기` 버튼 노출.
    - 기본 문구 템플릿: *"모임장님, [항목명] 진행 중인데 조금 힘들고 막혀요... 조언을 구하고 싶어요 🥺"*
- **FR-01-3 [찌르기 모달]**:
  - 버튼 터치 시 1초 팝오버 모달이 열려 개인화된 한 줄 메시지를 직접 편집하여 전송 가능.
  - 전송 시 햅틱 피드백 + 토스트 안내.
  - 동일 항목 대상 60초 쿨다운 적용(스팸 방지).

### FR-02: 모임장 찌르기 대시보드 및 알림 센터 (Leader Ping Center)
- **FR-02-1 [모임장 전용 알림 바]**:
  - 모임장(Owner/Manager)의 팀 목표 화면 상단에 '🔔 팀원 찌르기 도착 (N건)' 섹션 노출.
  - 찌르기 카드 구성:
    - 보낸 팀원 아바타, 닉네임, 항목 레벨(목표/마일스톤/할일), 항목 이름.
    - 찌르기 유형 뱃지: `[🎉 달성자랑]` (골드) vs `[🥺 힘들어요]` (로즈/오렌지).
    - 팀원이 남긴 메시지 및 전송 시각.
- **FR-02-2 [1:1 DM 반응 액션 버튼]**:
  - 각 찌르기 카드 우측에 **`[💬 1:1 DM으로 대화하기]`** 버튼 배치.

### FR-03: 모임장-팀원 전용 1:1 DM 대화창 (Leader-Member DM Thread)
- **FR-03-1 [인라인 DM 바텀시트 모달]**:
  - `[1:1 DM으로 대화하기]` 클릭 시 모임장과 해당 팀원 간의 1:1 대화 모달 즉시 실행.
  - 대화 헤더: 팀원 프로필, 찌른 항목 요약.
  - 스레드 영역: 이전 대화 내역 + 이번 찌르기 카드.
  - 입력 영역: 모임장 응답 메시지 입력창 + [전송] 버튼.
- **FR-03-2 [원클릭 추천 응답 칩]**:
  - 달성자랑 찌르기일 때: `[정말 대단해요! 👏]`, `[오늘 최고였어요! 🌟]`, `[도장 찍어드렸어요! 👑]`
  - 힘들어요 찌르기일 때: `[무리하지 말고 쉬어가요 💪]`, `[어떤 부분이 어려우신가요?]`, `[함께 해결해봐요! 🔥]`
- **FR-03-3 [대화 전송 및 실시간 반영]**:
  - 모임장이 메시지 전송 시 로컬 `groupState[gid].dmThreads`에 즉시 기록 및 상태 갱신.

### FR-04: 팀원 시점의 DM 수신 피드백 (Member Reaction Feed)
- **FR-04-1 [모임장 DM 도착 배너]**:
  - 모임장이 DM을 보내면 팀원의 팀 목표 카드 상단에 **`👑 모임장님의 격려 DM: "[메시지 내용]"`** 알림 배너 표출.
  - 탭 시 모임장과의 1:1 대화 모달이 열려 답변 작성 가능.

groupState[gid] = {
  pings: [
    {
      id: 'png_123',
      senderId: 'usr_me',
      senderName: '이영희',

      pingType: 'boast', // 'boast' (달성자랑) | 'struggle' (힘들어요)

    }
  ],
  dmThreads: {
    '이영희': [

      { from: 'leader', text: '영희님 정말 대단해요! 완벽해요 도장 찍어드렸어요! 🌟', time: '01:32' }
    ]
  }
};

## 4. 검증 및 인수 기준 (Acceptance Criteria)

- [ ] **AC-01**: 목표/마일스톤/세부할일이 완료 상태일 때 '🎉 달성자랑 찌르기' 버튼이 정상 노출된다.
- [ ] **AC-02**: 목표/마일스톤/세부할일이 미완료 상태일 때 '🥺 힘들어요 찌르기' 버튼이 정상 노출된다.
- [ ] **AC-03**: 팀원이 찌르기 모달에서 메시지를 전송하면 햅틱과 토스트가 작동하고 모임장 알림 피드에 즉시 적재된다.
- [ ] **AC-04**: 모임장 화면에서 찌르기 알림을 확인하고 [1:1 DM 대화] 버튼 클릭 시 전용 대화창이 정상 렌더링된다.
- [ ] **AC-05**: 모임장이 추천 응답 칩 또는 직접 입력으로 DM을 전송하면 스레드에 실시간 반영된다.
- [ ] **AC-06**: 팀원 화면에 모임장의 DM 응답 배너가 하이라이트 표시된다.
