## 4. [원칙 ④] 재검토 (반례·부작용)

- 반례 — 「IIFE 를 찾는 규칙이 틀려서 못 찾은 것을 0 으로 적으면 조용한 실패 아닌가」(결측을 0 으로 채우지 말 것): 그래서 0 과 함께 「큰 인라인 IIFE 없음」 줄을 적고, 지도에는 `noIife: true` 를 남긴다. 모듈 측정기의 ①(인라인 스크립트 줄 수 — 다른 방법으로 잰다)과 맞대면 드러난다: IIFE 가 있는데 못 찾은 것이면 ① 이 크다. 생성기는 0 이 아닌 종료 코드로 멈춘다.
- 반례 — 탐침에서 이름 0 으로 재면 검사할 이름이 빠진다: 이미 #TASK-ES-614 가 넣은 `--names-from` 이 그 용도다(이전 결과의 이름 목록으로 고정). 이름 고정 없이 돌리면 window 이름 0 으로 잰 결과가 나온다 — 둘 다 쟀다(7절).
- 부작용 — 현재 main: 없다. 출력·쓰는 파일이 같다(7.1).
- 알림 — 현재 main 의 지도 파일은 낡아 있다: `node scripts/inline-script-map.js --write` 를 돌리면 4개 파일이 달라진다(고치기 전 도구로도 같다 — 이 PR 과 무관. 이 PR 은 지도 파일을 갱신하지 않는다).
