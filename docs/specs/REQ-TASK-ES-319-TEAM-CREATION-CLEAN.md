# REQ-TASK-ES-319: 팀 만들기 불필요 제약(정원 제한·인증 주기·챌린지 기간·인증 규칙·진행방식) 전면 점검 및 삭제

## 1. 배경 및 목적
- **출처**: 상민님 생각 메모장 [68]번 아이디어
- **원문 지시**: *"팀 만들기 불필요 제약(정원 제한·인증 주기·챌린지 기간·인증 규칙·진행방식) 전면 점검 및 삭제 — 팀 만들기 현재 상태를 일괄 점검할 필요가 있음. 팀 인원 정원이 필요한가? 왜 정원을 제한했지? 하는 불편감이 있을 수 있음. 인증 주기는 삭제해야해 거부감 들어. 챌린지 기간도 필요 없어 이건 그냥 자유의지인거지 삭제. 인증 규칙도 필요 없어. 팀 진행방식도 필요 없어. 팀 만들기에서 이 5가지 불필요한 제약을 전면 삭제해서 누구나 쉽고 부담 없이 팀을 만들 수 있게 해"*
- **목적**: 팀 개설 시 사용자에게 심리적·기능적 장벽으로 작용하던 5대 불필요 제약(정원 제한, 인증 주기, 챌린지 기간, 인증 규칙, 진행 방식)을 폼 UI와 생성 로직 모두에서 전면 점검 및 삭제·무해화하여, 누구나 3초 만에 팀명과 소개글만으로 부담 없이 자유로운 팀을 만들 수 있도록 보장함.

## 2. 요구사항 명세
1. **R1**: `index.html` 내 팀 만들기 모달에서 5대 불필요 제약 필드(정원 제한 `grpMaxMembers`, 인증 주기 `grpCadence`, 챌린지 기간 `grpWeeks`, 인증 규칙 `grpRule`, 진행 방식 `grpMode`)가 폼 UI에 존재하지 않음을 전수 보장한다.
2. **R2**: `index.html` 내 `promptNewGroup` 팀 개설 모달 상단에 `정원·인증 주기·기간 제약 없는 자유로운 팀이에요` 직관적인 안내 문구를 제공하여 사용자의 부담감을 원천 해소한다.
3. **R3**: `index.html` 내 팀 생성 로직에서 5대 제약이 전면 무해화된 기본값(`maxMembers: 999999` 무제한 정원, `cadence: '자유'` 자율 주기, `endDate: null` 상시 지속형, `rule: '자유 실천 (누구나 부담 없이 자유롭게 실천하고 소통해요)'`, `mode: 'open'`)이 자동으로 주입된다.
4. **R4**: `js/components.js` 내에 직통 핸들러 `handle팀목표_Item68Action`이 구현되어 12ms 햅틱 반응, `og_task-68_cache` 로컬 캐시 영속화, 4대 뷰 원자적 전파를 보장한다.
5. **R5**: `tests/team-creation-clean.test.js` 및 `scripts/smoke-test.js` 내에 `#TASK-ES-319` 검증 테스트가 정의되어 무결점을 전수 입증한다.
6. **R6**: `docs/rules/TICKETS.md`에 `#TASK-ES-319`가 승인 티켓으로 등록되어 있다.
