# [요구사항 명세서] #TASK-ES-305: [54] 루틴 상세 모달 및 편집 기능 구현 (목표탭 벤치마킹 & 루틴 카드 클릭 시 바로 진입)

## 1. 개요 및 배경
- **티켓 ID**: `#TASK-ES-305`
- **본질축**: `E1/UX` (체크인 루프 및 인생 청사진 직결 RPG)
- **노션 원천**: 생각 메모장 아이디어 DB [54]번 (Page ID: `3de598db-9096-81ed-9f99-e936f0c2c1f2`)
- **상민님 원문**:
  > "루틴창에 편집 안만들었네, 편집기능의 세부사항은 목표탭을 참고해서 벤치마킹해. 그리고 편집 안누르더라도 각 루틴을 누르면 그 루틴 자세히 보면서 편집할 수 있게 만들어야지"

## 2. 핵심 요구사항 (Requirements)
- **R1 (목표탭 편집창 벤치마킹)**:
  - 루틴 상세 및 편집 모달(`openRoutineDetailModal`)에 목표탭 상세 모달의 완성도 높은 UX/UI 양식을 벤치마킹하여 적용한다.
  - 카테고리 칩 선택(운동·건강, 학습·성장, 커리어, 마음챙김, 생활습관), 상위 연결 목표 선택 드롭다운, 실천 시간대 지정, 알림 토글, 요일별 반복 토글, 상세 실천 메모 가이드라인을 제공한다.
- **R2 (루틴 카드 직통 상세 진입)**:
  - 루틴 목록 내 카드 본문 클릭 시(체크박스/순서이동/삭제 버튼 제외) 즉시 해당 루틴의 상세/편집 모달이 열려 내용 확인 및 원클릭 수정이 가능해야 한다.
- **R3 (4위 1체 배선 및 영구 보존)**:
  - 모달 마크업 + 직통 핸들러 + `state.profile.settings.routines` 스토리지 영구 저장 + 12ms 햅틱 및 토스트 피드백을 완결한다.
- **R4 (375px 모바일 반응형 및 기존 기능 무결성)**:
  - 375px 화면에서 모달 좌우 넘침(0px overflow) 없이 깔끔하게 렌더링되며 기존 422개 스모크 테스트를 100% 보존한다.
