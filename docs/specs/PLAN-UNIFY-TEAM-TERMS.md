## 1. 개요 및 변경 예산 (문제해결 8원칙 ①, ②)
- **목표**: 아워골 전체 화면(소통, 목표, 설정, 온보딩, 모달)에서 혼재되어 있던 '모임/모임장/모임원' 명칭을 **'팀/팀장/팀원'**으로 완전 단일화하여 인지 혼란을 원천 해소.
- **수정 대상 파일 목록**:
  1. `index.html`: 소통 탭 서브탭, 모임 목록/생성/상세 화면, 목표 탭 헤더/배지, 설정 탭 드롭다운/알림, 온보딩 툴팁 등
  2. `js/team-leader-check.js`: 찌르기 모달/배지/토스트 문구의 '모임장' ➔ '팀장'
  3. `js/team-invite-comm.js`: 초대장 모달 문구 '모임장 권한으로' ➔ '팀장 권한으로'
  4. `js/team-linked-goals.js`: 가이드 및 헤더 문구
  5. `js/team-visibility-levels.js`: 가이드 텍스트
  6. `scripts/smoke-test.js`: 변경된 텍스트 및 라벨 검증 추가

## 3. 5대 무결성 전수 검증 시나리오 (문제해결 8원칙 ④, ⑥)
1. **제1검증: 전수 클릭 검증**:
   - 소통 탭의 `[팀]` 서브탭 클릭 시 `group` 서브탭 정상 렌더링.
   - `+ 팀 만들기` 클릭 시 모달 정상 호출.
   - 팀 상세 진입 후 `‹ 팀 목록` 뒤로가기 버튼 정상 동작.
   - 목표 탭의 `참여 중인 팀 목표` 및 `[팀장]` 배지 확인.
2. **제2검증: 전 UX 회귀 검증**:
   - 캘린더의 일반 일정("약속·모임 등록")이 손상되지 않고 정상 동작하는지 확인.
3. **제3검증: 유저 데이터 100% 무손실 보존 검증**:
   - `scripts/verify-integrity-gate.js` 페르소나 데이터 10종 딥이퀄 검증 통과.
4. **제4검증: 화면 간 상호연동 전파 검증**:
   - 설정 탭의 '팀원 공개', 소통 탭의 '팀', 목표 탭의 '팀 목표'가 일관된 용어로 동기화되는지 확인.
5. **제5검증: 자동화 테스트 100% PASS**:
