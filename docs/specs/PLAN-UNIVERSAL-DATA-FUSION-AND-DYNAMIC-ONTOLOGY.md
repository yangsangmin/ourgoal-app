### [WP-2] 7-Tier 정밀 시계열 슬라이싱 엔진
- **목적**: 100년 전 과거 데이터부터 최신 데이터까지 단절 없이 수용하는 데이터셋 상대 슬라이싱.
- **세부 작업**:
  1. 슬릭 알약 탭 7단 구현: `[ALL]`, `[1Y]`, `[6M]`, `[3M]`, `[1M]`, `[1W]`, `[3D]`.
  2. 상대 윈도우 계산 로직 적용:
     $$\text{refDate} = \max_{r \in \text{allRecs}} \{ \text{new Date}(r.\text{startAt}).\text{getTime}() \}$$
  3. `1Y`에 370일 버퍼 부여 (52주 파워리프팅 주기화 전 세션 누락 방지).
  4. `ALL` 선택 시 1970년 이전 음수 타임스탬프(1924년 파리 올림픽 데이터) 완벽 수용.
  5. 윈도우 내 데이터 0건 시 `NO OBSERVED DATA IN RANGE — EXPAND TO [ALL]` 진단 패널 표출.

### [WP-3] [노션식 EAV] 다형성 패싯 온톨로지 매니저 & 한글 초성 검색 & 스키마 CRUD
- **목적**: 사용자가 어떤 분야의 데이터든 자유롭게 분류하고, 직접 단위를 정의/수정/삭제 가능하도록 지원.
- **세부 작업**:
  1. **한글 유니코드 초성 분해 수학 알고리즘 탑재**:
     - 음절 코드 오프셋: $S = \text{code} - 44032$, $L = \lfloor S / 588 \rfloor$.
     - 19개 초성 테이블 매핑 (`ㄱ, ㄲ, ㄴ, ㄷ ... ㅎ`).
     - 입력값이 초성(`/^[ㄱ-ㅎ]+$/`)인 경우 대상 엔티티 초성과 1ms 이내 고속 매칭 (`ㅂㅊ` ➔ `벤치프레스`, `ㅅㅋ` ➔ `스쿼트`, `ㄷㅅ` ➔ `독서`).
  2. **동적 패싯 온톨로지 트리**:
     - 8대 도메인(`health`, `learning`, `career`, `finance`, `mind`, `routine`, `hobby`, `relationship`) ➔ 카테고리 ➔ 엔티티 계층 트리.
     - 실제 유저 데이터가 존재하는 항목만 스마트하게 활성화.
  3. **사용자 직접 스키마 CRUD**:
     - `[+ 스키마 추가]`: 신규 도메인/엔티티/1차 단위/2차 단위 정의.
     - `[스키마 수정]`: 엔티티명 및 단위 변경 시 기존 레코드 메트릭 캐스케이딩 갱신.
     - `[스키마 삭제]`: 원본 실천 데이터 보존 및 상위 도메인/루틴으로 안전 이동 (Soft-fallback).

### [WP-4] 도메인 중립 엔터프라이즈 데이터 그리드 모달
- **목적**: 엑셀/노션급 고밀도 테이블로 수천 건의 시계열 데이터를 검색·정렬·편집·내보내기.
- **세부 작업**:
  1. **컨텍스트 인식 완전 동적 컬럼 매핑**:
     - B2B 영업 ➔ `대표 지표 1: 매출액 (만원)`, `대표 지표 2: 계약건수 (건)`
     - 개발 코딩 ➔ `대표 지표 1: 커밋수 (개)`, `대표 지표 2: PR수 (개)`
     - 수험 학습 ➔ `대표 지표 1: 문제수 (개)`, `대표 지표 2: 학습시간 (분)`
     - 자산 금융 ➔ `대표 지표 1: 저축/투자액 (만원)`, `대표 지표 2: 수익률 (%)`
     - 운동 체육 ➔ `대표 지표 1: 중량 (kg)`, `대표 지표 2: 반복수 (회)` (실제 운동 엔티티일 때만 선별 적용)
     - 임의 CSV ➔ 원본 숫자 헤더명과 단위를 그대로 동적 매핑
  2. **모노스페이스 3상태 다차원 컬럼 정렬**:
     - Header 클릭: `None ➔ Descending ➔ Ascending ➔ None` 순환.
     - 숫자 컬럼 Monospace 우측 정렬.
  3. **원자적 CRUD**:
     - `[+ Add Entry]`: 일시(1900년대 지원), 엔티티, 주요 수치, 메모 입력 팝업.
     - `[✏️ In-place Edit]`: 행별 모달 수정 및 즉시 반영.
     - `[🗑️ Delete]`: 개별 삭제 및 단일 원장 갱신.
  4. **배치 일괄 관리 & 소스 필터**:
     - 전체 선택 체크박스 및 선택 항목 일괄 삭제 (`Bulk Delete`).
     - 소스 태그 필터: `[All Sources]`, `[B2B Sales]`, `[Dev Coding]`, `[Study Exam]`, `[Historical 1924]`, `[Custom Upload]`.
  5. **클린 CSV 내보내기 (Export Clean CSV)**:
     - 정제된 데이터를 UTF-8 with BOM 형식으로 1초 다운로드.
  6. **지연 페이징 (Lazy Paging)**:
     - 30건 단위 슬라이스 및 `[+ Load More (30 / Total)]` 버튼 탑재 (10,000건 무지연 렌더링).

### [WP-5] 프로급 SVG 차트 & 십자선 크로스헤어 인스펙터
- **목적**: 트레이딩뷰/블룸버그급 인터랙티브 분석 환경 제공.
- **세부 작업**:
  1. **수학적 축 스케일링 (Nice Numbers)**:
     - $[1, 2, 2.5, 5, 10] \times 10^n$ 알고리즘으로 균등 눈금 분할.
     - 5~8개 수평 점선 보조 격자선 및 Y축 Monospace 라벨.
     - 1900년대 연도.월(`1924.05`) 정밀 X축 표기.
  2. **자석 스냅 십자선 크로스헤어**:
     - 마우스 호버/터치 드래그 시 커서 위치에 수평/수직 점선 십자선 투영.
     - 20px 반경 내 가장 가까운 데이터 포인트로 마그네틱 스내핑.
  3. **실시간 플로팅 인스펙터 툴팁**:
     - 일시 (`YYYY-MM-DD HH:mm`), 수치+단위, 직전 대비 $\Delta$, PR 골드스타(★) 배지, 메모.
     - **`[✏️ Edit Record]` 버튼** 탑재로 차트에서 바로 해당 데이터 행 수정 직행.
  4. **상대 성장률 정규화 지수 (Normalized Index Scale)**:
     - 서로 다른 단위 비교를 위해 기준 시점($t_0$)을 100%로 환산하는 정규화 곡선 토글.
  5. **8종 WCAG AAA 고대비 컬러 팔레트** 적용.
