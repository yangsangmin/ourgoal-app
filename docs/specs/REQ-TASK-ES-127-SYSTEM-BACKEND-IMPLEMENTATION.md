# #TASK-ES-127 활용법 감찰 적발 미구현 시스템 전수 백엔드·로직 완결 구현 요구사항 정의서 (REQ)

## 1. 개요 및 배경
- **문제 진단**: #TASK-ES-126 활용법 전수 감찰 감사에서 적발된 3대 중대 결측(WebCal 백엔드 404, 30일 탈퇴 유예 안전망 부재, 마니또 가상봇) 및 핵심 기능 괴리(데일리 퀘스트 EXP 누적 미연동, 목표 도달 예정일 예측 알고리즘 부재)를 해결하여 헌법 규범을 100% 만족하는 실제 백엔드·시스템을 완결 구현한다.
- **상민님 승인**: 옵션 "2" (실제 시스템 백엔드 완결 구현) 직접 선택 및 승인.

## 2. 세부 기능 요구사항 (문제해결 8원칙)
1. **[RFC 5545] 실시간 WebCal 캘린더 피드 백엔드 구축 (pi/calendar.js)**:
   - webcal://<domain>/api/calendar?token=<userId> 요청 시 iCalendar 표준(.ics) 스트림 반환.
   - 사용자의 일정(events) 및 목표 마일스톤(milestones)을 VEVENT 형식으로 변환하여 구글/애플/아웃룩 캘린더에서 실시간 동기화 구독 지원.
2. **[게임화 & 보상] 데일리 퀘스트 3종 EXP 실제 지급 및 레벨업 시스템 배선**:
   - 체크인(+30 EXP), 마일스톤 완료(+40 EXP), 25분 집중(+50 EXP) 달성 시 실제 wardXP()를 호출하여 프로필 누적 경험치 및 레벨 상승 반영.
   - 일일 중복 지급 방지 추적 로직(questClaimedDate, questClaimedFlags) 탑재.
3. **[예측 인텔리전스] 목표 도달 예정일(D-day 예측) 동적 계산 알고리즘**:
   - 목표 마일스톤 완료 속도 및 최근 실천 빈도를 분석하여 "현재 페이스 유지 시 예상 완료일(Predicted Completion Date)"을 산출하여 목표 카드에 동적 표시.
4. **[컴플라이언스 & 안전망] 30일 탈퇴 유예 안전망(Soft Delete) 백엔드 파이프라인 구축 (pi/withdraw.js)**:
   - 탈퇴 요청 시 즉시 영구 삭제하지 않고 withdrawal_status = 'grace_period', withdrawal_deadline = now + 30days 설정.
   - 30일 이내 재접속 시 원클릭 탈퇴 철회(복구) 모달 제공 및 30일 경과 시 배치/관리자 영구 삭제 파이프라인 배선.
5. **[헌법 제4조 제1항 제7호 준수] 마니또 익명 응원 시스템 무결성 강화**:
   - 가상 봇 눈속임을 근절하고, 실제 커뮤니티 데이터 연동 및 진정성 있는 익명 응원 메시지 전달 구조 완성.
