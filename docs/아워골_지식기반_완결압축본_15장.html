🏛️ 헌법의 궁극 목적: 실존적 불안 해소 및 무공해 성장 도피처 선언
"내가 제대로 잘 살고 있는 게 맞나? 앞으로 어떻게 나아가야 하지?"라는 현대인의 실존적 불안을 기록의 실질적 체감으로 치유하고, 자극적인 숏폼·쓰레기 알고리즘과 과시형 SNS의 박탈감으로부터 완전히 격리된 무공해 성장 도피처를 제공함을 최고 목적으로 선언한다.

1. 3대 철학 심사 기준 (Philosophy Gate)

아워골의 모든 기획과 코드는 다음 3대 철학 심사를 100% 통과해야만 구현 단계에 진입할 수 있다:

1. 무공해성 (Anti-Pollution)
도파민 유도성 무한 스크롤, 타인과의 비교 자극, 과시 소비를 배제하고 마음의 안식과 뇌의 피로를 씻어내는가?
2. RPG식 체감 (Self-Efficacy)
유저의 사소한 실천이 궁극적 인생 청사진과 연결되어, 기록 즉시 경험치 획득과 성장을 직관적으로 체감하는가?
3. 동류 연대 (Peer Bonding)
상대적 박탈감이 아닌, 비슷한 고민과 목표를 품은 동류와 함께 올바른 방향으로 나아간다는 확신을 주는가?

2. 3대 본질 루프 및 5대 축 귀속 의무 (5 Pillars)

코드베이스 내 모든 작업은 반드시 아래 5대 축 중 하나에 명시적으로 귀속되어야 한다 (기본값: INFRA):

축 구분핵심 정의 및 사용자 체감기술 구현 및 컴포넌트 배선
E1 (체크인 루프) 목표 실천, 마이크로 체크인, 스트릭 유지. 단순 체크박스가 아닌 인생 청사진을 향한 RPG 즉각 보상. 홈 화면 3초 체크인, 히트맵 연속성 렌더러, 스트릭 부활 엔진, 당일 퀘스트 카드 연동
E2 (회고 루프) 5단위 회고를 통해 자기효능감을 복원하고 "다음 기록 의지"를 유저 심상에 확고히 형성. 오늘·주·달·년·설정 5단위 세그먼트, Gemini Flash 회고 피드백, 성취 내러티브 카드
E3 (동류 소통 루프) 과시 없는 무공해 연대. 동반자 맺기, 1:1 대화, 팀 목표 챌린지, 1-Tap 원터치 응원. Supabase Realtime 양방향 웹소켓, 1:1 DM 엔진, 익명 마니또, 팀원 찌르기 백본
INFRA / FIX 기반 인프라, 데이터 영속성, 성능, 결함 수습. PWA 서비스워커 캐시 무효화, 3계층 스마트 스토리지, 회귀 결함 긴급 복구

3. 6대 핵심 고질병 원천 근절 선언 (Anti-Pattern Firewall)

1호 되던 기능 먹통 (Regression)
새 코드 추가 시 기존 정상 기능이 파괴되는 현상. 법정(Court) 기준 시험지 채점으로 완벽 차단.
2호 껍데기 버튼 방치 (Shell UI)
핸들러/로직 없는 가짜 UI 방치 행위. 4위 1체 배선 원칙 및 정적 린터로 100% 소탕.
3호 상호연계 고립 (Disconnection)
기능이 단독 화면으로 겉돌고 타 화면과 단절되는 설계 금지. 4대 연계 뷰 동시 전파 배선.
4호 유저 데이터 증발 (Data Loss)
로그인 전환·업데이트 시 아바타·목표·기록 1바이트라도 유실되는 것 절대 불허. 합집합 보존.
5호 화면 간 상태 불일치 (Desync)
홈·기록·통계 간 데이터 비동기 불일치 금지. state 마스터 단일 진실 공급원(SSOT) 준수.
6호 가짜 실제구현 (Fake Impl)
가상 봇 자동답장, 로컬스토리지 자가저장으로 실제 구현을 흉내 내는 기만행위 영구 박멸.

🎯 사업 정의 (Executive Summary)
"고립된 작심삼일을 끝내는 AI 지능형 페이스메이커 & 무공해 소셜 넛지 플랫폼". 2030 세대의 84%가 '갓생'을 지향하지만 설치 후 30일 이내 90%가 포기하는 고립된 의지력 한계와 SNS 피로감을 해결. 2027 예비창업패키지(최대 1억) 선정 및 시드 투자 패키지(요약본 2P, 디테일본 60P) 구비 완료.

1. 기존 솔루션의 치명적 한계와 아워골의 해결책 (PSST)

구분기존 습관 / 투두 앱의 페인포인트아워골(OurGoal) 혁신 솔루션
전시형 SNS 피로 인스타그램 등 성과 과시 인증으로 인한 상대적 박탈감 및 실패 은폐. 철저한 무공해 동류 연대. 테마별 유사 목표 매칭 및 1-Tap 담백한 응원.
목표와 일상 단절 '물 2L 마시기' 등 사소한 행동이 인생 목표와 어떻게 연결되는지 모름. 인생 청사진-목표-일일 체크인이 하나로 꿰어지는 RPG 퀘스트 보상 구조.
스트릭 붕괴 이탈 단 하루만 빠져도 스트릭이 0일로 리셋되며 죄책감에 앱 삭제(Guilt Avalanche). 누적 노력을 증명하는 연속성 히트맵(Heatmap)과 부활 스트릭 시스템.

2. 수익화 4대 절대 규범 (Financial Integrity Rules)

아워골의 수익화는 3대 코어 루프(체크인/회고/동류소통)를 인질로 잡지 않으며, 아래 4개 영역으로만 엄격히 제한된다:

1. 아바타 다양화 (순수 자기만족)
서비스 본질 이용과 무관한 꾸미기 영역으로만 유료화 설계. 기본 320종 아바타로도 서비스 전체 기능을 100% 온전히 무료 사용 가능해야 함.
2. 타 유저의 잇템 (자발적 커머스)
멘토나 동류의 프로필 확인 중 사용자가 실질적인 필요에 의해 스스로 원할 때만 구매하는 자발적 커머스 형태로 연결.
3. 템플릿 복사 리워드 광고 (윈-윈 구조)
타 유저의 우수한 목표 템플릿을 복사할 때 자발적으로 광고를 시청. 앱이 일방적으로 광고를 강요하는 행위를 영구 금지.
4. 크리에이터 생태계 재투자 (선순환)
우수한 목표 구조를 제작해 생태계에 기여한 유저에게 수익이 배분되는 정당한 보상 환경 조성.
⚠️ 서비스 런칭 초기 무광고 원칙 (Zero-Ads Firewall)
초기 유저의 온전한 정착과 순수한 성장 경험을 보장하기 위해, 서비스 런칭 초기에는 일체의 배너/전면 광고를 전면 배제하며, 광고 도입 시기와 형태는 상민님의 명시적 결정(결심)에 의해서만 개방된다.

⚡ 2중 8원칙 프로세스 의무화

🚫 AI 코드 축약 및 생략 전면 영구 금지 (No Code Truncation)
AI 에이전트는 코드 작성 시 // ... rest of code unchanged ..., /* 기존 코드 동일 */, // TODO: 나중에 구현 등의 축약 주석을 단 한 줄도 남길 수 없다. 모든 함수와 로직은 생략 없이 100% 완전한 실행 가능한 코드로 작성되어야 한다.

1. 4위 1체 배선 원칙 (The 4-in-1 Complete Wiring)

인터랙티브 UI 요소(버튼, 링크, 입력창) 추가 시 반드시 아래 4개 요소가 한 세트로 완결되어야 한다:

1호 마크업 (Markup)
고유 ID, 접근성 라벨(ARIA), 올바른 시맨틱 태그 부여. 핸들러 없는 클래스 전용 껍데기 마크업 배출 즉시 차단.
2호 리스너 (Listener)
클릭/터치/키보드 이벤트 바인딩 또는 명시적 이벤트 위임(id, data-*, 비즈니스 클래스 분기문) 결속.
3호 비즈니스 로직 (Logic)
빈 함수나 console.log, 더미 플래그를 금지하고 실제 데이터베이스 쓰기 및 상태 변경 처리.
4호 피드백 및 예외 (Feedback)
로딩 인디케이터, 성공 토스트/화면 갱신, 네트워크 실패 시 친절한 안내 및 무손실 롤백 처리.

2. CSS 은폐(display:none) 원천 금지 및 시맨틱 통합 3단계

UI 전면 개편 시 기존 기능을 display: none !important;나 .stash로 화면에서 가려버린 채 상위에 대체 레이어를 얹는 가짜 실제구현을 위헌으로 규정한다. 반드시 3단계 시맨틱 통합을 거쳐야 한다:

통합 단계엔지니어링 의무 규격금지 및 위반 행위
1단계: 데이터 식별 기존 화면을 지탱하던 실제 상태 변수(state)와 DB 쿼리 파이프라인 식별. 새 화면을 만든다고 기존 데이터 파이프라인을 버리고 더미 객체 신설.
2단계: 마크업 재배선 새로운 디자인 조형의 DOM 슬롯 안에 기존 데이터 컨테이너를 온전히 재배치. 기존 DOM 요소를 숨김 처리(display:none)한 채 별도 태그 중복 생성.
3단계: 핸들러 직통 결속 새 UI 요소의 클릭 이벤트에 기존 비즈니스 로직 함수를 1:1로 직접 연결. 클릭 시 화면만 닫히고 실제 데이터 처리가 누락되는 껍데기 배선.

3. 연속적 유저 여정 및 모바일 하드웨어 OS 인터랙션 단절 제로

  • Closed Loop 여정 완결: 목표 생성 ➔ 소셜 연동 ➔ 실천 ➔ 회고까지 인앱 내에서 물 흐르듯 1회 완결되어야 하며, 상민님이 "이 기능 다음에 왜 이 버튼이 없냐"고 반문하게 만드는 여정 단절을 차단한다.
  • 안드로이드 물리 뒤로가기 연동 (History Safe): 모달/시트 오픈 시 history.pushState를 필수 연동하여, 뒤로가기 제스처 시 앱이 꺼지지 않고 최상단 모달만 순차적으로 닫히도록 배선한다.
  • 가상 키보드 차폐 제로: interactive-widget=resizes-content 뷰포트 메타를 적용하여 텍스트 인풋 포커스 시 핵심 저장/완료 버튼이 키보드에 가려지는 결함을 100% 차단한다.
  • 좀비 마크업 소탕: 숨김 클래스로 은폐된 레거시 모달 내 미배선 껍데기는 발견 즉시 100% 영구 삭제한다.

아래 9대 행위는 아워골 프로젝트의 신뢰성과 무결성을 파괴하는 중대한 범죄적 결함으로 규정되며, AI 에이전트 및 작업자가 이를 단 1건이라도 위반할 경우 해당 작업은 즉각 무효화 및 롤백 처분된다.

절대 금지 9대 행위 상세 해설

금지 항목구체적 위반 사례 및 금지 규정기계적 집행 및 방어 기제
1호 위조 숫자 및 허상 지표 날조 실존하지 않는 가짜 스트릭, 하드코딩 통계 렌더링 금지. 검증 스크립트 판정 기준 완화(False-Pass) 금지. 자가채점(자기가 만든 시험으로 자기 합격 선언) 금지. 법정(Court) 자가시험이 카나리/변이 주입 검증. 기준 커밋 시험지로 채점.
2호 파괴적 데이터 삭제 .delete().not(), TRUNCATE, 조건 없는 DELETE 등 유저 데이터 일괄 파괴 쿼리 전면 금지. 헌법 제15조 제2항 비파괴 합집합 병합(Union Merge) 강제 집행.
3호 도구/개발자 언어 노출 "Supabase Error", DB 컬럼명, 프레임워크 스택 트레이스 유저 화면 노출 금지. 사용자 친화적 피드백 안내 및 글로벌 에러 바운더리 포획.
4호 main 직접 커밋 및 승인 없는 머지 로컬 main 직접 커밋 금지, 상민님 명시적 승인 없는 gh pr merge 및 원격 main 푸시 전면 금지. GitHub 브랜치 보호 규칙 및 pre-push 훅 차단.
