# 🎯 아워골 베타 테스터 배포 안내 가이드 (72시간 릴리즈)

아워골(ourgoal) 베타 테스트에 참여해 주셔서 감사합니다!  
아워골은 목표를 세우고, 매일 1줄씩 기록하며, AI 코칭과 함께 성장하는 나만의 목표 달성 메이트입니다.

---

## 📱 설치 방법 (2가지 방법 중 편한 방법 선택)

### 방법 1. [초간편 1초 설치] 완성형 PWA (아이폰 / 안드로이드 공통 추천)
별도의 파일 다운로드나 보안 경고 없이 1초 만에 앱으로 설치할 수 있습니다:
1. 스마트폰 브라우저(크롬, 사파리, 삼성인터넷)에서 **https://ourgoal-app.vercel.app** 에 접속합니다.
2. 화면 하단 또는 브라우저 메뉴(⋮ 또는 공유 버튼)에서 **[홈 화면에 추가]** 또는 **[앱 설치]**를 누릅니다.
3. 스마트폰 바탕화면에 "아워골" 앱 아이콘이 생성되며, 일반 앱스토어 앱과 똑같이 전체화면으로 실행됩니다.

### 방법 2. [직접 설치] 안드로이드 전용 APK 파일 (.apk)
카카오톡이나 메일로 전달받은 `.apk` 파일 또는 GitHub Releases에서 다운로드한 파일로 설치:
1. 전달받은 `ourgoal-beta.apk` 파일을 탭하여 다운로드합니다.
2. "출처를 알 수 없는 앱 설치" 경고가 뜨면 **[설정] → [이 출처 허용]**을 켠 뒤 설치를 진행합니다.
3. 설치가 완료되면 홈 화면에서 아워골을 실행합니다.

## 🔒 보안 및 개인정보 안심 안내
1. **내 목표 비공개 보장**: 작성하신 목표와 기록은 본인에게만 안전하게 보관됩니다. 공개 피드에는 내가 직접 '공개'를 선택한 내용만 공유됩니다.
2. **AI 데이터 안전성**: AI 피드백 생성 시 개인 식별 정보는 일체 전송되지 않으며, 안전한 서버리스 프록시를 통해서만 처리됩니다.
3. **간편 탈퇴 및 즉시 파기**: 언제든 [설정] → [회원 탈퇴]를 누르시면 작성된 모든 데이터가 즉시 영구 파기됩니다.

## 💡 주요 핵심 기능 둘러보기
- **1초 소셜 로그인**: 카카오톡 또는 Google 계정으로 복잡한 절차 없이 즉시 시작
- **AI 맞춤 코치**: 오늘 한 일을 한 줄 적으면 AI가 목표 진척도를 분석하고 솔직한 조언 제공
- **연속 달성 스트릭 & 프리즈**: 매일 기록을 이어가며 불꽃을 키우고, 하루 놓쳐도 '스트릭 프리즈'로 보호
- **음성 체크인**: 글쓰기 귀찮을 때 마이크 버튼 누르고 말로 10초 만에 기록
- **안드로이드 뒤로가기 지원**: 모달이나 설정창에서 스마트폰 뒤로가기를 누르면 창만 부드럽게 닫힘
