## 이 문서가 정직하게 밝히는 것 — 무엇을 했고 무엇을 안 했는가

**했다**: 8앵글×60주제 설계, 60편 전부 실제 대본/카드 카피 작성(캐러셀 30·영상 30), 팩토리 제출용 작업지시서(Brief) 초안.

**안 했다(할 수 없었다, 짐작이 아니라 실측 근거)**:
1. **영상 렌더링·캐릭터 영상 생성** — "콘텐츠 자동화 파이프라인(우선순위 2 시스템)"은 Obsidian 볼트 `AI콘텐츠_자동화공장`(A01~A53, 26에이전트, WF-01~12, G0~G2d 게이트)이며, command-center(`lib/pipeline.js`)는 이 시스템에 대해 **읽기 전용 관측 계약**만 맺고 있다(코드 주석: "다른 세션이 지금도 고치고 있다. 남이 쓰는 장부에 내가 같이 쓰면 둘 다 못 믿게 된다"). 이번 세션이 그 노션 DB(「콘텐츠 작업 큐」)에 직접 60행을 밀어넣는 것은 이 계약 위반이자 동시수정 충돌 위험이라 하지 않았다.
2. **시청자 패널 100명 평가** — 볼트에 `11_시청자_패널`(build_panel.py, panel_aggregate.py)이 이미 있지만 이것도 같은 파이프라인 소속·다른 세션 소관. 대본 단계에서 평가할 실물(영상)이 아직 없어 평가 자체가 성립하지 않는다.
3. **게시 큐 최종 확정(평가 점수 포함)** — 위 1·2가 안 끝나 완료 기준을 오늘 못 채운다.

**구조적 병목 발견(본질 3·8원칙 ②)** — 이건 이번 세션이 새로 만든 문제가 아니라 실측으로 드러난 기존 문제다: 볼트 관찰로그 기준 「콘텐츠 작업 큐」 **총 39행, 발행 완료 0건**(2026-09-06~09-15 생성분 포함, 9일 이상 적체). 일일 제작 트리거는 G1(텍스트 게이트)까지만 자동이고 **발행은 100% 사람 게이트인데 발행 자동화 인프라 자체가 없다**(v6.1 문서에 "발행 전까지 수집 인프라를 짓지 않는다"로 명시, 성과 루프 마지막 칸이 원래부터 빈 채로 동결). 즉 지금 병목은 "주제가 부족해서"가 아니라 "다 만들어도 발행이 안 된다"이다. 이 문서의 60편을 그대로 큐에 얹으면 적체가 39→99가 될 뿐, 게시 0건 문제는 그대로다. **[결심 필요]** 없이 보고만 한다 — 발행 자동화 구축 여부·우선순위는 상민님 결심 영역(신규 외부 연동·계정 토큰 필요 = 승인선 ②·④에 걸림).

## ① 문제 고백 (영상 8편) — "작심삼일 고백"

각 영상: 훅(1줄, 자막 첫 화면) → 본문(2~3비트) → CTA. 보이스오버 없이 자막 중심(니치 톤).

1. **작심삼일 47번째** — 훅: "다이어리 47권째, 셋째 날부터 백지." 본문: 과거 실패한 다짐 앱 화면 스와이프 → 아워골 체크인 화면으로 컷 전환 → "이번엔 혼자가 아니라서 21일째." CTA: "프로필 링크, 같이 실패 안 하기."
2. **목표를 세우는 게 무서운 이유** — 훅: "목표를 세우면 꼭 못 지켜서 목표 자체를 안 세웠다." 본문: 완벽주의→회피 루프 설명, 아워골 "작은 목표부터" 온보딩 화면. CTA: "오늘 목표 1개만."
3. **3번 삭제하고 재설치한 앱 이야기** — 훅: "이 앱 3번 지웠다가 다시 깔았어요." 본문: 실패 이유(알림 스트레스)→아워골 프리즈 기능(하루 봐줌) 소개. CTA: "번아웃 없는 스트릭, 링크."
4. **혼자 하는 갓생의 끝** — 훅: "혼자 하는 갓생은 항상 2주에서 끝났다." 본문: 응원 피드 화면(지인 응원 알림)→다시 시작한 이유. CTA: "혼자 하지 마세요."
5. **다짐 노트 5년치 검사** — 훅: "5년치 다짐 노트를 다시 펼쳐봤다." 본문: 같은 목표 반복 쓴 페이지들 → 아워골 30일 데이터 그래프로 전환. CTA: "이번엔 숫자로 증명."
6. **미라클모닝 실패 66일차** — 훅: "미라클모닝 66일차, 오늘도 늦잠." 본문: 실패 인정 → 아워골 "미체크인해도 괜찮은 이유"(프리즈) → 재도전. CTA: "완벽 대신 꾸준함."
7. **연초 목표 vs 연말 나** — 훅: "1월의 나 vs 12월의 나, 목표가 똑같다." 본문: 반복 다짐 자막 몽타주 → 아워골 체크인 스트릭 화면. CTA: "올해는 기록이 남게."
8. **부끄럽지만 공개하는 내 체크인율** — 훅: "지난달 체크인율 62%, 부끄럽지만 공개." 본문: 낮아도 괜찮은 이유(완주보다 재시작)→아워골 응원 댓글 캡처. CTA: "완벽 안 해도 돼요."

## ② 리액션 (영상 6편) — "AI 답변 리액션"

포맷: 화면에 아워골 AI 코치 답변 캡처 + 리액션 표정/자막.

9. **"오늘 하루 망쳤어요"에 AI가 한 대답** — AI 코치의 공감형 답변 캡처 → 실제 반응(울컥). CTA: "AI가 아니라 코치 같아요."
10. **작심삼일 고민 상담했더니** — 사용자가 "또 3일차에 포기할 것 같다" 입력 → AI의 구체적 재설계 제안 캡처. CTA: "직접 물어보세요."
11. **목표를 너무 크게 잡았다고 하자** — AI가 목표를 쪼개주는 답변 리액션. CTA: "목표 쪼개기, 무료."
12. **번아웃 왔다고 솔직하게 말해봤다** — AI의 휴식 권유+프리즈 제안 리액션(다정함에 놀람). CTA: "쉬어도 된다고 말해주는 앱."
13. **"나 진짜 의지박약인가요"** — AI가 의지력보다 시스템을 이야기하는 답변 리액션. CTA: "의지 말고 시스템."
14. **경쟁앱이랑 비교해달라 했더니** — AI가 정직하게 아워골의 강점·한계를 설명하는 답변 리액션(놀라운 솔직함). CTA: "숨기지 않는 앱."

## ③ 니치 튜토리얼 (캐러셀 10편) — "목표 세우는 법"

각 캐러셀 8~10장: 표지 → 본문 카드(카드당 1문장) → CTA 카드. "앱은 자연스럽게"(니치 팁 50%/앱 인접 30%/앱 직접 20% 피라미드 준수).

15. **목표를 3줄로 쪼개는 법** — 표지: "목표가 안 지켜지는 진짜 이유" / 카드1: 목표가 크면 뇌가 회피한다 / 카드2: 3줄 쪼개기 공식(결과·이번주·오늘) / 카드3~5: 예시(체중감량→이번주 3회 운동→오늘 15분 걷기) / 카드6: 아워골 목표 쪼개기 온보딩 스샷(앱 인접) / CTA: 저장하고 따라 해보기.
16. **SMART 목표법, 한국어로 다시 쓰면** — 표지: "SMART는 영어라 안 와닿는다" / 카드: 구체적·측정가능·달성가능·관련성·기한 → 한글 예시 5장 / 카드: 아워골 목표 설정 화면 대조 / CTA.
17. **작심삼일이 반복되는 뇌과학 3가지** — 표지 / 카드: 도파민 예측오류·습관 루프·의지력 고갈 / 카드: 각 대응법 1줄씩 / 카드: 아워골 스트릭·프리즈 설계 근거 / CTA.
18. **오늘 할 일 vs 이번주 목표, 뭐부터 써야 할까** — 표지 / 카드: 순서(연간→분기→주→일) / 예시 5장 / 앱 연동 카드 / CTA.
19. **목표를 남한테 말하면 진짜 이뤄질까** — 표지 / 카드: 공개 선언 효과 연구 요약(과신 주의점 포함) / 아워골 응원 피드 카드 / CTA.
20. **습관 형성 21일설, 진짜일까** — 표지 / 카드: 66일 평균 연구 소개(작심삼일 통념 반전, WF-01 스코어 가산점) / 카드: 아워골 30일 체크인 데이터로 실측 예고(다음 콘텐츠 예고) / CTA.
21. **목표 우선순위 정하는 3단 질문법** — 표지 / 카드: "1년 뒤 후회할까/오늘 15분 낼 수 있나/숫자로 잴 수 있나" / 예시 / 앱 카드 / CTA.
22. **완벽주의자를 위한 목표 세우는 법** — 표지 / 카드: 100점 대신 60점 기준 세우기 5단계 / 아워골 프리즈 기능 매칭 / CTA.
23. **아침형/저녁형 상관없이 되는 체크인 시간 정하기** — 표지 / 카드: 크로노타입별 팁 / 아워골 리마인더 커스텀 카드 / CTA.

## ⑤ 비교 함정 (캐러셀 10편) — "플래너 vs 아워골"
