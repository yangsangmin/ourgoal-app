- 핵심 수치: 주의 계층 4단: 필요한 것 → 진행 중 → 완료 다이제스트 → 허영지표 · 7화면 · 규칙 4: 화면은 일을 일으킨다 / 상태는 실물에 고정("Done=산출물 이동") / 침묵은 플래그 / 링크 하나로 공유
