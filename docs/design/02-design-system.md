티켓 #TASK-ES-015 · 상민님 지시(2026-09-12): "완전히 전부 다 바꿔라. 당근·토스·네이버·다방·스타벅스·숨고 동급 이상. 기능 추가·누락 없음. 배포·병합까지."

## 1. 원칙 (6사 공통 문법에서 뽑은 것)
1. **표면은 중립, 강조는 단 하나.** 흰 바탕 + 회색 표면 + 브랜드 코랄 한 색. 그라디언트 텍스트·버튼·배경 블롭·글래스 블러 전부 폐기.
2. **아이콘은 이모지가 아니다.** UI 라벨의 장식 이모지를 없애고 선(stroke) SVG 아이콘 또는 텍스트만 쓴다. 사용자가 입력한 본문의 이모지는 건드리지 않는다.
3. **그림자보다 바탕 대비.** 카드는 회색 바탕 위 흰 면으로 분리(선 없음), 리스트 행은 1px 헤어라인(#E5E8EB). 그림자는 바텀시트·플로팅 요소에만.
4. **8pt 그리드, 20px 좌우 여백.** 섹션 간격 24~32, 카드 안 16~20, 리스트 행 높이 56 이상.
5. **타이포는 4단계 + 굵기 대비.** 26/22/17/15/13. 700 대 400. 900은 쓰지 않는다. 자간 -0.02em(제목), 본문 -0.01em.
6. **터치 타겟 48px, 주 버튼 52px 풀폭.** 눌림은 opacity .7 + scale .98, 120ms.
7. **로딩은 스켈레톤, 빈 화면은 한 줄 + CTA 하나.**
8. **모션은 짧고 스프링.** 시트 260ms cubic-bezier(.2,.8,.2,1), 탭 전환 180ms, 리스트 등장 없음.
9. **문구는 사용자 언어.** 도구 언어("노션 DB 규격") 금지. 위조 사회적 숫자 금지.

## 4. 화면별 재배치
- **홈**: 인사(제목) → 오늘의 질문(todayMissionCard) → 답하기(capture) → 피드백 슬롯 → 내 위치(요약 pill·퀘스트·레벨·목표 카드) → 기록됨(최근 기록 3개 링크). 모드 칩은 설정 > 화면 스타일로 이동(기능 유지).
- **목표**: 세그먼트(개인/팀) → 목표 칩 가로 스크롤 → 목표 헤더(제목·D-day·진행률 링) → 마일스톤 리스트(체크 원형 24px, 헤어라인 분리) → AI 입력은 하단 고정 입력바로.
- **일정**: 앱바 안에 월 이동, 세그먼트(월/주/일) 우측. 그리드 셀 그림자 0, 오늘 = brand 원.
- **기록**: 기간 세그먼트(오늘/주/월/년/설정) 최상단 → 요약 숫자(큰 숫자 26/700) → 차트 → 히트맵 → 리스트. AI 비서·템플릿 카드는 리스트 위 "빠른 기록" 한 줄로 압축.
- **소통**: 서브탭 밑줄형(당근·네이버식) → 피드 카드(아바타 40 원형·이름 15/600·시간 13 회색·본문 15·리액션 pill).
- **설정**: 그룹 헤더 13/600 회색 + 리스트 행 + 우측 chevron/스위치. 계정 위험 동작은 맨 아래 회색 텍스트 버튼.
- **랜딩/로그인**: 상단 여백 큰 로고 텍스트(ink 28/700) → 한 줄 카피 → 하단 고정 카카오(노랑)·구글(흰 테두리)·이메일(텍스트) 3단.
