## 기존 코드/PR과 겹치는 부분 (착수 전 확인)
- BACKLOG "다크패턴 금지" 원칙: 페이월 문구는 불안 조장형 FOMO를 쓰지 않는다.
- 맞춤 피드백 봇 설정 화면, 기간별 리포트(7일/30일 토글), 목표 생성 흐름은 이미 존재한다. 트리거만 끼워 넣고 화면 자체는 바꾸지 않는다.

## 사용자 필요 작업 (외부 콘솔·키, 코드에 넣지 않음)
- 토스페이먼츠 개발자센터 가맹점(테스트) 등록 후 **테스트 클라이언트 키** 발급. 이번 태스크는 테스트 키 + "가상 성공 처리"까지만 구현한다.
- 실결제 승인·빌링키 발급은 서버 시크릿 키가 필요하므로 클라이언트에 넣지 않는다. 필요 시 `api/` 서버리스 함수로 후속 태스크 분리.
- 정기결제(빌링) 상품은 토스 심사·계약이 별도로 필요하다. 심사 진행 여부 결정.

## 실행 프롬프트 (노션 원문, 2026-09-06 내보내기)

> 프롬프트의 코드 예시는 참고용이다. 기존 코드의 함수명·상태 구조·디자인 토큰이 우선한다.

아워골(OUR GOAL)의 수익화를 위해 토스페이먼츠(Toss Payments) 결제 연동 및 Pro 구독 페이월 시스템을 구축해주세요.

1. 요구사항:
- 토스페이먼츠 결제위젯/빌링 SDK 스크립트를 index.html 헤더에 추가해주세요:
  <script src="https://js.tosspayments.com/v1/payment-widget"></script>
- state.profile.settings에 구독 상태 필드를 추가하세요:
  subscription: { isPro: false, plan: null, expiresAt: null, billingKey: null }
- 페이월 팝업 모달 openPaywallModal(triggerReason)을 구현하세요:
  * 혜택 안내: 무제한 목표 관리, 맞춤 AI 코치 무제한, 30일/연간 심층 분석 리포트, 캘린더 양방향 실시간 동기화
  * 요금제: 월 8,900원 / 연 69,000원 (35% 할인 뱃지 부착)
  * [3일 무료 체험 시작하기] 결제 CTA 버튼 배치
- 유료 기능 잠금(Feature Gating) 로직을 연동하세요:
  * 활성 목표 2개 초과 생성 시도 시 페이월 팝업 트리거
  * 맞춤 피드백 봇 설정 화면 진입 시 페이월 팝업 트리거
  * 기간별 리포트에서 30일 선택 시 페이월 팝업 트리거
- 결제 완료 시 가상 성공 처리 후 isPro = true로 전환되고 상단 프로필에 'PRO' 뱃지가 붙도록 해주세요.

2. 수정 대상: index.html 내 결제 모달 생성 함수, 프로필 뱃지 렌더링, 페이월 트리거 분기 로직
3. 검증 기준: 무료 유저는 목표 3개 생성 시 페이월이 뜨고, Pro 활성화 시 제한 없이 생성이 가능한지 확인.
