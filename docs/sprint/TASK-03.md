## 기존 코드/PR과 겹치는 부분 (착수 전 확인)
- #captureCardBox(기록 입력 카드)는 기록 안내 문구·카테고리 선택 필드가 이미 있는 영역이다. 레이아웃 변경 없이 마이크 버튼과 칩 행만 추가한다.
- 기존 체크인 저장 함수와 축하 애니메이션(1단계 즉각 보상)을 그대로 재사용한다.

## 사용자 필요 작업 (외부 콘솔·키, 코드에 넣지 않음)
- 없음 (브라우저 내장 API). 단, iOS Safari·Firefox 등 미지원 브라우저 예외 처리를 검증 기준에 포함한다.

## 실행 프롬프트 (노션 원문, 2026-09-06 내보내기)

> 프롬프트의 코드 예시는 참고용이다. 기존 코드의 함수명·상태 구조·디자인 토큰이 우선한다.

텍스트 입력의 마찰을 줄여 데일리 체크인 완료율을 높이기 위해 브라우저 내장 Web Speech API 기반 음성 인식과 원터치 퀵 루틴 스탬프를 구현해주세요.

1. 요구사항:
- captureCardBox 내부 텍스트에리어 우측 하단에 마이크(🎙️) 버튼을 추가하세요.
- 마이크 클릭 시 window.webkitSpeechRecognition 또는 window.SpeechRecognition을 실행하여 음성을 실시간으로 텍스트에리어에 채워 넣으세요.
  * 음성 인식 중일 때는 마이크 버튼이 붉은색 펄스 애니메이션(@keyframes pulse)을 보이며 '듣고 있어요...' 상태 표시.
  * 말이 끝나면 자동으로 인식을 종료하고 텍스트 끝에 추가.
- 텍스트에리어 상단에 가로 스크롤 가능한 '원터치 퀵 루틴 칩'을 배치하세요:
  * 칩 목록: [💪 운동 완료], [📚 1시간 집중], [💧 물 2L], [🏃 5km 러닝], [🧘 명상 10분]
  * 칩 클릭 시 텍스트에리어에 해당 내용이 자동으로 들어가고 즉시 저장이 가능하도록 처리.

2. 수정 대상: index.html의 #captureCardBox, CSS 스타일, 음성 인식 이벤트 핸들러
3. 검증 기준: 마이크 버튼 클릭 시 음성 인식 텍스트가 정상 반영되는지 확인 (미지원 브라우저 예외 처리 포함).
